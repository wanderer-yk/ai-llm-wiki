# 个人记忆 vs 自进化记忆

[[RDSClaw]] 插件的两大记忆管线对比（源文五维对照表原样保留）：

| 维度 | 个人记忆 | 自进化记忆 |
|------|----------|------------|
| 消息来源 | User 消息 | User + Assistant 消息 |
| 提取目标 | 用户是谁、关心什么、发生了什么 | AI 学到了什么、犯了什么错、应该怎么做 |
| 典型内容 | "用户偏好 TypeScript"、"用户对花生过敏" | "上线前必须重启服务"、"删除前必须确认" |
| 演进方式 | LLM CRUD 语义整合 | 向量去重 + 存储 |
| 价值 | 让 Agent 记住用户 | 让 Agent 越用越好 |

## 关键差异解读

1. **消息来源决定视角**：个人记忆是"用户画像"视角（含 [[双提取器分流]] 的个人画像/世界记忆细分），自进化记忆是"AI 自我改进"视角。
2. **演进机制不对称**：个人记忆有完整 CRUD 语义整合（INSERT/UPDATE/SKIP/DELETE，见 [[LLM-CRUD记忆整合]]）；自进化记忆仅向量去重（≥0.92）+ 存储——错误经验与行为诉求如何过期/纠错，源文未说明，是不对称的张力点。
3. **价值定位互补**："记住用户"（个性化）与"越用越好"（自进化）分别对应 LoCoMo10 事实查询 +28.50% 与整体能力提升的归因。

## 跨来源对照

"让 Agent 越用越好" ↔ [[用得越久越好用]]（Hermes）；自进化闭环 ↔ [[memory-skill-nudge三子系统自进化闭环]]；从错误提取经验 ↔ [[reflection模式]]。
