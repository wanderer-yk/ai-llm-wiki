# C端全栈开发三挑战

**C端全栈开发三挑战**是天猫新品营销技术团队对 C 端全栈开发模式下 AI 辅助的三大建设方向的概括：①质量验收标准高、隐含逻辑多，无法全 AI 完成；②链路长、仓库多，需要有效串联；③高频高耗时节点需要分析优化，[[sources/[202605081607]天猫新增团队AI编码实战指南下|来源]]。

## 三挑战展开

1. **质量与隐含逻辑壁垒**：C 端位于 [[场景严苛度分级]] 表最顶端（错误 0 容忍、代码与视觉要求高），且业务隐含逻辑多——决定了 C 端路线是"AI 辅助"而非小二端式的"AI 主导"。
2. **长链路多仓库**：跨仓库的开发链路需要知识、流程与工具的有效串联——指向知识库建设与全链路 AI 串联度。
3. **高频高耗时节点**：对开发流程中重复且耗时的环节做针对性分析优化——指向标准化 workflow 沉淀。

## 与 Action 清单的对应

三挑战是问题定义，[[C端全栈开发Action清单]] 是解法清单；两者的递进关系构成本文 C 端章节的结构框架，并导向 [[AI友好代码架构]] 与 [[全链路AI串联度提升]] 两个未来方向。
