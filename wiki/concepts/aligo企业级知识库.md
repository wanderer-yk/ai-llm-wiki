# AliGo 企业级知识库

AliGo 企业级知识库是 [[阿里商旅]] 为其 AI 差旅助手 [[aligo]] 构建的集中式企业知识库系统：以 [[MaxKB]] 为基座，面向差旅政策等复杂文档提供解析、检索与渲染能力，通过标准化 API 供 RAG 子智能体接入。

## 四能力

| 能力 | 说明 |
|-----------|------|
| 支持 AliGo 快速集成 | 标准化 API 接口，RAG 子智能体快速接入知识库检索 |
| 图文混排文档处理 | 差旅政策等复杂文档的图片识别、切分与渲染 |
| 支持本地化部署 | 企业数据安全/私有化，完整容器化部署方案 |
| 多企业隔离 | 千人千面，请求自动映射对应企业知识库 |

其中**多企业隔离**（请求自动映射对应企业知识库）与**图文混排文档处理**最具区分度——前者是 SaaS 多租户知识层的工程要求，后者与智空间 [[图文嵌入模式]]（图文混排的模型侧处理）分别代表知识层与生成侧两条图文处理路线。

## 路线对照：集中式 vs 分布式

- 本方案为**集中式企业知识库**：中心化部署、多租户隔离、服务化 API。
- 有赞 [[knowledge-wiki]] 为**分布式项目知识层**：`.wiki/` 目录跟随 Git submodule，知识与代码同分支同步，自底向上构建（见 [[知识库降熵论]]、[[分布式wiki架构]]）。

两者服务对象不同：前者服务企业级 SaaS 终端用户（差旅场景的"千人千面"检索），后者服务研发团队内的 Agent 上下文供给，不宜简单判定优劣。
