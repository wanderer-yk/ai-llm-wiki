# 翻译"信达雅"

翻译"信达雅"是翻译质量的金标准，源自中国传统翻译理论。在 AI 翻译出海场景下，被 [[货拉拉技术]] 团队重新定义为出海企业需要实现的第一个核心目标。

## 三维度内涵

### 信（准确）

翻译内容准确无误，避免一词多义误判。典型问题如 UI 文案中的 "order" 在不同上下文中可能指"命令"或"订单"，AI 翻译通常选择"最大概率"词汇而非最合适词汇。解决方案是引入 [[多语种参照系few-shot]] 在语义空间锁死多义词语义。

### 达（地道）

翻译表达自然流畅，避免 [[翻译腔]]。AI 翻译因缺乏语境背景容易产生生硬、不自然的表达，带来沟通隔阂。解决方案是注入上下文和业务场景信息。

### 雅（美学追求）

翻译适配界面长度与风格统一。在 UI 文案翻译中，翻译结果需要考虑界面布局约束，保持品牌风格的一致性。这是商业翻译区别于通用翻译的特殊要求。

## 在多 Agent 框架中的实现

在 [[多agent翻译框架]] 中，"信达雅"标准通过翻译 Agent 的三项技术（术语库强约束、Few-shot 参照系、上下文注入）和翻译质量评分 Agent 的 [[双重自动评估打分机制]] 共同保障。
