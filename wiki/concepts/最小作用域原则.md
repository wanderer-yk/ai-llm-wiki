# 最小作用域原则

有赞 Knowledge Wiki 的知识写入约束原则：**能写 context 不写 app，能写 app 不写 workspace**。

## 核心逻辑

知识写入的层级越高，影响范围越大，维护成本越高。最小作用域原则确保：

1. **精准定位**：知识写在最具体的作用域，AI 读取时不会获取不相关的信息
2. **低维护成本**：context 级知识随局部变更更新，不影响全局
3. **避免噪音**：知识写多了反而是噪音——Agent 消费知识的方式和人不同，需要精准导航线索

## 三级作用域

```
workspace（全局）
  └── app（应用级）
       └── context（上下文级）  ← 优先写入
```

只有当知识确实需要被多个 context 共享时，才提升到 app 级；只有当知识确实需要被多个 app 共享时，才提升到 workspace 级。

- 是 [[知识准入控制]] 中"治理"维度的核心工具
- 是 [[分布式wiki架构]] 自底向上构建路径的写入规则
