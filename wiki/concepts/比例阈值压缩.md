# 比例阈值压缩

比例阈值压缩是 [[hermes-agent]] 运行时上下文压缩的触发机制（`agent/context_compressor.py`）：当对话 Token 数达到模型上下文窗口的固定百分比（默认 50%）时触发压缩。与 [[openclaw]] 的**绝对阈值**（按具体 token 数触发）相比，比例阈值无需按模型窗口大小频繁调整配置，泛化能力强——来源文章类比“硬盘 50% 自动清理”。

## 触发算例（原样保留）

```
context_length = 200,000 tokens（模型的最大窗口）
threshold_percent = 0.50（50%时触发压缩）
threshold_tokens = 200,000 × 0.50 = 100,000 tokens

当前对话 Token 数 ≥ 100,000 → 触发压缩！
```

## 压缩方式

触发后采用“头尾保留、中间摘要”的裁剪策略（与离线 [[轨迹头尾保护压缩]] 思路一致）：保留前 10 条 + 尾部动态，中间部分摘要化。Token 计数为粗略估算（4 字符≈1Token）。

## 定位

在 [[上下文压缩策略]] 页记录的压缩触发机制谱系中（绝对阈值、一次性摘要、分阶段压缩），比例阈值构成新的第三类触发方式；与离线轨迹压缩的四维对照见 [[双压缩范式对比]]。
