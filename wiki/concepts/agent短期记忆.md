# Agent 短期记忆

Agent 短期记忆指会话级的状态管理能力，覆盖两个维度："本轮对话说了什么"（对话历史）与"业务流程走到哪"（业务流程状态），区别于长期记忆（用户偏好、历史行为模式）。它是 Agent 在多轮对话、多次工具调用中保持连贯的实时状态基座，通常以微秒级低延迟存储承载（见 [[little定律并发放大]]）。

## 数据模型总览（淘宝闪购 Agent 实践）

短期记忆按**消费者**划分为两类双轨存储（详见 [[模型记忆与业务上下文记忆分离]]），并配合会话级并发控制（见 [[会话级分布式锁]]）。各记忆类型与存储结构的映射：

| 记忆类型 | 数据结构 | 选型理由 |
|---------|--------------|---------|
| 对话历史 | List | 对话是有序时间序列，支持有序追加（RPUSH）和范围读取（LRANGE） |
| 业务上下文 | Hash | 按领域拆分为多个字段，支持 field 级独立读写，避免读写竞争 |
| 会话状态标记 | String | 原子性状态标记（如会话阶段），操作简单 |
| 分布式锁 | String | 基于 SET NX EX 实现，保障并发安全 |

## TTL 会话记忆生命周期

所有会话 Key 设置 TTL（本文为 `EXPIRE 1800`，即 30 分钟），流量高峰过后内存自动回落，无需人工干预，实现"高峰扩、低谷缩、过期自动数据清理"的全自动资源管理。这与 [[记忆时间衰减]] 中 OpenClaw 用算法做时间衰减形成对照——同一"记忆生命周期"问题的两种介质解法（算法衰减 vs 硬性过期）。

## 与长期记忆的关系

本 Wiki 现有的记忆类概念——[[长记忆四件套]]（小红书 PMO）、[[openclaw双层记忆系统]]、[[markdown多层记忆体系]]、[[memdir结构化记忆系统]]——均面向**跨会话长期记忆**；短期会话态存储是其对偶互补的一环。本文展望中亦明确：记忆正从"对话级"走向"用户级"，长期记忆（用户偏好、历史行为模式）是下一步规划。

## Token 优化：写时归一

对话记录写入前将原始数据（文本+卡片富媒体）转换为模型更易理解的自然语言格式以减少 Token 消耗，属于"写时归一"路径，与 [[上下文压缩策略]]、[[工具结果头尾修剪]] 的"读时修剪"路径互补。转换执行主体（模型/规则）未在原文披露。
