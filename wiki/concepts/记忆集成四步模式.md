# 记忆集成四步模式

记忆集成四步模式是 Agent 框架集成记忆系统的通用流程模型：描述一次推理过程中短期记忆与长期记忆如何协同工作。该模式出自《AI Agent 记忆系统》（柳遵飞（翼严）），是理解 [[agentscope]] 等框架 `memory`/`long_term_memory` 双组件协作方式的骨架。

## 四步流程（原文）

```text
Step1：推理前加载 — 根据当前 user-query 从长期记忆中加载相关信息
Step2：上下文注入 — 从长期记忆中检索的信息加入当前短期记忆中辅助模型推理
Step3：记忆更新 — 短期记忆在推理完成后加入到长期记忆中
Step4：信息处理 — 长期记忆模块中结合 LLM+向量化模型进行信息提取和检索
```

## 要点

- Step1–Step3 构成推理循环中的记忆流转闭环：检索 → 注入 → 更新；
- Step4 发生在**长期记忆模块内部**，由 LLM + 向量化模型承担信息提取与检索，对应 [[长期记忆record-retrieve双向机制]] 的 Record/Retrieve 双向机制；
- 该模式解释了为何长期记忆通常被实现为**独立第三方组件**（Mem0、Zep、Memos、ReMe）：其内部流程（信息提取、向量化、存储、检索）复杂，框架经 API 集成而非内置。

## 关联

- 依赖 [[记忆会话边界二分]] 的短期/长期两分前提；
- [[agentscope]] 的 `ReActAgent.builder().longTermMemory()` 集成 API（[[mem0]]、[[reme]]）是该模式的具体工程落地。
