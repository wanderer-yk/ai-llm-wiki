# 类skill公共知识库

**类skill公共知识库**是天猫新品营销技术团队轻量级团队知识库的组织形态：以类 Skill 的形式封装小二端开发规范与代码模版，使知识以"能力包"而非"文档堆"的方式存在，可被多种编码工具直接消费，[[sources/[202605081607]天猫新品团队AI编码实战指南下|来源]]。

## 架构组成

- 类 Skill 封装：开发规范 + 代码模版以统一格式打包；
- git 仓库管理源文件，npm 包作为资源承载与版本管理工具；
- 文件链接实现文档的多级管理与索引，"渐进式披露，不会过度占用 token"（[[npm包知识库架构]]）；
- AI 通过 curl 读取 npm 包下 CDN 资源，不依赖具体编码工具，接入只需配置在编辑器 Rules（[[无感辅助]]）；
- 可借用 CodeWiki 进行知识库问答；最终实现基础开发方案的统一收口（[[统一收口]]）。

## 跨团队 Skill 形态对照

- 与 vivo [[skill功能聚合]]：vivo 按功能维度组织工具"说明书"以压缩搜索空间，天猫按规范+模版组织团队知识以统一开发方案——都是"用 Skill 结构收敛知识"。
- 与腾讯 [[生产级skill]]：腾讯强调 Skill 的完整文件结构、设计决策与版本管理，天猫用 npm 包版本管理达成同等目标。
- 三方共同验证了 Skill 作为团队 AI 资产载体的价值（呼应 [[业务团队AI资产沉淀论]]）。
