# 统一任务抽象先行

统一任务抽象先行是无岳《Claude Code 源码拆解》第六章的核心命题（原文）：**「多 Agent 的前提不是 prompt 分工，而是统一任务抽象。」**主会话后台化、本地 subagent、in-process teammate、remote agent 全部映射进**同一任务语义**后，多 Agent 编排才不失控。

## Task 接口要点（作者示意骨架，非严格源码）

`Task` 对象承载生命周期治理（retain/diskLoaded/evictAfter）、结果回流、调度差异——[[前后台差异在调度]]、[[任务结果回流]]、[[任务生命周期治理]]。

## 论证链

1. [[多agent即多执行体论]]：多 Agent=多执行体，不是多 prompt；
2. [[子agent即任务对象]]：subagent 是 Task 的特例；
3. [[任务对象化判据]]：什么该对象化、什么不该；
4. [[执行收回论]]：能收回的执行才是可控执行；
5. 反面对照：spawnAgent 无生命周期治理即反模式（源页第六章对照）。
