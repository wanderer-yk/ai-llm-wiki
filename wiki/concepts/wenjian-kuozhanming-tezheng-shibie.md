# 文件扩展名特征识别

文件扩展名特征识别是 [[项目身份感知能力]]的具体实现方案，基于文件扩展名（如 `.flow`、`.dt`）精准判断项目类型。

## 识别策略

- EDI 项目优先于普通 Java 项目
- 通过扩展名特征快速确定项目类型
- 项目类型决定后续评审规则选择与 RAG 检索策略

## 应用场景

[[edi平台|EDI 平台]]的配置文件扩展名通常为 `.flow`、`.dt` 等。系统通过识别这些扩展名，自动切换到 EDI 专用评审规范，而非使用通用 Java 规则。

## 价值

解决了技术 2 无法区分不同项目类型的问题，确保 RAG 检索方向的准确性。这是 [[双rag架构]]的入口步骤，为后续的两级分块、知识工程检索、BGE 重排序等环节奠定基础。
