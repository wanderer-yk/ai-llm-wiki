# 工厂模式自适应 Agent 生成

**工厂模式自适应 Agent 生成**是奕寰在 [[agent设计模式对跖点]] 展望部分提出的前瞻性提案（**提案性质，非已落地实践**）：主 Agent 利用工厂模式的多态特性，在一次对话中按任务自适应生成仅负责本次任务领域/规划子节点的专业子 Agent 实例。作者自述“很容易实现，只不过用来解决的场景还没有出现"。

## 出处与定位

- 该提案是八组映射中的第八组：主 Agent 动态生成专业子 Agent ↔ 工厂模式多态（作者称“复杂工厂模式”；结合“多态”语境疑指抽象工厂模式，按原文措辞保留并加注）。
- 与第七组（Skills ↔ 简单工厂模式）同属工厂模式家族：Skills 是事先利用父类原子能力创作的静态技能文档，本提案则是运行时动态生成 Agent 实例。

## 相关对照

- 与 [[skills-sub-agent包装论]]（沈询文章簇：Skills 可视为对 sub-agent 的封装）同涉子 Agent 机制，但前者是静态封装复用，本提案是运行时按任务多态生成，形成“静态封装 vs 动态生成”的对照。
- 与 [[react-agent]] 的关系：提案若落地，主 Agent 的循环中会出现由 LLM/系统按任务实例化的专业子 Agent，改变现有单一循环+工具集合的执行结构。

## 开放问题

- 适用的任务场景尚未出现——何种任务需要“一次对话内自适应生成专属 Agent”而非复用既有 Skills 或子 Agent 定义？
- 生成实例的生命周期、权限边界与成本控制机制未讨论。
