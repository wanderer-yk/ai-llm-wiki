# 推理成本博弈论

[[韩春]] 提出的视角：Agent 的架构选型与阈值配置，本质上是与模型厂商推理成本的**间接博弈**——应用侧的每个结构性选择都在回应厂商的计费与算力结构。

**例证**：LangChain 区分 System/User Prompt 以利用 KV Cache 前缀缓存，降低算力消耗与 TTFT——相关知识放 system 还是 user 不只关乎效果（system 的"权重"可能更高），也关乎缓存命中带来的成本差异（见 [[llm不确定性物理不可消除]] 中厂商让渡精确性的同一成本逻辑）。

关联：[[kv-cache时间窗优化]]、[[cacheScope分级缓存]] 是本 wiki 中 KV Cache 成本/缓存策略的工程化对照点。
