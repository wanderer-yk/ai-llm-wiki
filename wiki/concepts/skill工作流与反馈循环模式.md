# Skill 工作流与反馈循环模式

Skill 工作流与反馈循环模式是 Anthropic 官方最佳实践（经 writing-skills 转述）中处理复杂任务的两种 Skill 结构模式：

## 两种模式

1. **工作流模式（可追踪检查清单）**：将多步骤任务编码为可逐项核对的检查清单，Agent 按清单推进并记录进度——适用于顺序性、一致性关键的任务
2. **反馈循环模式（验证器循环）**：验证器脚本 → 修复 → 重复直到通过——适用于结果可机器验证的任务

## 设计细则：验证器错误信息字段级具体

反馈循环模式的关键细则：验证脚本的错误信息必须**具体到字段级**，帮助 Agent 快速定位修复方向。示例（原文）：

```
"Field 'signature_date' not found. Available fields: customer_name, order_total"
```

即不只报"缺少字段"，还附上可用字段清单。

## 未量化主张

来源声明反馈循环模式"能显著提升输出质量"，但**无量化数据**——已登记 [[ai工程量化效果声明追踪]]。

## 跨来源收敛

该模式与 [[机器可验证完成条件]]（Pipeline 通过条件）、[[反馈循环护栏]]（Ralph Loop）、[[闭环负反馈控制]] 构成同一工程思想的跨来源收敛；其"验证不通过即不能继续"的性质与 [[blocker-gate]]、[[验证门禁化]] 同属硬门控家族。
