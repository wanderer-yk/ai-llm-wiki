# 上下文窗口四要素

上下文窗口四要素是[[觖弦]]在文章结尾感言中对「有限的上下文窗口中该放什么内容」这一问题的内容枚举：Agent 运行时上下文窗口中可能放的内容可归纳为四类——

1. **系统提示词**（system prompt）
2. **工具定义**（tool definitions）
3. **历史对话**（conversation history）
4. **参考文档**（reference documents / RAG 注入内容）

## 与文章各章的对应

| 要素 | 文章中的工程实现 |
|------|------|
| 系统提示词 | 摘要压缩后合并注入 system prompt（「【以下是之前对话的摘要，请参考】」） |
| 工具定义 | InnerTool 注册 + ToolCallbackBuilder 组装 JSON Schema；Skill/MCP 工具动态注册 |
| 历史对话 | ChatMemory 三层压缩（[[三层上下文压缩]]）；Session 级隔离；SubAgent 独立记忆 |
| 参考文档 | RAG 多路召回 + Rerank 后以「【参考资料 N】」模板注入 |

## 跨源对照

- [[上下文工程]]（马上消费）：四要素是企业级「知识注入+数据注入」框架的简化投影；
- [[agent框架三要素]]（腾讯）：Context Engineering 被列为框架三要素的「连接核心」，四要素即其内容清单；
- [[三大武器库]]（腾讯 binxiong）：知识库+MCP+Skills 与四要素中的「参考文档/工具定义」存在映射；
- [[工具定义最终论]]：四要素中作者对「工具定义」给出了终局预测。

四要素枚举的价值在于为 [[harness工程三部曲演进论]] 的「放什么内容」问题提供了可操作的检查清单。
