# 提示词工程统一论

提示词工程统一论是本文的收束性论断：**写好 Skill 与写好 Rules 需要的能力一样，都是提示词工程**。既然三者（Rules/MCP/Skills）的本质区别是信息在 API 请求中的注入位置（[[api请求位置决定论]]），且 Rules 与 Skills 对模型等价（[[rules与skills等价论]]）、Skill 流程非代码化（[[skill流程非代码化]]）、Skill 质量 = 提示词质量（[[skill质量等式]]），则三类机制的写作功底完全同源——区别只在工程包装（触发方式、执行隔离、组织分发），不在写作本质。

## 实践含义

- 团队培训与规范沉淀可以统一：一套提示词写作规范同时适用于 CLAUDE.md、`.claude/rules/*.md` 与 SKILL.md；
- 选型时比较的是「这个内容适合常驻注入还是按需触发、是否需要执行隔离」，而非「哪个机制更强」（[[rules-skills-mcp选型指南]]）。
