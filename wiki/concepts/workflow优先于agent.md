# Workflow 优先于 Agent

有赞共享技术团队在 AI 客服场景中提出的架构决策原则：优先选择确定性 Workflow 而非自主 Agent，追求结果可控。

## 核心论点

客服场景的特殊性决定了架构选择：
- **确定性优先**：客服回答直接影响用户体验，错误回答的代价极高
- **可控结果**：Workflow 的每一步输出可预测、可审计
- **"宁可不答，不能答错"**：与 [[意图识别保守策略]] 一脉相承

## 与 Agent 的关系

这一原则并非否定 Agent 的价值，而是明确的**分阶段策略**：
- **当前阶段**：Workflow 为主，确保核心客服链路的稳定可靠
- **未来规划**：从 Workflow 向更具自主性的 Agent 能力演进

这种渐进式思路与 [[三阶段平台演进路线]] 在哲学上一致——先建立确定性基础，再逐步引入灵活性。
