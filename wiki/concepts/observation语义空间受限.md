# observation语义空间受限

[[韩春]] 指出的 ReAct/闭环控制的关键缺陷：**Observation 观察的依然是 LLM 的返回，未跳脱 LLM 语义空间范畴**。即使 Tool 触达了真实环境，反馈信号仍被压缩回自然语言，经由 LLM 语义空间二次转译。

## 失真为何不可避免

1. 自然语言不如数学公式严谨；
2. Attention 机制导致长 Context 语义丢失。

两者叠加使信息失真根本不可避免（作者猜想：存算一体 GPU 或量子计算的突破或可改善 Attention 层面）。

## 关联

- 是 [[llm不确定性物理不可消除]] 在反馈链路上的延伸：生成端不确定 + 观察端失真。
- 两条补救路径：[[必要多样性定律]]（冗余监督）与 [[真实世界负反馈]]（更换反馈信号源）。
- 与 [[工具结果上下文守卫]]、[[工具结果头尾修剪]] 构成对照：后者管理 Observation 的 token 成本，本文指出其语义代价的必然性。
