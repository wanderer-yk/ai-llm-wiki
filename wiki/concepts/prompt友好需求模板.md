# prompt友好需求模板

[[柚漫剧团队]] 的"Prompt 友好型 PRD"实质支撑（3.1.2）：**通过 prompt 撰写规则反推需求模板**，生成内容完整、逻辑严密的需求文档。

## 反推流程

1. 提取需求关键词；
2. 与 prompt 词模版比对，查缺补漏；
3. 结合交互表述，明晰结构化 / 标准化要求。

## 三类填空式模板

| 模板 | 适用场景 |
|------|----------|
| 单页面 0-1 | 全新单页需求 |
| 单页面 1-2 | 已有单页的迭代需求 |
| 多页面流程 | 跨页面流程需求 |

填空式约束与 [[结构化输出]] 的思想同源——用预定义结构收窄生成空间；模板由设计师供给（[[设计师作为需求架构师]]），是 [[需求质量协作者定位]] 的落地工具。
