# 标准化融合趋势

**标准化融合趋势**是 [[牛潇]] 对 [[mcp]] 与 [[agent-skills]] 未来演进方向的预测。

## 融合方向

1. **MCP 支持技能描述标准** — MCP 协议将内置对 Skills 的语义描述能力，使 MCP 工具能够自描述其在 Skills 流程中的角色
2. **Skills 内置 MCP 语义描述** — Skills 配置将内置对 MCP 工具的引用规范，提升互操作性
3. **统一开发框架** — 出现同时支持 MCP 服务定义和 Skills 流程编排的统一开发框架
4. **低代码平台** — 面向非技术人员的低代码平台，可视化编排 Skills 流程并自动连接 MCP 服务

## 意义

标准化融合将降低 MCP+Skills 协同架构的实施门槛，使更多企业能够采用这一范式构建生产级 AI 系统。

## 开放问题

- 统一开发框架的具体落地形态尚未明确
- 标准化融合的具体协议规范尚未发布
