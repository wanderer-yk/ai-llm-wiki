# 三大武器库

围绕 [[codebuddy]] 构建的统一规范体系，让 AI 真正"懂"项目。三大机制协同：知识库让 AI"知道"、MCP 让 AI"连接"、Skills 让 AI"掌握"。

## 一、知识库（知道）

### 双通道注入

1. **核心记忆（OpenSpec specs/）**：结构化、自动读写、与代码同仓库
2. **辅助记忆（MCP Knot 平台）**：非结构化、按需检索，存放业务术语表、架构决策历史、踩坑记录

### 知识库五分类

| 知识类别 | 来源 | 说明 |
|---------|------|------|
| 业务知识 | iWiki | 业务逻辑、产品规则 |
| 架构知识 | iWiki + Git | 系统架构、技术选型 |
| 项目规范 | OpenSpec specs/ | 编码规范、API 规范 |
| 历史决策 | iWiki + OpenSpec | 架构决策记录 |
| 常见问题 | iWiki | FAQ、已知问题 |

## 二、MCP（连接）

通过 Model Context Protocol 让 AI 直接访问团队内部工具，消除"复制粘贴"式跨工具搬运，实现信息零损耗传递。

| MCP 工具 | 连接目标 | AI 获得的能力 |
|----------|---------|-------------|
| TCS Component | 前端组件库 | 查询组件使用规则 |
| TAPD MCP | 需求管理平台 | 直接查询需求/Bug 单 |
| iWiki MCP | 文档平台 | 检索项目文档 |
| 极光流水线 MCP | CI/CD 部署平台 | 触发构建、查看部署状态 |

## 三、Skills（掌握）

团队沉淀的标准化操作流程（SOP）封装为 AI 可复用的技能包。

- **统一管理仓库**：`ted.aurora/tcsc-skills`（按业务域分类，如产品市场/atomic、工程实践/bug-fix）
- **分发平台**：SkillHub 市场（`skillhub.dev.jiguang.woa.com`）
- **核心设计**：SKILL.md 定义完整 SOP，AI 照着执行不需人工解释上下文
- **核心理念**：好的 Skill 写一次，全团队永久受益

## 跨来源对比

- 知识库五分类的分源策略呼应爱奇艺 [[多源分治策略]]，但腾讯给出更细粒度的知识分类维度
- MCP 工具连接层思路与马上消费 [[上下文工程]] 的"Agent 接入"维度方向一致
- Skills 的 SOP 封装思路与美团 [[主r打样-sop分发]] 高度一致
