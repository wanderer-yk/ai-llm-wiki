# 评测 Agent 乐观偏差

跨端技术团队在探索用 Agent 自动评测 [[AI答疑助手]] 回答质量时发现的不对称偏差现象：评测 Agent 判"需改进"的案例，人工校验几乎全部确认（精准率高）；而判"优秀"的案例，人工仍有相当比例标坏（召回率低）——即模型系统性高估回答质量。

## 根因

模型在评估自身或同类输出时倾向过度自信：证据不足时无法意识到"不知道"，反而给出高分。

## 架构结论

**任何 LLM 应用不能完全依赖模型自评估，人工校验不可或缺。** 团队计划以 [[多维度标注体系]] 对齐来约束评测 Agent 的乐观倾向（注意：此方案仅为后续计划，未落地实施细节）。
