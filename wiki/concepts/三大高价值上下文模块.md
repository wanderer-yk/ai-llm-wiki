# 三大高价值上下文模块

三大高价值上下文模块是淘天集团搜索团队对「上下文工程成为核心技能」的具体化：由统一的 **Context Manager** 协同三类信息源，动态整合、解决冲突、按任务需求调整优先级，生成「精简、准确、与当前目标高度匹配」的上下文输入，降低 Token 浪费与幻觉风险。

模块构成（逐字保留）：

| 模块 | 内容 |
|------|------|
| 用户信息（profile） | 基于用户在平台内的交互行为，结合输入内容，提取有效信息 |
| Agentic RAG（知识检索） | 大模型采取「规划 - 执行 - 观察」模式，自主决策获取所需信息；含站内知识（行业规则、活动信息）与站外知识（趋势、百科） |
| Memory（记忆模块） | 历史对话摘要保留关键信息；截取历史曝光内容，通过模型筛选并总结 |

Context Manager 的动态路由示例（大促场景）：

- 用户偏好明确 → 优先注入行为序列；
- query 涉及新知识 → 强化外部检索；
- 多轮对话 → 调用 Memory 提取摘要而非原始记录。
