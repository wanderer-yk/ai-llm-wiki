# 双重自动评估打分机制

双重自动评估打分机制是 [[货拉拉技术]] 团队在翻译质量评分 Agent 中采用的半自动化翻译质量评估方法，结合语义相似度与文本相似度两个维度进行加权综合评估。

## 双重打分维度

### 语义相似度

采用 COMET / BERTScore 等基于深度学习的语义评估指标，衡量翻译结果与参考译文在语义层面的接近程度。这一维度能够捕捉意译、同义替换等语义等价但表面形式不同的翻译质量。

### 文本相似度

采用 BLEU 等基于 n-gram 匹配的传统机器翻译评估指标，衡量翻译结果与参考译文在词汇层面的重合度。这一维度对字面准确性较为敏感。

## 工作流程

1. 翻译 Agent 产出翻译结果后，评分 Agent 对其进行双重打分
2. 综合加权得分低于阈值的样本被自动拦截
3. 被拦截的低分争议样本交由人工进行 [[译后编辑]]
4. 高分样本直接通过，无需人工介入

## 价值

该机制有效化解了 [[效果评估矛盾]]——通过自动化打分覆盖全部翻译结果，仅将需要人工判断的争议样本过滤出来，大幅降低质检成本的同时保障了翻译质量底线。这是 [[多agent翻译框架]] 实现 90% 成本削减的关键技术之一。
