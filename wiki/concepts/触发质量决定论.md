# 触发质量决定论

触发质量决定论是本文对 Skill 自动触发上限的判断：**自动触发的上限取决于描述质量而非数量**。在 1% 窗口/8000 字符的列表预算和 250 字符单条描述限制下（[[skill列表token预算]]），堆砌 Skill 数量只会挤爆预算导致截断；描述模糊的 Skill 大概率不被模型自动识别，最终需手动 `/skill-name`——此时与 Rules 无区别。

## 推论

- Skill 体系建设的杠杆点在 description 写作（做什么、何时用、何时不用的三要素，见 [[description三大要素]]），而非扩充数量；
- 与 [[description触发准确性权衡]]、[[agent欠触发倾向]] 的实践结论互证，形成「描述工程决定触发行为」的源码级证据链。
