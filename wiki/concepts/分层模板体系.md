# 分层模板体系

[[六步智能提示词生成法]]第四步的核心设计。`PromptTemplateEngine` 采用三层结构组装最终提示词，确保 AI 输出既符合编码规范又针对具体问题类型。

## 三层结构

### 第一层：角色设定

将 AI 明确为"精通 Java 开发的资深工程师"，建立专业语境。

### 第二层：通用编码规范（JAVA_STANDARDS）

自动注入阿里巴巴 Java 开发手册 6 条核心规则作为固定锚点，确保修复代码符合团队规范。这一设计呼应美团 [[ai友好研发规范]] 中"从团队协作建议升级为约束 AI 产出基础设施"的理念。

### 第三层：问题类型专属修复要求（ISSUE_TEMPLATES）

为不同问题类型提供专属修复指导：

| 问题类型 | 修复要求 |
|---------|---------|
| NullPointer | 防御性检查 + IllegalArgumentException |
| ResourceLeak | try-with-resources 模式 |
| SQLInjection | PreparedStatement 参数化查询 |
| 其他 | 降级到通用默认："修复以下代码问题" + "保持代码风格与项目一致" |

## 输出格式约束

明确约束输出格式为"仅输出修复后的完整方法代码"，减少解释性文字浪费 Token。

## 扩展性设计

新增问题类型只需添加模板配置和示例字符串，无需修改框架代码。
