# 从 Copilot 到 AI Agent 范式转移

[[柚漫剧团队]] 测试章 5.1 提出的范式判断：QA 域正从 Copilot 式辅助（用例生成、规划生成）**跨越到 AI Agent 自主执行（用例执行）**——LLM 成为具备"独立行动"能力的 AIQA，人从"执行者"转为"**监督者/调教者**"。

## 两个跨越

1. 能力跨越：从"生成建议"到"执行动作"（对应 Agent Loop 中的工具调用与自主决策，参见 [[react-agent]]）。
2. 角色跨越：人退出执行回路，进入监督与调教回路——与 [[ai-native研发模式]] 的"施工队长"叙述一致，其组织后果见 [[角色概念模糊]]。

该范式转移是 [[AIQA]] 体系（主 Agent + 数字员工 + 专业 Agent）的立论前提。
