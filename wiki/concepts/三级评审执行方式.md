# 三级评审执行方式

本文为对抗自评失真设计的评审者分离策略（逐字要点）：

1. **最优**：使用 Agent Teams（目前仅 Claude Code 支持）开一个独立的 Reviewer Agent——给它产出文件路径 + 对应清单 + 上下文，让它从零开始逐项核查。
2. **次优**：没有 Agent Teams 能力就用 SubAgent，走同样流程。
3. **兜底**：当前 Agent 自己逐项核查。但即使是自检，也必须"严格逐项"，不允许目测一遍就放行。

## 实战执行三处

- 第一步：Content Writer 写口播稿+大纲后，两个独立 Reviewer Agent 分别质检，主 Agent 校对终版（"写—审—校"三段编排）。
- 首章：独立 Review Agent 质检。
- 每章：完成后进入质检，全部通过才任务完成。

## 谱系位置

与 [[llm-as-judge]]（天猫）、[[高阶模型审查低阶模型]]（美团）同属"评审者分离"家族；本文差异在于提供了按 Agent 能力降级的**三级可执行降级路径**，且兜底自检也被约束为逐项核查而非自由目测。与 [[评测agent乐观偏差]]、[[硬性自检规则]] 构成完整评估方案。
