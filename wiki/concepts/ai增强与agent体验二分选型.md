# AI 增强与 Agent 体验二分选型

AI 增强与 Agent 体验二分选型是 [[沈询]] 在 AI Agent 系列第二篇（2026-02-25）中为 Agent 适用边界自设的二分准则：是否选用 Agent 不取决于技术先进性，而取决于产品目标是"给既有系统增强 AI 能力"还是"让用户明显感知这是一个 AI 驱动的创新类产品"。

## 二分内容

1. **既有系统增强 AI 能力 → 代码 + toolcall**
   - 效果最好，准确性有保障
   - 适合需要精确控制、高性能的场景
2. **让用户明显感知 AI 驱动的创新类产品 → AI Agent**
   - 适合需要处理不确定性、快速迭代、让非技术人员也能完成复杂任务的场景

## 内部张力

全文高调主张"Agent 是更面向未来的新应用使用范式"，末尾却明确给出"既有系统用代码 + toolcall，准确性有保障"的边界——说明作者并未主张 Agent 全面替代传统方案，宣传语气与实用建议之间存在落差。这一保守边界也与有赞 [[workflow优先于agent]] 的确定性优先立场部分收敛：双方都在准确性敏感场景放弃全自主 Agent。

## 原文关键判断

"关键是要理解每种方式的本质，根据实际场景选择最合适的方式。Agent 的核心价值在于它开辟了新的可能性，让 AI 真正成为决策者，而不仅仅是执行者。"
