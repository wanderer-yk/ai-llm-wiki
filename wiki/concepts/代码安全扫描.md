# 代码安全扫描

在代码片段发送至大模型之前，通过敏感信息扫描工具进行脱敏处理的安全机制，避免密钥、密码等敏感信息泄露。

## 在 Code Insight 中的应用

[[code-insight|Code Insight]] 的 [[向量检索rag|RAG 双阶段流水线]]中，代码进入索引阶段的第一步即为安全扫描：

```
代码 → 敏感信息扫描 → 分块 → 嵌入 → 向量库
```

## 核心价值

- **防止泄露**：避免将密钥、令牌等敏感信息发送至外部模型服务
- **合规保障**：满足企业代码安全管控要求
- **自建动机**：敏感信息扫描是自建代码索引（vs 使用第三方工具）的三大动机之一

## 自建 vs 第三方

| 维度 | 自建方案 | 第三方工具 |
|------|---------|-----------|
| 代码安全 | 内部扫描+脱敏 | 代码发送至第三方 |
| 成本控制 | 几毛钱/次 | 数美元/次 |
| 定制性 | 可定制扫描规则 | 受限于工具能力 |
