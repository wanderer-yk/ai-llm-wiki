# AI 狼人杀游戏

基于大模型 Agent 实现的狼人杀游戏，支持人机混合对战。狼人杀作为社交推理博弈场景，对多智能体系统提出了六项核心工程挑战。

## 六大工程挑战

1. **持续思考**：Agent 需在多轮对话中持续推理，非单轮问答
2. **信息隔离**：不同角色拥有不同信息视野（狼人夜谈对村民不可见）
3. **多说话者记忆**：LLM API 仅 system/user/assistant 三角色，无法区分多说话者
4. **决策明确性**：Agent 需输出结构化决策（"投 3 号"），而非模糊自然语言
5. **人类玩家接入**：人机混合对战中编排器需无差别处理人与 AI
6. **进程实时展示**：游戏状态需实时推送给前端，支持观战与复盘

## 游戏循环

详见 [[werewolf-game-loop|狼人杀游戏循环]]：夜晚（狼人 MsgHub 讨论 + 神职独立调用）→ 白天讨论 → 投票放逐 → 胜负判定 → 下一轮

## 未来方向

- 多人混合对战（多人 + AI 填充席位）
- 全模态交互（TTS + 角色专属声线）
- 新角色扩展（白痴、守卫、丘比特）
