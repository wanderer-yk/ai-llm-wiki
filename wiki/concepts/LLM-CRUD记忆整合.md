# LLM CRUD 记忆整合

LLM CRUD 记忆整合是 [[RDSClaw]] 个人记忆管线整合器的核心机制：对每条新事实，先向量检索已有记忆，再由 LLM 判定四种动作——INSERT（新事实）/ UPDATE（信息更丰富）/ SKIP（已存在）/ DELETE（矛盾过时）。

## 机制意义

- **去重升级**：从原生 Jaccard 字面相似度升级为「向量近似 + 精确匹配 + LLM 语义判断」。
- **矛盾处理升级**：从统计评分自然淘汰升级为 LLM 显式识别矛盾并主动 DELETE——解决"花生过敏"类低频重要信息被统计信号埋没的问题。
- 每次整合决策都有 LLM 参与，弥补原生六维统计评分"无语义判断"的盲区。

## 边界

该机制仅用于个人记忆管线；自进化记忆管线演进方式仅为「向量去重 + 存储」，无 CRUD/矛盾清理（不对称，详见 [[自进化记忆管线]]）。
