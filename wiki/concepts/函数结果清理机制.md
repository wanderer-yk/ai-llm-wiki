# 函数结果清理机制

**函数结果清理机制**（FRC，函数结果清理）是 [[claude-code]] 动态 Prompt 中的上下文管理模块：旧工具结果自动清除、仅保留最近 {N} 条，配合「工具结果总结提示」模块要求模型把重要信息写进回复，防止关键信息随结果被清理而丢失——上下文管理的主动设计而非被动截断。

## 要点

- 清理对象是历史工具输出（占用 token 最大的部分），保留窗口为最近 {N} 条（**{N} 具体值未披露，属遗留悬案**）。
- 配套的自我转写指令形成闭环：既然旧结果会被清理，模型必须在回复中沉淀重要结论。
- 与 [[三层上下文压缩]]（MicroCompact/SM Compact/Full LLM Compact）是不同粒度的互补机制：FRC 面向单条工具结果，三层压缩面向整段对话；均体现「规则驱动优先于大模型总结」的成本意识（对照 [[上下文压缩策略]]、[[快照冻结与前缀缓存]]）。
