# 能力抽象对象迁移

能力抽象对象迁移指平台化思维在 AI 时代的延续方式：分层、解耦、平台化的**方法不变，但被抽象的对象变了**——从业务域实体（传统领域模型中的商品、订单、用户状态机）迁移为 AI 能力组件（Agent、SOP 协议、Tool、Memory）。原文概括为「变化的不是方法，而是被抽象的对象」。

迁移后的 AI 搜索体系四核心组件（逐字保留）：

| 组件 | 定义 | 备注 |
|------|------|------|
| Agent | 独立解决某类问题的智能实体 | 例：AI 助手商品筛选（跑马灯 agent）、双 11 清单对话页清单生成 Agent |
| SOP协议 | 统一 Agent 调度层以及 Agent 执行层调度协议，能对 Agent 和 tool 进行编排 | 对应 langChain 框架中 chain 的概念 |
| Tool | 工具服务，基于主搜编排框架，工具配置化接入 | 支持通用 MCP 协议工具，同时支持本地及远程工具调用 |
| Memory | 记忆模块 | 针对过去回答的结构化存储和检索能力 |

驱动方式同步迁移：从状态机驱动 → Agent 驱动——Multi-Agent 架构使 Agent 自主规划交互流程、输出结构化知识、答案原子化/多样化呈现，「摆脱传统固定意图的限制」。
