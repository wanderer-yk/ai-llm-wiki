# 全链路可观测体系

全链路可观测体系指面向 AI Agent 的完整执行过程（多轮推理、Prompt 渲染、工具调用、子任务分发、上下文裁剪、流式生成），系统性地采集、组织、存储并可视化链路数据的工程体系，目标是"让 AI Agent 不再是黑盒"。本概念由《OpenClaw-Observability》一文（[[皓跃]]）围绕 [[openclaw]] 的 `openclaw-observability` 插件完整落地。

## 动机："Done" 黑盒问题

- Agent 只回复 "Done" 时无法判断：真完成 / 中间步骤报错被 Prompt 掩盖 / 根本没调工具而"脑补"回答。
- 传统文本日志"太碎、太散、太难关联"（长 System Prompt、嵌套 JSON、模型中间输出、HTTP 上下文、工具调用记录）。
- 解决思路：不做日志搬运工具，做面向 Agent 的可观测插件。

## 核心论断

可观测成立的关键不是"采到数据"，而是"数据能被组织成可理解的执行过程"。

## 价值主张

"不是让我们看到更多信息，而是更快地看到真正有效的信息。"典型成效见 [[静默决策显性化]]（Done 案例复盘）。
