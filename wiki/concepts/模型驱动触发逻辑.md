# 模型驱动触发逻辑

模型驱动触发逻辑（Model-driven Activation）是 Skill 的触发机制：**Skill 是否被调用完全依赖 description、由模型自主判断，而非关键词硬编码**。这是 Skill 开放标准区别于传统规则路由的关键设计。

## description 写作四要点

1. 祈使语气
2. 聚焦用户意图
3. 适当强势
4. 含关键触发词

好例含作用、使用时机与识别性关键词（如 PDF 提取例）；差例如 "Helps with PDFs."——过短、无触发场景、无使用时机。

## 发现的两条边界

1. **触发后行为边界**（writing-skills 测试发现）：description 内容不仅影响是否触发，还影响触发后 Agent 是否完整阅读 Skill 正文——总结工作流的 description 会诱发走捷径（见 [[description只写触发条件]]）
2. **触发失效边界**（Issue #514）：操作型 Skill（"运行部署脚本""生成日报"类）触发率恒为 0%，触发取决于任务复杂度/专业性而非 description 质量（见 [[操作型skill触发失效]]）

## 评测化落地

触发是否命中是独立评测维度：用 `should_trigger` 布尔样例构成 [[触发测试集]]，并以 run_loop.py 自动迭代优化 description 触发准确率。
