# 触发测试集

触发测试集（trigger_eval.json）是用 `should_trigger` 布尔样例测试 Skill description 触发边界的评测数据：每条样本为一个用户 query 与其期望触发结果，是 [[模型驱动触发逻辑]] 的评测化落地，也是 [[像做机器学习一样做prompt工程]] 中"训练集/测试集"在触发维度的具体格式。

## 设计特征

- **正反例严格平衡**：可见样本 18 条，9 true / 9 false（Issue #514 提及 "20 eval queries"，计数出入待核）
- **反例为相邻高混淆任务**：debug segfault、性能优化、重构依赖注入、写单元测试、解释语法、代码翻译、报错解读——全部是"与代码审查相邻"的任务而非无关任务，用于测试精度边界
- **正例含刻意模糊表述**："not a formal review, just a sanity check" → true，测试召回边界
- **中英双语覆盖**：中文/英文、纯文本/含代码块/含 URL 等多形态
