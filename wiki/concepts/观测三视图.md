# 观测三视图

观测三视图是《OpenClaw-Observability》展示分析层（[[四层观测架构]] 第四层）提供的三类视图，使开发者看到"完整、可解释、可下钻的执行时间线"而非散乱日志。

## 三类视图

| 视图 | 内容 |
|------|------|
| Trace 视图 | 按时间序展示一次执行链路中的 LLM、工具、子任务与输出过程 |
| 分析视图 | 聚合 Token、会话数、耗时分布、失败率等指标 |
| 安全视图 | 规则扫描与高危行为链告警 |

## 安全视图：六维度框架外的增量维度

美团 [[agent可观测性六维度]] 覆盖 goal / step / tool / failure / recovery / cost 六项指标，但不含安全维度。本文安全视图（规则扫描 + 高危行为链告警）是该框架之外的**增量维度**，二者构成"实现架构 vs 指标框架"的对照关系。

在跨来源的 Agent 安全扫描主题簇中，[[记忆内容威胁模式扫描]] 与 [[skill安全扫描统一门禁]] 聚焦**内容扫描**（记忆与 Skill 文本的安全模式），本文安全视图聚焦**行为链告警**（执行序列层面的高危模式），二者互补。

## 实证价值

Trace 视图使 Done 案例"十秒定性"，详见 [[静默决策显性化]]。
