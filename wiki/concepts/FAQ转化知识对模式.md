# FAQ转化知识对模式

[[上下文工程]]数据注入的两条路径之一。将动态结构化数据转化为静态的"标准问+相似问+标准答"知识对，准确率可达 98%+。

## 核心思路

解决**查询方-录入方口径不对齐**问题：数据表中正式名称（如"中国邮政储蓄银行股份有限公司"）与用户口语简称（"邮储银行"）无法通过传统 SQL 匹配。通过预先转化为知识对，从根本上规避名词不一致导致的召回失败。

## 转化结构

```
标准问：邮储银行的合同范本怎么查？
相似问：中国邮政储蓄银行合同模板、邮储合同范本在哪...
标准答：[具体操作步骤/答案内容]
```

## 适用场景

- 机构合作（合作伙伴名称口语化）
- 合规处罚（法规条款表述差异）
- 合同范本（模板名称与用户认知差异）
- 其他结构化数据需要自然语言查询的场景

## 与其他方法的对比

与 [[主体合并宽表模式]] 互补：宽表模式适合围绕实体的多维度查询，FAQ 转化适合围绕具体问题的精准问答。两者可组合使用覆盖不同数据注入场景。
