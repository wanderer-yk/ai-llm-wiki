# 知识到流程跃迁

[[柚漫剧团队]] 研发章（4.3.3）对 Rules 与 Skills 分工的凝练：**Rules 是教 AI"认识我们的工程"，Skills 是教 AI"按我们的方式做事"**——从静态知识注入跃迁到动态流程封装。

## 机制

- **Skill 的本质**：可复用的任务流程封装。
- 首个落地场景：前端单测（见 [[前端单测Skill]]）——AI 单测是 Skills 建设的第一个对象。
- 与 MCP 的三线对位：Rules 解决"AI 不认识我们的框架"、MCP 解决"AI 查不到我们的端能力"、Skills 解决"AI 不会按我们的流程做事"（见 [[ai-coding基建]]）。

## 跨源同构

与腾讯 [[生产级skill]]（可复用 SOP 封装）与 vivo [[skill功能聚合]]（按功能组织工具说明书）共同验证 Skill 层作为 Agent 工程化关键层的价值。
