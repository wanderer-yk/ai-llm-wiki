# 记忆召回与反馈环

记忆召回与反馈环是 [[openclaw]] 原生记忆系统的检索机制：`memory_search` 工具检索 `MEMORY.md` + `memory/*.md`，并通过信号记账将召回行为反馈给 Dreaming 评分，形成"越被检索 → 越容易晋升"的正反馈环（仅启用 Dreaming 时生效）。

## 检索基础设施（原文要点）

| 项目 | 内容 |
|------|------|
| 检索工具 | `memory_search`，作用于 `MEMORY.md` + `memory/*.md` |
| 后端 | builtin（SQLite + FTS，可选配 sqlite-vec 向量扩展）、QMD |
| 降级策略 | embedding 不可用时 builtin 自动降级为 FTS 全文索引 + 词法排名 |
| 信号记账 | `recordShortTermRecalls`（异步）→ `memory/.dreams/short-term-recall.json`（查询/结果路径/评分） |
| 预取 | Active Memory 插件：主回复前子 Agent 自动调用 `memory_search` |
| 时间衰减 | 检索侧另有可选时间衰减：默认关闭，半衰期 30 天 |

## 分析

- 反馈环使召回行为参与记忆生命周期治理：`lightHits`/`remHits`/recall 信号共同进入 Deep Sleep 六维评分（[[Deep-Sleep六维评分与晋升门控]]）。
- 局限：召回受 embedding 配置、查询精准度、Agent 检索意识制约（[[原生记忆不确定性链路]] 第四环）；[[RDSClaw]] 以三索引混合召回补强（[[混合召回]]）。
- QMD 后端技术细节未披露。
