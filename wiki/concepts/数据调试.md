# 数据调试

数据调试是天猫新品营销技术团队"问题调试"章的第二个小节，处理"无报错提示"的数据类问题：让 AI 自行在关键节点生成 console 输出日志，将不可见的数据流转化为可复制、可反馈的调试信息。其实质是把数据问题的诊断信号从"无"构造为"有"。

## 原文示例 prompt

```text
xxxx显示为空，帮我在关键节点新增console日志，以便我复制给你排查问题。
```

## 页面调试的备选通道（原文旁注）

以上页面调试也可通过 MCP 工具或 cursor 的 browser tab 进行（原文因篇幅所限未展开）。这为既有 [[cursor]] 页面补充了一个 browser tab 页面调试的使用场景数据点，MCP 页面测试通道则与自检机制中的"通过 MCP 工具进行页面测试"共用同一基础设施。

## 关联

- 与[[报错调试]]并列构成问题调试章的调试双子节；报错调试有现成信号（报错文本），数据调试需主动构造信号（日志），二者的分界是"是否有报错提示"；
- "让 AI 自加日志再依据日志修复"的模式与美团[[agent可观测性六维度]]中 step/tool 观测思想相通：把中间状态外化为可审查产物；
- 复制回的调试信息本质上是给 AI 的补充上下文，与[[结构化上下文组装]]同属"把诊断信息结构化后回灌"路线。
