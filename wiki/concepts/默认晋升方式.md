# 默认晋升方式

默认晋升方式是 [[openclaw]] 未启用 Dreaming 时，日记忆 → 长期记忆（MEMORY.md）的晋升机制：完全依赖 Agent 主动整理，无机制保证发生。作者评价："灵活但不确定"——灵活在 Agent 可按语境自由判断，不确定在是否执行、何时执行、整理质量均无保证。

## 两种途径

1. **主会话直接写 MEMORY.md**（可跳过日记忆）；
2. **心跳维护**（每隔几天执行）。

## AGENTS.md 模板·心跳记忆维护（原文）

```markdown
🔄 Memory Maintenance (During Heartbeats)
Periodically (every few days), use a heartbeat to:
1. Read through recent memory/YYYY-MM-DD.md files
2. Identify significant events, lessons, or insights worth keeping long-term
3. Update MEMORY.md with distilled learnings
4. Remove outdated info from MEMORY.md that's no longer relevant
```

## 分析

模板指导仍是"方向性建议"——是否执行心跳、整理是否彻底，均取决于 LLM 自主决策（[[LLM弱约束记忆决策]]）。Dreaming 系统（[[Dreaming三阶段演进]]）提供了确定性替代路径但默认禁用；[[RDSClaw]] 以实时 CRUD 整合提供第三条路径。
