# 组织级自进化

组织级自进化是来源文章对 [[RDSHermes]] 相对开源 [[hermes-agent]] 的关键升级描述：开源版的经验资产（Memory/Skill）积累在**单用户**本地 `~/.hermes/` 目录，自进化是单点的；RDSHermes 将 Skill 存储搬到云端，一个 DBA 踩过的坑全团队的 Agent 都能绕过——自进化从个人资产升级为**组织级共享资产**。

**⚠️ 归因：此描述为厂商自述，未经第三方验证。**

## 边界对比

| | 开源 hermes-agent | RDSHermes |
|---|---|---|
| 经验存储 | 单用户 `~/.hermes/` 本地目录 | 云端共享存储 |
| 受益范围 | 单个用户/单台机器 | 全团队所有 Agent |
| 进化单位 | 个人 | 组织 |

## 关联

- 与 [[知识复利效应]]（有赞共享技术：知识沉淀价值随规模增长加速释放）直接同族——组织级自进化可视为知识复利在 Agent Skill 资产上的具体形态；
- 是 [[领域知识护城河论]] 从个人层到组织层的延伸；
- 与 [[用得越久越好用]] 的区别：前者强调受益范围扩大，后者强调时间维度的价值累积。
