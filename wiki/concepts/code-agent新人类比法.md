# Code Agent 新人类比法

[[书牧]]（[[天猫技术]]）提出的类比框架：将 Code Agent 类比为**新入职、基础十分扎实的高级全栈程序员**。

基本功强（技术栈规范已内化），但无法直接上手企业级需求——需了解仓库归属、依赖关系、基础设施规范、业务架构等 [[专家知识四层模型完整版]] 所涵盖的知识。

这一类比直观地解释了 [[范式变革瓶颈论]]：AI 执行能力已不是问题，缺的是企业级专家知识注入。
