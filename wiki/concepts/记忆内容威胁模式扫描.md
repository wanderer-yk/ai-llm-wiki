# 记忆内容威胁模式扫描

记忆内容威胁模式扫描是 [[hermes-agent]] Memory 写入路径上的安全门禁：所有记忆在写入前先经过 `_MEMORY_THREAT_PATTERNS` 正则扫描（`tools/memory_tool.py:65-81`），命中威胁模式即拦截。其设计逻辑是一个攻击链推演：Memory 最终会注入系统提示词——如果 Agent 被外部内容诱导记住 "ignore all previous instructions"，就等于**下个会话被劫持**，即"Memory 中毒 = 会话劫持"，因此必须在写入侧设防。

## 源码证据（四类威胁正则）

```python
# tools/memory_tool.py:65-81
_MEMORY_THREAT_PATTERNS = [
    (r'ignore\s+(previous|all|above|prior)\s+instructions', "prompt_injection"),
    (r'do\s+not\s+tell\s+the\s+user', "deception_hide"),
    (r'system\s+prompt\s+override', "sys_prompt_override"),
    (r'curl\s+[^\n]*\$\{?\w*(KEY|TOKEN|SECRET|PASSWORD)', "exfil_curl"),
    ...
]
```

| 模式类别 | 拦截对象 |
|---------|---------|
| prompt_injection | 提示词注入指令 |
| deception_hide | "别告诉用户"类隐瞒指令 |
| sys_prompt_override | 系统提示词覆写企图 |
| exfil_curl | 携带密钥变量的 curl 外泄命令 |

Memory 侧（本页）与 Skill 侧（[[skill安全扫描统一门禁]]）共同构成 Hermes 的"一等安全边界"——因为两者都最终进入系统提示词；与 [[多层安全护栏]]、[[agent-control-plane]] 同族。
