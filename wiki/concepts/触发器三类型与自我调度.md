# 触发器三类型与自我调度（Trigger）

触发器模块（Trigger）是 [[AssistantAgent]] 将"主动服务"能力（定时任务、延迟执行、事件回调）机制化的组件：定义三种触发器类型，且 Agent 可**通过工具自主创建触发器**，实现"自我调度"——从被动应答升级为主动发起任务。

## 三种触发器类型

| 触发器类型 | 标识 | 能力 |
|---|---|---|
| 定时触发 | `TIME_CRON` | 支持 Cron 表达式定时触发任务 |
| 延迟触发 | `TIME_ONCE` | 支持一次性延迟触发 |
| 回调触发 | `CALLBACK` | 支持回调事件触发（外部系统发事件到 Webhook） |

## 文内示例

- 定时："每天早上 9 点发送销售日报" → Cron 触发器自我调度；
- 延迟："30 分钟后提醒我开会" → 一次性触发器；
- 回调：外部系统发 Webhook 事件 → 触发 Agent 处理并返回响应。

## 与工具体系的印证

动态工具模块中的 **Trigger Tools**（定时任务、事件回调）印证了触发器经工具创建的路径：Agent 以工具调用方式自主创建/管理触发器（见 [[CodeactTool工具体系]]），这是"自我调度"得以成立的机制闭环。

## 比较候选

- 与 [[openclaw定时任务系统]]（OpenClaw 的定时任务系统）为跨框架比较候选：二者均让 Agent 具备时间维度与事件维度的主动性，可对比触发器模型（Cron/一次性/回调）与权限控制（Agent 能否自主创建定时任务）的设计差异。
- 主动服务能力与 [[经验学习与快速响应]] 互补：触发器解决"何时唤醒 Agent"，经验解决"唤醒后如何更快执行"。
