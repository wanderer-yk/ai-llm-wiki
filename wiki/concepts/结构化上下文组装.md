# 结构化上下文组装

有赞共享技术团队提出的上下文信息组装方法，用结构化方式（XML 标签分层）替代文本字符串拼接，结合 Prompt 定义知识优先级，显著减少模型幻觉。

## 问题背景

早期采用文本字符串拼接方式组装上下文信息，线上 Badcase 反馈显示模型频繁产生幻觉——知识片段之间的边界模糊，模型难以区分不同来源和可靠性的信息。

## 解决方案

### XML 标签分层结构

使用 XML 标签对上下文信息进行分层组织，例如：

- **知识库层**：标注信息来源和可信度
- **商品信息层**：商品规格、价格、库存等
- **物流政策层**：配送规则、退换货政策等

### Prompt 定义知识优先级

通过 Prompt 明确定义不同知识源的优先级规则：
- 当商品规格与商品详情图片信息冲突时，规格信息优先
- 官方文档优先于历史对话提取的 QA

## 效果

从文本拼接升级为结构化组装后，线上幻觉类 Badcase 显著下降。这一改进由线上 Badcase 反馈直接驱动，属于生产问题倒逼的工程优化。
