# IntentResult 模型

IntentResult 模型是 [[智空间]] 平台的结构化意图理解框架：把用户的自然语言"人话"解析为七个标准字段，作为意图识别 Agent 的标准输出与下游推理执行的统一输入，实现"把'人话'翻译成标准模型"。它在全文三次复现：复杂指令方案的意图识别节点、ReAct 推理模块输入五要素之一、框架 prompt 的输出模型定义。

## 七字段解析实例（原文保真）

输入："给用户1234发放一张满50减20的优惠券，预发环境"

| 字段 | 解析值 |
|------|--------|
| 谁 | 一般是我，不用解析 |
| 什么地点 | 预发环境 |
| 什么条件 | 未提供 |
| 关联方是谁 | 用户1234 |
| 做什么 | 发放 |
| 对象是什么 | 满50减20的优惠券 |
| 什么时间 | 现在 |

## 能力声明

支持单意图、多意图、负向约束与背景说明的解析。

## 复用位置

- [[复杂指令场景方案]]：意图识别节点的输出模型。
- [[ReAct推理模块]]：组装给大模型的输入五要素之一（来自意图识别 Agent）。
- [[意图识别双层prompt结构]]：框架 prompt 结构中的"输出模型定义（IntentResult）"，业务定制层围绕它填写意图定义与归一化词表。

## 关联

- 与 [[结构化输出]]（Function Calling 结构化机制）同属"LLM 决策可靠解析"路线。
- 与 [[FSWW工具召回算法]] 衔接：IntentResult 作为工具召回的匹配输入之一。
