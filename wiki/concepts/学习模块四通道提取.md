# 学习模块四通道提取（Learning）

学习模块（Learning）是 [[AssistantAgent]] 的经验供给端：从 Agent 执行历史**自动提取并持久化**有价值经验，供 [[经验学习与快速响应|经验模块]] 复用。其特色是以**四条学习通道**覆盖 Agent 运行时的不同切面。

## 四条学习通道

| 学习通道 | 说明 |
|---|---|
| After-Agent 学习 | 每次 Agent 运行完成后提取经验 |
| After-Model 学习 | 每次模型调用后提取经验 |
| Tool Interceptor | 从工具调用中提取经验 |
| 离线学习 | 批量分析历史数据提取模式 |

## 学习过程四步

捕获执行上下文 → 提取器分析识别 → 生成经验记录 → 持久化存储供后续复用。

- **学习上下文捕获四要素**：用户输入、中间推理步骤、生成的代码、执行结果——与 [[code-as-action]] 的执行链路（输入→推理→代码生成→执行→输出）对应。
- **三类提取器**：经验提取器（成功模式）、模式提取器（通用模式）、错误提取器（失败教训）。

文内工作流示例："查询订单状态"成功执行后保存三类经验入库 → "查询我的订单状态"匹配相似经验，更快决策 + 生成正确代码 → 配置了 `fastIntentConfig` 的经验命中即跳过 LLM。

## 与既有概念的关联

- 与 [[多智能体自进化]]（阿里商旅的观测→评测→进化闭环）同属"Agent 从运行中自我改进"路线；Learning 模块的特殊性在于将学习触点细分为 Agent 级、模型调用级、工具调用级与离线批量四个粒度。
- 错误提取器（失败教训）提供了负面经验留存机制，与提取成功模式形成正负双向学习。
- 待披露：经验库存储介质与相似匹配算法、提取质量的把关机制。
