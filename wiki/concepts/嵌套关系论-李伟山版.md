# 嵌套关系论（李伟山版）

嵌套关系论是 [[李伟山]] 文章第 05 章的核心论点：Prompt / Context / Harness Engineering 三者关系不是替代，而是**层层包裹、相互依存的嵌套关系**。

## 三者职责边界三问

| 维度 | 核心问题 | 对应进化 |
|------|---------|---------|
| Prompt | 我该跟模型说什么？ | 第一次进化 |
| Context | 模型在回答时该知道什么？ | 第二次进化 |
| Harness | 整个 AI 系统该如何可靠地运转？ | 第三次进化 |

## 三段递进论证

三者缺一不可的递进逻辑：

- **无 Prompt → Context 无效**：模型不知道该做什么
- **无 Context → Harness 瞎跑**：模型缺乏关键信息
- **无 Harness → 沙滩城堡**：系统层面无约束/验证/反馈

三者层层包裹、相互依存，共同服务于 [[三次进化统一目标论]]。
