# Ralph 替代循环

Ralph 替代循环是技巧 11"让它成为你自己的"提出的可配置性扩展：Ralph 只是一个循环，任务源和输出均可替换，由此可派生出针对不同代码质量目标的实验性循环族。通用适配判据："任何可以描述为'查看仓库，改进某些东西，报告发现'的任务都适合 Ralph 模式。循环是相同的。只有提示改变。"

## 四种替代循环

1. **测试覆盖率循环**：从 16% 提升到 100%
2. **重复代码循环**：以 jscpd 重复代码检测为数据源，迭代消除重复
3. **Linting 循环**：迭代清理 Lint 问题
4. **熵循环**：扫描代码异味并清理——"软件熵的逆转"

## 可替换维度

- **任务源可替换**：本地 prd.json → 任意来源。"代理选择任务，而不是你。你只是改变该列表的位置。"
- **输出可替换**：开分支提 PR / 评论 issues / 更新变更日志。示例工作流：issue 积压 → Ralph 分类、实现、开 PR → 人审查。

## 跨来源同构

- 扫描→修复流水线：与 [[sonar]] + [[六步智能提示词生成法]]（转转回收团队）同构——静态扫描结果作为循环任务源，AI 迭代修复
