# 配置化到自动化

配置化到自动化是本文 5.2 节提出的能力升级路径：在 [[ai助手工厂]] 已实现"配置化、模板化、极简化"的基础上，下一阶段将人工运维环节交由后台 agent 完成，把助手工厂从"人配"推进到"agent 配"。文中仅作预告，后台 agent 的具体形态与调度架构未展开。

## 拟由后台 agent 接管的人工环节

- 案例分析
- MECE 意图划分（[[排查助手定制三问]] 第二问）
- 一键三连配置录入（[[三步法配置助手]]）
- 调试发布
- 运维期真实用户 query 分析

## 案例沉淀不可替代论

原文："唯一不能被AI代替的是：具体案例沉淀（问题描述、解决过程、决策分析等）。"——自动化改变的是操作执行，专家案例沉淀（[[专家经验沉淀论]]）仍是平台的价值源点。

## 关联

- 与 [[自动化决策层级]]（zhiyuanfu 五层决策金字塔：优先使用确定性最低成本层级）和 [[24h打工人]]（无人值守调度）构成自动化边界思想的跨来源呼应。
- "案例沉淀不可替代"与 [[专家经验定向ai辅助排查]]（人定向+AI穷举+人裁决）同样划定了 AI 与人的分工边界。
