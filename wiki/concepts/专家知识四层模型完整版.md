# 专家知识四层模型完整版

[[书牧]]（[[天猫技术]]）以 [[code-agent新人类比法]]（Code Agent = 新入职高级全栈程序员）为类比框架，将 Code Agent 所需专家知识系统化分层。

## 四层结构

### 第一层：基础技术层（[[基础技术层七项子规范]]）

1. 技术栈规范（Java/Spring/前端框架——大模型内化能力强项，无需额外注入）
2. 基础设施规范（[[MTOP]]/[[BUC]]/[[ACL]]/[[BPMS]] 等公司中间件/微服务/网关/OA 基建）
3. 应用选型及分层规范（单体/Serverless/FaaS 分类及对应代码分层建议）
4. 代码质量规范（基本代码规范、单测规范）
5. CI/CD 平台和流程（[[Aone]]/[[O2]]/[[摩天轮]]）
6. 安全合规规范（公司数据安全规范等）
7. 解决方案经验（[[解决方案经验知识化]]：消息重试→最终一致性、[[tair]] version→分布式并发）

### 第二层：业务层（[[业务架构两级分解]]）

- 整体业务架构：电商核心领域全貌（[[百补业务]]/[[国补]]/[[3C数码行业]]），对一线开发非必选但理想 AI 程序员应了解
- 细分业务架构：程序员负责的具体细分领域知识，直接上手开发所必需

### 第三层：团队层

团队开发规范（[[团队规范消亡论]]：理想 AI Coding 情况下可能不再需要，应跟着公司整体规范和业务架构走）

### 第四层：代码仓库层（[[代码仓库三要素]]）

- 仓库代码架构：项目概要/结构/技术栈/API/数据模型/部署配置的理解（[[deepwiki]]/[[artifact7]]）
- 仓库代码索引：需求理解后的粗略定位（[[codebase]]）
- 精确代码定位：基于 AST 进行准确增删改

## 关键发现

[[业务层知识为最大挑战论]]：业务层知识最复杂、最易变、最隐性（存在于人类大脑中），是四层中最大瓶颈。

作者承认分层"不一定完备和准确"但思路正确，AI Coding 只需其中部分知识即可开始工作。
