# 动态能力面稳定内部对象

「动态能力面，稳定内部对象」是 Claude Code 扩展层（MCP/Skills/Plugins）的核心命题：「外部可以热闹，内部必须收敛」——外部能力来源可以多样且动态变化（重连、启停、刷新能力列表），但内部对象必须尽量少，所有外部能力被翻译进少数稳定内部对象。

**要解决的矛盾**：每多一种扩展来源，就多一套能力模型、权限模型和 UI 暴露方式，最终导致 special case 爆炸。收敛到统一对象后，UI、permission、query loop、task system 都不必为每种扩展源单独写适配逻辑。

**收益与代价**：内部收敛越到后期越像护城河——它是系统长期秩序的来源；代价是接入新扩展的前期翻译成本更高，本质是「用接入成本换长期秩序」。

该原则与 seanguo 的 [[skill-command-mcp三层架构]] 形成扩展能力组织方式的两种路线对照（收敛对象 vs 三层工具链）。
