# 测试用例生成

基于 AST 推导受影响 API 接口，结合大模型理解改动点后自动生成测试用例建议，是 [[code-insight|Code Insight]] 的三大落地场景之一。

## 工作流程

1. 代码变更检测
2. [[ast加符号表联合分析|AST+符号表]] 解析变更影响范围
3. [[调用关系图谱]] 推导受影响的 API 接口
4. 大模型理解改动点语义
5. 自动生成测试用例建议

## 核心优势

- 基于静态分析（AST）的影响范围推导，确保覆盖面
- 大模型理解改动语义，生成有针对性的测试用例
- 将"人判断影响范围→人写测试"升级为"AST 推导影响→AI 生成测试"

## 与其他测试方法论的关联

- 美团 [[human-in-the-loop测试sop]]：人工主导 AI 辅助的测试用例生成五步法
- 有赞方案更偏自动化推导，美团更强调人机协作
