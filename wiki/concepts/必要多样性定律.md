# 必要多样性定律

控制论定律 **"Only variety can destroy variety"**（只有多样性才能消灭多样性）在 Agent 领域的应用，由 [[韩春]] 引入：因 LLM 输出具有多样性，必然需要**另一个 LLM** 来监督其输出质量——这是 Multi-Agent 质检 Agent 存在的控制论根源。

## 概率×概率的本质

LLM 监督 LLM 本质是**概率×概率**：用冗余算力换取确定性，而非获得确定性本身。质检 Agent 自身也会出错，系统整体可靠性是两个概率的合成。

## 关联

- 为美团 [[高阶模型审查低阶模型]]（高配模型作 Judge 审查低阶编码）提供控制论解释——高配 Judge 正是"更多 variety 对抗 variety"。
- 与有赞 [[q-score质量评分机制]]、[[评分agent坏样本聚焦]] 构成"LLM 质检 LLM"的跨团队实践对照。
- 是 [[闭环负反馈控制]] 总定义中的"必要多样性工具"组件。
