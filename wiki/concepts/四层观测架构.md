# 四层观测架构

四层观测架构是《OpenClaw-Observability》一文提出的 Agent 可观测总体架构：**采集层 → 建模层 → 存储层 → 展示分析层**，是 [[全链路可观测体系]] 在 [[openclaw]] 上的具体实现骨架。

## 第一层：采集层

基于 [[openclaw]] 的 Hook 机制，在 5 类生命周期节点拦截：

1. 会话开始/消息进入
2. LLM 推理开始/结束
3. 工具调用前/后
4. 流式输出中的 thinking/assistant 事件
5. Run/子任务切换节点

## 第二层：建模层

抽象 Trace 核心字段，使数据能被组织成可理解的执行过程（而非仅"采到数据"）。字段定义见 [[Trace数据模型]]。

## 第三层：存储层

异步非阻塞写入 [[DuckDB]]，保证观测不拖慢主链路。机制见 [[异步非阻塞观测写入]]。

## 第四层：展示分析层

提供 Trace/分析/安全三类视图，开发者看到"完整、可解释、可下钻的执行时间线"而非散乱日志。详见 [[观测三视图]]。
