# 召回双风险论

召回双风险论出自《从 Vibe Coding 到范式编程》脚注[2]，是 F1-doc（方案召回质量）指标的设计理据：知识召回存在两类失败模式，**漏召**（假阴性，FN）——该召回的知识没被召回，导致模型「自由发挥」（凭通用知识即兴生成，偏离领域事实）；**误召**（假阳性，FP）——不该召回的内容被召回，污染生成结果。F1-doc 越高，表示「召全」与「召准」的平衡越优（Precision = TP/(TP+FP) 表征准确性，Recall = TP/(TP+FN) 表征完整性）。

## 与 Trade Spec 工程设计的对应

- 双路召回（KBase 语义检索=广度防漏召 + 索引导航式召回=精度防误召与信息过载）；
- 知识点机制（一句话形式+触发关键词，专收「向量检索难以准确召回」的高误解概念，绕开周边描述性文字造成的召回噪音）；
- 知识库配置区的「召回策略和优先级」配置（与有赞 [[知识优先级机制]] 呼应）。
