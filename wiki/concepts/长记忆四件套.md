# 长记忆四件套

小红书 [[小红书PMO团队]] 3.0 阶段设计并实现的 Agent 长记忆基础设施，解决 Workflow 模式下 Agent 每次对话"失忆"的根本问题。

## 四大组件

### 1. UserProfile（用户画像）
4 维用户画像，持续积累对用户的理解。

### 2. SessionMessage（三级对话缓存）
三级缓存架构：
- **DB 层**：持久化存储
- **应用层**：高频缓存
- **Agent 层**：实时上下文

### 3. KnowledgeItem（5 类知识库）
5 类知识库，支持全文搜索 + 标签搜索两种检索模式。

### 4. ContextBuilder（动态拼装 + 自动压缩）
动态拼装上下文窗口，自动压缩避免 Token 溢出。是四件套的编排核心。

## 与 Workflow 模式的对比

Workflow 模式下 Agent 每次对话都是"失忆"状态，根本无法实现长记忆。长记忆四件套通过持久化 + 分层缓存 + 动态拼装解决了这一问题。
