# 六步落地路径

[[zhiyuanfu]] 提出的 Agent 系统渐进式建设路径。核心原则：**先可复盘 → 再可重复 → 再可规模化 → 最后可有限自治**。

| 步骤 | 做什么 | 核心产出 |
|------|--------|----------|
| ① 写 spec | 需求规格化 | spec.md |
| ② 留痕 | 记录执行过程 | agent.log + prompts |
| ③ 补 observability+eval | 可观测+评估 | 六维度配置 + eval 四问 |
| ④ 高频动作沉淀 Skill | 固化可复用能力 | Skill 库 |
| ⑤ 引入调度并发 | 多任务并行 | 调度层 |
| ⑥ 最后才 Goal-Driven | 有限自治 | STATE.yaml + 约束体系 |

## 关键约束

别跳步。连任务执行不稳定、没有留痕、没有 Skill 沉淀的系统，不可能真的进入目标驱动。

## 与其他落地路径的关联

- 与 [[四步行动指南]]（美团：盘债→规范→打样→Pre-PR）结构相似——都是渐进式、先治理后扩展
- spec→留痕→eval→Skill 的顺序与 [[规格驱动ai开发]] 的核心理念一致
