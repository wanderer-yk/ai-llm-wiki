# 多 Agent 翻译框架

多 Agent 翻译框架是 [[货拉拉技术]] 团队为解决 [[Lalamove]] 海外开城翻译难题而提出的一套完整可靠的翻译流程架构。该框架通过多个专业 Agent 的分工协同，解决了传统人工翻译成本高、速度慢、质量难控的问题。

## 三层架构

框架采用三层设计：

| 层级 | 职责 |
|------|------|
| **应用层** | 负责业务侧的翻译请求接入和结果返回 |
| **核心层** | 基于 [[悟空平台]]，桥接各 Agent 的调度与协同 |
| **数据层** | 提供术语库、Few-shot 参照语料、上下文信息等数据支撑 |

## 三大核心 Agent

### 翻译 Agent（资深译员）

负责精准语言转换，组合使用三项关键技术：

- **术语库强约束**：锁定品牌/业务专有名词的统一翻译
- **[[多语种参照系few-shot]]**：利用同源语料其他语种人工翻译结果作为带权 Few-shot，锁死多义词语义
- **上下文注入**：匹配文本使用场景等业务信息，辅助推断 UI 文字真实意图

### 翻译质量评分 Agent（专业校对）

执行 [[双重自动评估打分机制]]，结合 COMET/BERTScore（语义相似度）与 BLEU（文本相似度）进行加权综合评估，拦截低分样本交由人工 [[译后编辑]]。

### 敏感信息识别 Agent（合规审查）

进行二次安全审查，区分通用安全扫描（暴力/色情/仇恨）与特定地区合规（政治/宗教/民族政策），防止 LLM 幻觉在敏感地带产生舆论风险。

## 核心设计理念

该框架体现了"翻译、评估、安全三位一体"的设计理念，通过 Agent 分工将翻译质量保障从纯人工模式升级为"人机结合"模式。同时，该框架不仅限于翻译场景，更沉淀为 [[垂直场景llm落地框架]]，具备向其他业务场景迁移的通用性。
