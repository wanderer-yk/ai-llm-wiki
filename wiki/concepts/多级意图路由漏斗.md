# 多级意图路由漏斗

多级意图路由漏斗是一种将大模型不确定性**严格限制在必要环节**的请求处理架构：请求经过逐级收窄的漏斗，大部分路径由轻量模型或规则逻辑保障，只有高价值任务才进入大模型处理。其本质是把「大模型参与」本身变成一种需要审批的稀缺资源分配。

漏斗层级（逐字保留）：

```
安全筛查（风险拦截）
  → 一级意图识别（闲聊 vs 任务型）
    → 多维细化（高价值任务）
      → 专用模块精准调度
```

## 与近义页的区分

- **[[意图路由]]**（问诊 Agent 场景）：那是排查问题的**单层两路分派**；本页是 AI 万能搜的**多级漏斗**（安全筛查→一级意图→…逐级收窄），且核心是"把大模型参与变成稀缺资源分配"——粒度与视角均不同，不可混用。

## 设计意图

- 安全筛查前置，风险请求不进入后续任何模型环节；
- 闲聊与任务型分流，避免大模型资源被低价值请求占用；
- 只对高价值任务做多维细化并调度专用模块（如跑马灯 agent、清单生成 Agent）；
- 与 [[预编排sop模式]] 配合：路由之后走固化 SOP，形成「轻量判断 + 受控执行」的完整链路。

## 与既有概念的关系

- 与 [[意图路由]]（智空间来源）主题重叠——是否合并为一页待裁决；
- 与 [[意图规划]]（马上消费：Query 改写→意图识别→意图挖掘）同为意图处理框架，但淘天版本显式引入「安全筛查」为第一级，且目标是控制不确定性而非纯理解准确率。
