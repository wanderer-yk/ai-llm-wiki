# 状态外置持久化

状态外置持久化是 Ralph Loop 支撑长时间运行的核心机制：将"状态管理"从 LLM 内存（token 序列）转移到硬盘（文件系统），把环境本身视为"累积记忆"。每轮循环视为全新会话，Agent 靠文件读取工具扫描项目结构与日志同步状态——这是 Ralph 能够支持数小时/数天持续开发的关键原因。

## 三大持久化组件

| 组件 | 职能 |
|---|---|
| progress.txt | 追加式日志；新实例先读以同步进度；顶部维护"代码库模式"区；记录坑与解法 |
| prd.json | 结构化任务清单；`passes: true` 标记完成（[[机器可验证完成条件]]）；中断后可恢复优先级 |
| Git 提交记录 | 回滚 + Diff 客观评估；`git log` 让智能体看到此前尝试路径、避免重复错误 |

## 四步读写循环（技巧 4）

读 progress.txt → 读 prd.json → 追加本次进度与模式 → 更新 passes。

最佳实践：代码库模式区置顶、单任务单迭代、即时更新状态、记录坑与解法。由此形成的"累积知识库"使后续迭代无需阅读整个 Git 历史即可快速同步。
