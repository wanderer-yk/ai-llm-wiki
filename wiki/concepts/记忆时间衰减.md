# 记忆时间衰减

记忆时间衰减是 [[openclaw]] 对每日笔记（`memory/日期.md`）的遗忘机制：检索相关性权重随时间按指数衰减，而非物理删除。公式与数值（原文）：

```
时间衰减公式：

  衰减系数 = e^(-λ × 天数)

  其中 λ = ln(2) / 半衰期天数（默认 30 天）
```

```
1天前的记忆：衰减系数 ≈ 0.977（几乎不变）
7天前的记忆：衰减系数 ≈ 0.851（轻微降低）
30天前的记忆：衰减系数 = 0.500（减半）
60天前的记忆：衰减系数 = 0.250（只剩1/4）
90天前的记忆：衰减系数 = 0.125（只剩1/8）
```

关键边界：衰减仅作用于检索相关性权重（影响 [[混合召回]] 中的排序），不删除文件；无自动删除、需人工清理；MEMORY.md 豁免衰减、永不衰减（"保持常青"）。 MEMORY.md 免衰减 + 每日笔记衰减的分层设计使重要事实越久越稳、琐事自然沉底，与 [[Evergreen免衰减]]（源自 [[sources/[202604151800]OpenClaw长期记忆优秀管线与玄学效果|[202604151800]]]）为同一机制的两次独立描述，构成字面级互证。
