# 反馈驱动迭代

反馈驱动迭代是 [[smallnest-autoresearch]] 的第三大改进：把每轮审核发现的反馈直接注入下一轮 Agent 的提示词，使其针对性改进上一轮的具体不足，而非漫无目的的重试。它是对 Ralph Wiggum 方法（见 [[ralph-wiggum方法]]）盲循环的直接替代——盲循环不知道上一轮哪里不好，反馈驱动循环明确知道。

## 反馈来源

1. **审核反馈**：交叉审核（[[多agent交叉审核]]）发现的不足，如 Issue #21 迭代 2"Claude 审核发现不足"、Issue #15 迭代 1"反馈：设计方向问题"→"反馈：改进实现细节"
2. **测试失败**：测试不通过时以"测试失败"为反馈进入下一轮修复
3. **评分差距**：低于 9.0 达标线的评分本身指示与目标的距离（见 [[5维度量化评分]]）

## 案例证据

Issue #15 的收敛轨迹 5.0 → 7.0 → 9.1 配有逐轮反馈注释，是"反馈注入下一轮"的直接日志证据；Issue #21 从 1.0（功能完全未实现）到 9.0 的收敛同样伴随审核反馈。

## 学术与工程脉络

该机制与 [[reflection模式]] 的学术脉络（Reflexion / Self-Refine / CRITIC）同构——均以对上轮输出的结构化批评驱动改进；本文贡献在于将其嵌入双 Agent 轮换调度，使"反思者"与"执行者"由不同模型交替担任。
