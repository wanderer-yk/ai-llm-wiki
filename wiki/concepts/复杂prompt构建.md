# 复杂prompt构建

**复杂prompt构建**是天猫新品营销技术团队提出的一项 prompt 工程技巧：当场景功能过于复杂、人工难以直接描述清楚具体 prompt 时，转而让 AI 理解你的朴素诉求，并根据诉求去生成 prompt，[[sources/[202605081607]天猫新品团队AI编码实战指南下|来源]]。原文方法表述（逐字）："场景功能就很复杂，比较难描述清楚其具体的 prompt。所以可以让 AI 理解你的朴素诉求，并根据诉求去生成 prompt。"图注概括为"让 AI 去操作 AI，开发者只思考需求是什么"。

## 示例案例：neko 智能参数调试面板

复杂 prompt 构建的示范案例为【neko 智能参数调试面板功能】，其六项诉求（原文保留）：

1. 理解 http get/post 参数/正文字段格式；
2. 分析字段业务/技术语义并精准划分；
3. 基于字段重构表单面板（原生 js、无前端构建过程）；
4. 表单以 iframe 加载并与外部参数/正文保持同步；
5. 基于 postMessage 实现内外双向实时联动；
6. "同步过程是非常频繁的，需要保持双方原本格式。"

此类多约束、多技术点的复合需求正是"人工写不清 prompt"的典型场景，最终由 AI 生成"多功能复杂 prompt"（配图 imgfileid 503059738）。
