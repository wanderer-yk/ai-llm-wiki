# 长期记忆六大核心组件

长期记忆六大核心组件是支撑 Agent 长期记忆系统的标准组件分解：LLM、Embedder、VectorStore、GraphStore、Reranker、SQLite。该分解出自《AI Agent 记忆系统》（柳遵飞（翼严）），描述了跨会话持久化记忆所需的完整技术栈，也是 [[mem0]]、[[reme]] 等长期记忆产品的内部架构参照。

## 六组件及职责（原文表格）

| # | 组件 | 职责 |
|---|------|------|
| 1 | LLM 大模型 | 提取短期记忆中的有效信息（语义理解、抽取、决策、生成） |
| 2 | Embedder 向量化 | 文本转语义向量，支持相似性计算 |
| 3 | VectorStore 向量数据库 | 持久化存储记忆向量和元数据，支持高效语义检索 |
| 4 | GraphStore 图数据库 | 存储实体-关系知识图谱，支持复杂关系推理 |
| 5 | Reranker 重排序器 | 对初步检索结果按语义相关性重新排序 |
| 6 | SQLite | 记录所有记忆操作的审计日志，支持版本回溯 |

## 在两条流水线中的位置

- **Record 流水线**：LLM 事实提取 → Embedder 向量化 → VectorStore 存储 →（GraphStore 复杂关系存储）→ SQLite 操作日志；
- **Retrieve 流水线**：query 向量化 → VectorStore 语义检索 → GraphStore 关系补充 → Reranker 重排 → 结果返回。

SQLite 作为审计日志/版本回溯组件是值得注意的设计：它不是记忆内容本身，而是记忆系统的**操作留痕层**。
