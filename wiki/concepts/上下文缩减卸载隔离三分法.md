# 上下文缩减/卸载/隔离三分法

上下文缩减（Context Reduction）、上下文卸载（Context Offloading）、上下文隔离（Context Isolation）是处理 Agent 短期记忆上下文的三大核心策略，出自《AI Agent 记忆系统》（柳遵飞（翼严））第三章。三分法回答的是同一问题——上下文受 maxToken 限制时如何取舍——但给出了三条信息代价不同的路径。

## 一、上下文缩减（Context Reduction）

减少上下文信息量以降低 token 消耗，含两种方法：

- **保留预览内容**：仅保留前 N 字符或关键片段；
- **总结摘要**：LLM 生成摘要替代原文。

两种方法均**有信息丢失**，但有效降低 token 成本。

## 二、上下文卸载（Context Offloading）

解决缩减策略的信息可恢复性问题：将完整内容卸载到文件系统/数据库等外部存储，消息中仅保留最小引用（文件路径、UUID），需要时重载。适用于网页搜索结果、超长工具输出、临时计划。以最小引用换取**信息零丢失与随取随用**。

## 三、上下文隔离（Context Isolation）

借助多智能体架构拆分上下文（类比"单体架构拆微服务"）：子智能体的整个上下文仅由主智能体的任务指令组成，主智能体只取回结果。适用于指令清晰简短、只关心最终输出的任务（如代码库片段搜索）。

## 策略选择三因素

1. **时间远近**：近期消息优先保留；
2. **数据类型**：用户输入、模型回复、工具结果的重要性不同；
3. **信息可恢复性**：需完整保留 → 卸载；可丢失 → 缩减。
