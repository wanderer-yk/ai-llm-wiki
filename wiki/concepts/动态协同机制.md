# 动态协同机制

**动态协同机制**是 [[牛潇]] 对未来 AI 系统中 [[agent-skills]] 与 [[mcp]] 关系的终极预测。

## 核心理念

智能体根据**任务复杂度**自动选择使用 Skills（配置驱动）或 MCP（代码驱动），运行时动态平衡两者：

- **简单任务** → 自动使用 MCP 原子操作直接执行
- **复杂业务流程** → 自动激活 Skills 编排多个 MCP 工具
- **高度不确定性场景** → 动态调整 Skills 规则或回退到 MCP 原子操作

## 技术挑战

这一机制的实现需要解决"任务复杂度评估"问题——智能体如何量化评估任务复杂度以决定调用机制，目前仍是一个黑盒。

## 与 Wiki 既有概念的关系

- [[经典协同模式三式]] 模式3（MCP 增强型技能）是动态协同的雏形——通过数据分析推荐最优工作流
- [[数据自迭代]] 的闭环学习机制是动态协同的数据基础
- [[自动化决策层级]] 的"优先使用确定性最低成本层级"理念是动态协同的决策逻辑

## 开放问题

- 智能体如何量化评估"任务复杂度"以决定调用机制
- 动态平衡配置驱动与代码驱动的切换边界如何定义
- 统一开发框架和低代码平台的具体落地形态尚未明确
