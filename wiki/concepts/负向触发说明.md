# 负向触发说明

防止 Skill 过度触发（over-triggering）的 Description 编写技巧：当 Skill 在不相关场景频繁被加载时，在 Description 中加入**排除性说明**——"不要用于 X（那个用某 skill）"，为 Agent 指明更合适的替代。

来源示例（逐字保留）：

```makefile
description: >
  CSV 文件的高级数据分析，包括统计建模、回归分析、聚类。
  不要用于简单的数据浏览（那个用 data-viz skill）。
```

在触发评测迭代决策表中的位置：误触发居多时的调整方向即"增加负向说明（'不要用于…'），收窄适用范围"（见 [[skill触发评测方法]]）。与 [[description三大要素]] 的三问互补：三问定义"何时用"，负向说明定义"何时不用"。
