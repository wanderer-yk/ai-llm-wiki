# 双路检索上下文

双路检索上下文是 [[货拉拉]]基于 [[lightrag]] 的 GraphRAG 方案2.0 中的核心检索设计，通过将用户查询分解为高低级关键词，分别走 Local 和 Global 两条检索路径，最终合并输入 LLM 生成回答。

## 检索流程

```
用户 Query
    ↓
LLM 提取关键词
    ├── 低级关键词（具体实体名）→ Local Query Context
    │       ↓
    │   同义词扩展 → 混合检索（向量+BM25+标量）+ 图关系
    │
    └── 高级关键词（概念性词汇）→ Global Query Context
            ↓
        Embedding → 图实体检索
    ↓
合并上下文 → LLM 生成
```

## Local Query Context

处理**低级关键词**——即具体的实体名称（如表名、字段名）。路径为：

1. 同义词扩展：通过 [[graphrag三类实体设计|同义词层]]将查询术语扩展为同义表达
2. 混合检索：向量检索+BM25 全文检索+标量检索三路融合
3. 图关系补充：基于图索引获取相关实体的关系信息

Local 路径主要解决 [[badcase五分类|Badcase类型1（语义不匹配）]]和[[badcase五分类|类型2（多实体召回低）]]问题。

## Global Query Context

处理**高级关键词**——即概念性词汇或抽象描述。路径为：

1. Embedding：将关键词转换为向量表示
2. 图实体检索：基于 Embedding 在图索引中检索语义相关的实体

Global 路径主要解决用户使用模糊/概念性描述时的语义关联问题。

## 设计动机

双路检索的核心设计动机：单一检索路径无法同时满足精确召回（具体实体名匹配）和语义关联（概念性描述匹配）两种需求。低级关键词走 Local Context 解决精确召回；高级关键词走 Global Context 解决语义关联，两路合并后输入 LLM 综合判断。

## 与混合检索的关系

Local Query Context 路径中使用了[[混合检索]]策略——向量检索、BM25 全文检索、标量检索三路融合。双路检索上下文是在混合检索之上增加了 Global 维度的语义图检索能力。
