# 四阶段两检查点流水线

web-video-presentation 将"从一篇文章到视频"切成四个阶段、卡两个人工检查点的执行编排（检查点处 Agent 被强制停下）：

1. **阶段一 内容编写**：AI 同时产出口播稿（script.md）与开发大纲（outline.md）；
2. **检查点 Plan**：人一次性拍板五件事（见 [[Plan检查点五项对齐]]）；
3. **阶段二 开发**：首章必须经人验收成为基准（首章暴露页面密度、字体大小、动效节奏、信息呈现方式），后续章节按 [[开发模式三档]] 顺序或并行推进；
4. **检查点 Audio**：人决定合成 TTS 音频还是自己人声录；
5. **阶段三 音频合成**：MiniMax CLI TTS 两步批量合成（清单人眼校对→串行逐条），断点续跑；
6. **阶段四 录屏**：浏览器全屏 + 自动播放（[[三种播放模式]]），音画天然对齐，录完裁头尾。

## 定位

该流水线是 [[视频网页四步关键流程]]（内容方法层）的 Skill 工程化落地版（执行编排层），两者共同构成"网页即视频"方案的完整实现。
