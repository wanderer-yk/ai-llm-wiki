# 场景生成（Scenario-based Testset Generation）

场景生成是 Ragas（[[ragas]]）测试集生成管线中位于知识图谱构建之后的环节：知识图谱构建完成后「可以使用他来构造任何类型的问题」，但真实用户的查询表达因人而异——「取决于他们的人设、查询长度以及查询风格」——因此 Ragas 采用基于场景（Scenario-based）的方法，每个「场景」是一个四参数组合，用于使生成的问题覆盖真实用户的查询分布，而非仅覆盖理想化的提问方式。

## 场景四参数

| 参数 | 取值示例 |
|------|---------|
| 节点 | KG 中有关系的内容节点 |
| 查询长度 | 短、中、长等 |
| 查询风格 | Web search、Chat 等 |
| 人设（Persona） | 高级工程师、初级工程师等 |

四参数组合是「查询空间的双正交维度（跳数×抽象度，见 [[ragas查询类型分类]]）」之外的第二层条件化——它控制的是**表达分布**，而非**推理结构**。长度/风格/人设的条件化能力是 Ragas 区别于其他合成问题手段（[[doc2query]]、Answer Relevancy 反向出题、[[多查询生成]]）的独有查询分布覆盖能力。

## 实操入口

「可通过内置的 Query Synthesizer 或自定义来完成场景生成以及评测集的产出」：`_generate_scenarios` 为每道题分配节点素材并贴风格/人设标签，是四参数在 API 层的落地；调度与 LLM 生成的分离见 [[场景采样两阶段解耦]]。
