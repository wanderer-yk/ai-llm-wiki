# A 动作与 C 动作失衡论

[[书牧]]（[[天猫技术]]）提出的诊断：在 [[信息传递链路模型]] 中：

- **A 动作**（任务目标输入）缺少体系化方法论
- **C 动作**（AI 任务执行）获得行业绝大多数关注（基模迭代、Agent 感知/规划/记忆/工具）

这种失衡导致 [[任务传达瓶颈论]]——企业级研发 AI Coding 后半段（代码执行）已无大瓶颈，真正瓶颈在前半段（任务目标准确传达）。

解决路径是 [[系统性降熵]]：将专家知识提前结构化外化为知识库（D 动作），降低 A 动作环节的信息熵。
