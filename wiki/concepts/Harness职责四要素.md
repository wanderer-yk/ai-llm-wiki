# Harness 职责四要素

本文对 Harness 职责的概括定义："**划定边界、管理状态、设立检查点、在关键节点拦住错误**。"

## 无 Harness 的失败模式（动机证据）

直接下指令让 Agent 做视频时的三种失败模式：

1. 稿子与画面对不上；
2. 章节数与音频数不一致；
3. 后期章节风格漂移。

模型的失败不是能力问题，而是"每次都做得出来、不同人/文章/主题稳定产出、效率不靠运气"的稳定性问题——这正是四要素要解决的。

## 与既有概念的同构性

- 与爱奇艺 [[harness-engineering]] 五要素（任务入口、执行依据、工具边界、验证反馈、结果记录）高度同构：划定边界↔工具边界、管理状态↔结果记录、设立检查点+拦住错误↔验证反馈。
- 向下展开为 [[Harness六大核心部分]]（六核心表格）；向上收敛为 [[Harness核心价值三元组织论]]（全文最终定义句）。
- Skill 级落地实例：Plan 检查点五项对齐、章节自检硬门控。
