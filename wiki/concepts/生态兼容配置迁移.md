# 生态兼容配置迁移

生态兼容配置迁移是 [[hermes-agent]] 的迁移友好性设计：直接兼容读取三大生态的既有配置文件，使从 OpenClaw 或 AI Coding 工具迁移到 Hermes 的成本极低。

## 三层兼容清单（原样保留）

1. **OpenClaw 生态**：`AGENT.md`、`SOUL.md`、`USER.md`
2. **AI Coding 主流规范**：`CLAUDE.md`（[[claude-code]]）、`.cursorrules`（[[cursor]]）、`.cursor/rules/*.mdc`
3. **多平台 IM 协议**：WhatsApp、Slack 适配提示词

## 意义

- 降低用户切换 Agent 平台的锁定成本，与 Hermes“官方支持从 [[openclaw]] 无缝迁移”的产品策略一致；
- 使既有 AI Coding 规范资产（个人/团队的 CLAUDE.md 体系）无需重写即可复用；
- IM 协议层兼容则延续了 OpenClaw 式的“部署在服务器上、通过消息平台交互”的使用形态。
