# 多通道记忆统一管理

多通道记忆统一管理是 [[RDSClaw]] 插件开箱即用特性之一：钉钉、飞书、企业微信三个 IM 渠道的跨群对话记忆统一归集到同一记忆库，消除渠道割裂——用户在不同 IM 中与 Agent 的交互沉淀为同一份长期记忆。

## 工程意义

IM 场景下同一用户可能在多个平台、多个群与同一 Agent 交互；若各渠道记忆割裂，Agent 在任一渠道都无法形成完整用户画像。统一归集是记忆管线在多渠道场景的前置条件，也放大了 [[双提取器分流]] 与 [[Evergreen免衰减]] 的价值。

## 跨来源对照

IM 渠道接入 Agent ↔ [[imclaw]]（花叔）：IM 作为 Agent 入口的思路呼应（弱关联）。
