# 配置优先级链

## 定义

配置优先级链是 [[mcp-server-ts]] 框架中用于管理多来源配置覆盖关系的机制，通过环境变量驱动配置（`MCP_BASE_PATH` / `MCP_HOST` / `MCP_PORT` / `MCP_DOMAIN`），使框架适用于生产环境。

## 端口优先级

端口配置遵循三级优先级链：

**环境变量 > 命令行参数 > 默认值**

例如：`MCP_PORT=3001` 环境变量优先于 `npm run start -- -p 3002` 命令行参数，命令行参数优先于默认端口 3001。

## 访问地址优先级

访问地址配置遵循三级优先级链：

**`MCP_DOMAIN` > `MCP_HOST` > localhost**

- `MCP_DOMAIN=mcp-server.internal.com`：域名优先级最高，适用于生产环境。
- `MCP_HOST=192.168.1.100`：IP 地址次之。
- localhost：默认值，适用于本地开发。

## 设计意图

通过分层优先级机制，开发者无需修改代码即可在不同环境（本地开发 / 测试 / 生产）间切换配置，与 [[模块化业务隔离]] 的设计哲学一致——将环境配置与业务逻辑解耦。
