# 分层统一知识库

[[书牧]]（[[天猫技术]]）主张构建的专家知识管理架构：分层、统一、可自治更新的专家知识库，覆盖基础技术、业务架构、团队规范、代码仓库等维度。

## 核心特征

1. **分层**：按 [[专家知识四层模型完整版]] 系统化分层
2. **统一**：[[专家知识统一管理论]]——独立于各 AI Agent 体系，全局视野、跨团队复用
3. **可自治更新**：[[知识自治论]]——自动化+人工确认的半自动保鲜

## 带来的优势

[[双一致性优势论]]：全局架构理解的一致性 + 规范执行的一致性，有望解决大型复杂系统跨角色/团队协同效率低下问题。

## 与既有方案的对话

与 [[knowledge-wiki]]（有赞共享技术，`.wiki/` + Git submodule 分布式架构）存在架构路线分歧——天猫主张知识独立于 Agent 体系，有赞以 Git submodule 跟随代码仓库。与 [[code-insight]]（有赞，绑定代码搜索）也存在路线差异。
