# 提示词爆炸

提示词爆炸是问诊 Agent“进阶模式”（提示词内嵌 SOP）暴露的系统性反模式：当多个技能的 SOP 全部内嵌进单一提示词后，提示词随技能数线性膨胀，引发连锁劣化。它是 [[agent构建演进三阶段]] 从“提示词内嵌”走向 [[sop-doc可召回排查文档]] 的直接动因。

## 症状链（原文归纳）

1. 提示词膨胀；
2. 上下文混乱；
3. 指令跟随能力下降；
4. 运行稳定性差；
5. 可维护性差。

## 解法

SOP Doc 范式将技能描述从提示词中拆出、下沉为独立可召回文档，实现按需加载；提示词本身收敛为 [[手册执行者模式]] 的执行规范（四硬约束 + 工作流 + 回答格式），与具体技能解耦。

## 概念族定位

与 [[prompt极简主义]]（OpenClaw）、[[openclaw上下文压缩流水线]]、[[skill功能聚合]] 同属“控制提示词/上下文体积”概念族；本概念的独特贡献是从**生产事故视角**（稳定性、可维护性）而非纯 token 成本视角论证拆分的必要性。
