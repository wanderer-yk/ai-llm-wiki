# AI 原生协作流程

有赞共享技术团队在 AI 客服建设中总结的跨职能协作模式，针对 [[ai项目协作三大特征]] 提出的系统性解决方案。

## 背景：AI 项目协作的特殊挑战

AI 项目中 Prompt/Context/业务逻辑高度耦合，传统的"产品定义需求→研发实现→测试验收"瀑布式协作模式失效。

## 流程要素

### 1. Prompt 评审机制

- Prompt 不再是研发的"黑盒"，而是需要跨职能评审的公开产物
- 产品、研发、测试共同参与 Prompt 设计和优化

### 2. 评估指标对齐

- 团队统一评估标准，避免对"好回答"的认知差异
- 基于 [[agent评测四要素]] 建立共享评测体系

### 3. 产研共同迭代

- 协作从传统的"交付接口"变为"共同迭代 Prompt+逻辑+数据"
- 产品把控业务逻辑和效果反馈，研发把控技术实现和性能

### 4. 文档化决策过程

- 记录 Prompt 变更原因、评测结果对比、知识库更新记录
- 为后续迭代提供可追溯的决策依据

## 角色分工

| 角色 | 主要职责 |
|------|----------|
| 产品 | 把控指标、效果反馈、业务逻辑 |
| 研发 | 技术实现、性能优化、系统架构 |
| 测试 | 评测基础建设、用例集维护 |
