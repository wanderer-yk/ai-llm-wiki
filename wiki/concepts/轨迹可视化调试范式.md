# 轨迹可视化调试范式

轨迹可视化调试范式指 AI 系统调试方式从传统「日志回溯」升级为「轨迹可视化」：**AI 系统的错误多源于上下文缺失或工具调用顺序不当，而非代码逻辑错误**——因此调试的关键不是看代码哪里写错，而是完整回放 Agent 的决策轨迹，逐层下钻分析「为何此处幻觉」「哪个 Tool 返回异常」。

淘天集团搜索团队为此自研 Trace 工具，全链路记录七环节（逐字保留）：

```
用户输入 → 意图识别 → 上下文组装 → Agent决策 → Tool调用 → 模型生成 → 后处理
```

七个环节任意一处都可能是错误的根因：上下文组装遗漏导致幻觉、意图识别偏差导致路由错误、Tool 调用顺序不当导致数据异常——这些均无法通过传统代码调试手段定位。
