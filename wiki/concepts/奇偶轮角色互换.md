# 奇偶轮角色互换

奇偶轮角色互换是 [[smallnest-autoresearch]] 中 [[多agent交叉审核]] 的具体调度机制：核心迭代循环里奇数轮由 Codex 先审后实现、偶数轮由 Claude 先审后实现，通过交换双方进入顺序消除固定先后带来的位置偏差。角色差异由 agents/ 目录下的角色文件固化，并预留 gemini.md 扩展位（是否实际启用未明）。

## 角色文件分工（原文保留）

```bash
├── agents/
│   ├── codex.md            # Codex 角色：实现者指令 + 代码规范 + 自检清单
│   ├── claude.md           # Claude 角色：审核者指令 + 评分标准 + 问题模板
│   └── gemini.md           # Gemini 角色：实现者指令（扩展 Agent）
```

## 调度规则（原文）

```text
奇数轮: Codex 审核 → Codex 实现 → 测试 → Claude 审核 → Claude 实现
偶数轮: Claude 审核 → Claude 实现 → 测试 → Codex 审核 → Codex 实现
```

## 实战证据与遗留矛盾

- **Issue #15 显式注释**（`feat: define source-of-truth event protocol`）首次给出互换细则："奇数轮 Codex 实现 + Claude 审核，Claude 补充实现 + Codex 审核"，并出现 Claude 作为实现者的实例——部分解释了 4.3 节迭代示例为何未体现互换。
- **轮次计数矛盾**：Issue #15 日志出现两个"迭代 1"条目（Codex 5.0、Claude 7.0）后接"迭代 2"，却声称"共 2 轮"；轮次编号与条目计数不一致，"一轮"是否包含双 Agent 的实现+审核子步骤尚无明确定义。
- **评分执行者疑点**：示例中分数均出现在"Claude 审核"之后，但按规则偶数轮应由 Codex 审核——谁在什么轮次打分未明。

## 关联

- 角色文件 + 顺序互换是 [[ai自审偏差]]（单 Agent 自审盲区）与 [[多agent角色思维隔离]]（角色 prompt 内生审计）的调度级实例，与 [[高阶模型审查低阶模型]]、[[双轨校验]] 同属跨模型质量保证谱系。
- 作者以"ClaudeCode/Codex 自己足够智能决定回退还是改进上一轮的变动"为由不设回退机制，与 revert 硬保护的张力见 [[硬性保护与软性保护]]。
