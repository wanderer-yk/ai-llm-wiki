# 评测集优先于知识库

小红书 [[小红书PMO团队]] 1.0 阶段的核心认知。

## 核心论点

评测集是 Agent 的"单元测试"，10+ 代表性 Case 的评测集比知识库本身更有价值。

## 推理逻辑

1. 知识库可以不断扩充，但不知道 Agent 真正能回答好哪些问题
2. 评测集定义了 Agent 真实能力边界
3. 有了评测集，每次优化都有客观衡量标准
4. 评测集驱动知识库的定向补充，而非盲目堆量

## 实践证据

1.0 阶段通过 10+ 代表性 Case 评测集验证了 AI 项目顾问的能力边界，支撑了生产落地决策。

## 跨领域关联

- 与美团 [[agent评测系统]] 的评测思路形成方法论呼应——两家团队独立强调了评测在 Agent 开发中的基础性地位
- 与 [[数据自迭代]] 中 AI 质检闭环有互补关系——评测集管能力边界，质检管线管日常质量
