# 工具结果上下文守卫

工具结果上下文守卫（Tool Result Context Guard）是 [[openclaw]] 对单条工具结果体积与工具结果总预算的双重限制机制，实现位于 `src/agents/pi-embedded-runner/tool-result-context-guard.ts`。它与剪枝机制互补：守卫在工具结果进入上下文时限制其占比，剪枝（[[openclaw上下文剪枝]]）在结果过期后清理。来源：[[sources/[202603190830]深入理解OpenClaw技术架构与实现原理上|深入理解OpenClaw技术架构与实现原理（上）]] 3.6.5 节。

## 双预算常量与公式（verbatim）

```javascript
SINGLE_TOOL_RESULT_CONTEXT_SHARE = 0.5   // 单条最多占上下文 50%
TOOL_RESULT_CHARS_PER_TOKEN_ESTIMATE = 2 // 更保守的估算

// 1. 每条工具结果限制
maxSingleToolResultChars = contextWindowTokens * 2 * 0.5

// 2. 总上下文预算 (75% headroom)
contextBudgetChars = contextWindowTokens * 4 * 0.75

// 3. 超预算时压缩最旧的工具结果
//    替换为 "[compacted: tool output removed to free context]"
```

## 行为要点

- 单条工具结果上限：上下文窗口的 50%
- 总预算：上下文窗口的 75%（headroom 预留 25%）
- 超预算时**压缩最旧的工具结果**，替换为占位符 `"[compacted: tool output removed to free context]"`

## 已知张力（待核证）

**字符/token 估算不一致**：单条上限用 `TOOL_RESULT_CHARS_PER_TOKEN_ESTIMATE = 2`（即每 token 2 字符），总预算却乘以 4（隐含每 token 4 字符）。源文未解释差异，疑为分层估算（对单条用保守估算、对总量用常规估算）或笔误，待官方源码核证。
