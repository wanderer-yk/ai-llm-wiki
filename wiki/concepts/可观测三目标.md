# 可观测三目标

"看得见、说得清、改得动"是《OpenClaw-Observability》一文为 Agent 可观测插件确立的三项价值目标，构成 [[全链路可观测体系]] 的价值主张框架。

## 看得见

还原完整执行链（原文链路）：

```
用户输入 → 意图理解 → Prompt 组装 → 模型推理 → 工具调用 → 外部结果返回 → 二次生成 → 最终输出
```

## 说得清

从"体感定位"转向"证据定论"。四类归因问题：

1. 模型选错工具
2. 工具返回格式异常
3. Prompt 约束触发静默策略
4. 上下文截断丢失关键信息

其中第 3 类的典型实证即 [[静默决策显性化]]（Done 案例）。

## 改得动

将调用频率、失败率、延迟、Token 消耗、异常模式等数据沉淀为优化依据。

## 开放问题

"改得动"一节仅为原则性声明，观测数据是否实际回流为评测集或优化迭代未展开（与 [[评测集优先于知识库]] 的呼应待证）。
