# 真实世界负反馈

[[韩春]] 提出的第三条路：负反馈的监测对象从 LLM 输出转向 **Agent 对物理世界的真实影响**，使反馈信号首次跳脱 LLM 语义空间（突破 [[observation语义空间受限]]）。

**原文案例**：自然语言意图 → 网络设备配置变更，Observation = **真实流量**；真实流量异常即驱动变更终止与回滚。

## 与本 wiki 生产落地谱系的关系

- 与 vivo 丁俊杰 [[验证门禁化]]（未通过验证/审批/沙盘均不能执行）、[[agent生产落地四层框架]]（回滚层）同构：真实流量即门禁信号；
- 与 [[agent-canvas沙盘机制]] 互补：沙盘提供执行前的推演空间，真实世界负反馈提供执行后的终止机制；
- 与 [[业务diff等价物]] 呼应：真实流量监测是业务世界"变更可感知"的一种实现。
- 三方独立收敛于同一判断：Agent 生产落地的保障不在模型侧，而在环境/反馈侧。
