# 内外双路径自进化

内外双路径自进化是 [[hermes-agent]] 实现“自进化”的核心架构论断：以自动 Skill 生成（外路径：快速、轻量、即时生效，见 [[动态skill生成]]）与手动触发的 RL 训练（内路径：深度、根本改变模型权重）双轮驱动，构成完整的自进化闭环。

## 自进化数据链路（总纲）

**任务执行 → 经验记录 → Skill 抽象 → 模型再训练**——由 Skill 动态沉淀 + RL 闭环训练打通。

## 问题动机

来源文章指出传统 Agent 范式的痛点：“每一次任务执行往往都是从零开始的探索，过往的弯路、纠错过程以及人工干预的经验，大多随着会话结束而消散”。这与其他 Wiki 页面记录的经验沉淀问题（[[知识复利效应]]、[[长记忆四件套]]）属于同一问题族，但 Hermes 的解法不止于记忆，而是延伸到模型权重层面。

## 双路径的功能定位

- **Skill 机制**：解决“即时纠错” + “沉淀复用”（外、轻量、即时生效）。
- **RL 闭环**：实现“智能提升”（内、深度、改权重），见 [[research-ready训练闭环]]、[[grpo算法]]。

## 概念区分

外路径与内路径的差异即 [[外挂式进化vs权重内化]]：Skill 沉淀相当于“记笔记”（可解释、可人工纠偏，但权重不变），RL 相当于“练内功”。作者据此判断 Skill 外挂式进化“并不是真正意义上的自进化”，Context Engineering 优化存在天花板。

## 术语张力（需注意）

来源文章 chunk 5 曾表述“通过强化学习中的奖励机制（Reward Model）达到领域局部最优”，而后文介绍 [[grpo算法]] 时明确“不需要单独训练一个奖励模型（Reward Model），直接用规则化的奖励函数”。可调和（奖励函数≠习得的 Reward Model，前者属措辞混用），引用时需区分。

## 关联

与 [[skill-for-skill元技能自举]]、[[自举式开发]]、[[反馈驱动迭代]] 构成“Agent 自我改进”主题的不同深度层次：前两者停留在 Skill/流程层，Hermes 的双路径首次补齐“模型再训练”环节。RL 环节的意义另见 [[rl知识蒸馏降本论]] 与 [[用户数据不直接训练论]]（澄清“自动用用户数据训练”的营销号误传）。
