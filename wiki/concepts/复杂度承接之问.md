# 复杂度承接之问

复杂度承接之问是《Claude Code 源码拆解》收束全文的终极之问（verbatim）：「当模型开始真的做事，系统准备在哪里把这些复杂度接住。」它是贯穿启动、REPL、Query Loop、Tool Runtime、Permission、Task、扩展层各章的统一问题——每一层架构的存在理由，都是承接某一种真实复杂度。

文章给出的三级回答：

- **架构级**：[[三主干链路]]——控制链接住「怎么想、怎么续跑」，执行链接住「怎么动、怎么受约束」，任务链接住「怎么并发、怎么持续、怎么回流」
- **原则级**：[[复杂度安放位置论]] 与 [[每种复杂度只在一个地方爆炸]]、[[五条带走结论]]
- **组织级**：[[组织接入交付链路论]]——把承接问题从系统内部扩展到组织交付链路
