# AI 狼人杀

## 简介

AI 狼人杀是基于 LLM 驱动的多智能体狼人杀游戏，支持人类玩家与 AI 角色混合对局。该项目使用 [[agentscope|AgentScope]] Java 框架开发，是展示多智能体协作、信息隔离、结构化决策等技术的典型场景。

## 游戏规则

### 角色配置

- **狼人** — 夜间选择击杀目标，白天伪装身份
- **预言家** — 夜间查验一名玩家的身份
- **女巫** — 拥有解药（救人）和毒药（杀人）
- **猎人** — 死亡时可带走一名玩家
- **村民** — 通过逻辑推理投票放逐狼人

### 游戏流程

1. **夜晚阶段** — 狼人讨论并选择击杀目标 → 神职角色依次使用技能
2. **白天讨论** — 所有存活玩家轮流发言
3. **投票放逐** — 投票选出最可疑的玩家
4. **胜负判定** — 狼人数量≥好人则狼人胜；狼人全灭则好人胜

## AI 策略设计

### 狼人策略

- **悍跳狼** — 冒充预言家，给出虚假查验信息，引导投票方向
- **深水狼** — 伪装普通村民，发言精简避免成为焦点

### 设计原则

不同角色的 Prompt 差异显著：狼人需学会撒谎配合，神职需懂得使用技能，村民需分析逻辑。AI 通过 [[agentscope|ReActAgent]] 基于 ReAct 范式持续思考和对话。

## 技术架构

### 消息流转

- **讨论阶段**: `call()` 主动发言 → [[agentscope|MsgHub]] 自动广播 → 其他玩家 `observe()` 被动接收写入 Memory
- **投票阶段**: 关闭自动广播 → 逐个 `call()` 收集投票 → `broadcast()` 统一公布（防跟票）
- **夜间行动**: 创建专属 MsgHub 实例实现信息隔离

### 人机交互

- 玩家可选择任意角色（预言家、狼人或随机）加入
- 通过 [[human-in-the-loop|Human in the Loop]] 机制无缝参与
- SSE 实时推送支持玩家视角（角色过滤）和上帝视角（赛后复盘）
