# 声明式事实记忆

声明式事实记忆是 [[hermes-agent]] 通过 `MEMORY_GUIDANCE` 提示词（`agent/prompt_builder.py:144-162`）确立的记忆书写规范：记忆应写成**声明式事实**（descriptive facts），而非对自己的**命令式指令**（instructions to yourself）。文章给出的记忆价值判断标准是："最值钱的记忆，是能减少未来用户干预（reduces future user steering）的那条"——即防止用户再次纠正或提醒的记忆。

## 源码证据

```python
# agent/prompt_builder.py:144-162
MEMORY_GUIDANCE = (
    "You have persistent memory across sessions. Save durable facts using the memory "
    "tool: user preferences, environment details, tool quirks, and stable conventions.\n"
    "Prioritize what reduces future user steering — the most valuable memory is one "
    "that prevents the user from having to correct or remind you again.\n"
    "Write memories as declarative facts, not instructions to yourself. "
    "'User prefers concise responses' ✓ — 'Always respond concisely' ✗. "
    "'Project uses pytest with xdist' ✓ — 'Run tests with pytest -n 4' ✗."
)
```

## 正反例

- ✓ `User prefers concise responses`（用户偏好简短回复——事实）
- ✗ `Always respond concisely`（总是简短回复——指令）
- ✓ `Project uses pytest with xdist`（项目用 pytest 带 xdist——事实）
- ✗ `Run tests with pytest -n 4`（用 pytest -n 4 跑测试——指令）

指令式的"怎么做"应归入 Skill 层（见 [[memory与skill职责边界]]）。
