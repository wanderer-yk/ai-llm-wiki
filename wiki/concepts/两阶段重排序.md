# 两阶段重排序

两阶段重排序是 [[deep-research|Deep Research]] 中针对海量 URL 导致 LLM "瞎选"问题的解决方案，将 URL 清洗分为粗排和精排两个阶段。

## 第一阶段：粗排

粗排追求**召回率**（Recall），快速从海量 URL 中筛选出候选集。该阶段基于[[多维综合评分机制]]的六维度信号进行快速打分，处理单次步骤产生的几百个文本块只需在内存中计算余弦相似度即可，无需使用向量数据库。

## 第二阶段：精排

精排对粗排结果进行**深度评估**，优化 Top-K 结果。该阶段基于重排模型（如 [[jina-reranker-v2-base-multilingual]]）或 LLM 滑动窗口算法，深度评估问题与 URL 文本信息之间的语义相关性。

## 设计理念

两阶段设计平衡了效率与质量：粗排保证不遗漏重要信息，精排确保交付给后续流程的 URL 具备足够的相关性和质量。
