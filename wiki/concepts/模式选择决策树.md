# Skill 模式选择决策树

模式选择决策树是 [[青斧]] 在文章第五章给出的选型速查工具：按任务特征六分支映射到 5 种核心模式 + 特殊模式，是 [[skill设计模式五加一模式对比]] 的选型入口。原文：

```text
你的 Skill 需要做什么？
├─ 执行一个有明确步骤的操作
│  └─ → 模式 1：线性流程
├─ 在大量选项中帮用户选择正确的方向
│  └─ → 模式 2：决策树 + 按需加载
├─ 在单次会话中反复执行"做→验证→改进"
│  └─ → 模式 3：循环迭代
├─ 跨多个 session 持续推进一个长期项目
│  └─ → 模式 4：接力棒循环
├─ 跨越多天/多周，有阶段划分和 Go/No-Go 决策
│  └─ → 模式 5：多阶段 + 检查点
└─ 需要 LLM 进行深度分析而非快速执行
   └─ → 特殊模式：思维框架
```

六分支的深层维度是**时间尺度递进**（单步操作 → 单会话循环 → 跨 session → 跨天/周）与**操作型/思维型分野**（前五支控制行为，最后一支控制思维）。各模式详见 [[skill线性流程模式]]、[[skill决策树加按需加载模式]]、[[skill循环迭代模式]]、[[skill接力棒循环模式]]、[[skill多阶段检查点编排模式]]、[[skill思维框架模式]]。
