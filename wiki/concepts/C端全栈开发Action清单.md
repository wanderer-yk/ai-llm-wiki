# C端全栈开发Action清单

**C端全栈开发Action清单**是天猫新品营销技术团队在 C 端方向总结的五项主要 Action——团队声明大部分内容前文 C 端实战已提过，此处为主要 Action 的汇总，[[sources/[202605081607]天猫新品团队AI编码实战指南下|来源]]。

## 五项 Action（原文清单）

1. **代码结构与公共组件的设计**——提高生码效率与代码可控度；
2. **多类高频开发流程的标准化 workflow 沉淀**；
3. **基础团队知识库**——统一读取方案 + 快速知识查询；
4. **AI 基于知识库内容产出技术方案并人工审核**——"后期考虑提供专用的技术方案 Agent，并进行技术方案的打分评测"（[[技术方案打分评测]]）；
5. **开发流程中的工具辅助**——走查辅助、接口查询、页面检查MCP。

## 结构解读

- 第 1-3 项是环境与资产建设（代码架构、流程、知识），第 4 项是"AI 产出 + 人审核"的半自动分工（[[人提方案AI执行半自动方案]]），第 5 项是流程内工具嵌入——注意"页面检查MCP"与小二端后期"甚至不想配mcp"的场景分化：C 端流程化工具形态下 MCP 被明确纳入。
- 清单整体是 [[C端全栈开发三挑战]] 的解法映射，并为 [[知识库生成与自动更新]]、[[AI友好代码架构]]、[[全链路AI串联度提升]] 三个未来方向提供现状基线。
