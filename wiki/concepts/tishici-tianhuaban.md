# 提示词天花板

提示词天花板是技术 1（流水线+通用大模型）的核心缺陷之一。评审规则硬编码于 Prompt 导致规则膨胀触及上下文长度上限，可维护性与扩展性差。

## 问题分析

- 评审规则不断累积导致 Prompt 膨胀
- 规则之间相互挤压竞争，自动压缩时随机截断
- 效果提升仅靠换模型/调 Prompt，无法系统性地沉淀知识

## 解决方案

[[joyagent|JoyAgent]] 的 [[自定义知识库绑定机制]]提供了一种替代方案：接入者可在平台自定义智能体并绑定知识库，无需修改 Prompt 即可定制评审规则。[[双rag架构]]进一步将知识工程代码检索与 JoyAgent 知识库检索融合，突破单一 Prompt 的天花板。
