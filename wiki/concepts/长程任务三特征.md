# 长程任务三特征

百度Geek说《Harness Engineering》一文对"长程任务"的界定：凡是同时具备以下三个特征的任务，都超出单次 Agent 会话可靠完成的范围，需要 [[harness-engineering]] 式的工程化编排。

## 三特征

1. **规模大**——涉及成百上千个文件；
2. **运行时间长**——一次跑不完，天然跨越多个会话；
3. **消耗 Token 极高**——几千万到上亿 Token 量级。

## 三个工程化实例

- 21 个前端模块 JS 全量迁移 TypeScript；
- 几十个模块全量 Code Review + 批量修复几十上百条意见；
- 中文硬编码全量提取为 i18n 资源。

三特征是全文"特征→关注点→困难→原则"论证链的起点：由特征推导出三大关注点（[[效果速度成本三关注点]]）与三大困难（[[长程任务三困难]]），再映射到四原则。
