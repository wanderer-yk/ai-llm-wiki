# 分层架构最优四原则

**分层架构最优四原则**解释了为什么 [[agent-skills]] 与 [[mcp]] 的两层协同架构（[[经典协同模式三式]] 模式1）是最优选择。

## 四原则

1. **关注点分离** — Skills 管业务逻辑（why/what），MCP 管技术实现（how），各司其职
2. **变更独立性** — 修改业务流程（如调整部署步骤）不需要修改 MCP 服务代码，修改 MCP 工具实现也不影响 Skills 编排
3. **复用性** — MCP 工具（如 `run_tests`、`upload_to_s3`）具有跨 Skill 复用性，多个 Skills 可共享同一 MCP 工具
4. **安全与灵活性平衡** — MCP 层提供安全边界（权限控制、数据隔离、审计追踪），Skills 层提供业务灵活性（配置即生效、非技术人员可维护）

## 实践意义

这四原则使得团队协作更加高效：工程师专注于 MCP 服务开发和维护，产品经理和业务专家专注于 Skills 流程优化，互不干扰。
