# 五条带走结论

五条带走结论是《Claude Code 源码拆解》在全文总结「我们最后该带走什么」中将整篇文章自我压缩出的五条原则，与五大章一一映射（verbatim）：

1. 先定义执行边界，再发起第一轮推理。（对应启动层，[[复杂度前置]]）
2. 当 Agent 进入连续运行阶段，query loop 就必须升级成 runtime。（对应 Query Loop，[[运行时课题论]] / [[queryloop状态机]]）
3. 工具一旦开始碰副作用，工具层就必须制度化。（对应 Tool Runtime，[[工具有制度]]）
4. 权限系统的核心不是确认框，而是可解释的执行链。（对应 Permission System，[[权限执行链论]]）
5. 多 Agent 的前提不是 prompt 分工，而是统一任务抽象。（对应 Task/多 Agent，[[统一任务抽象先行]]）

价值：这是文章自身的最终蒸馏，各条均获作者 takeaway 级自我确认，可作为构建 Agent 运行时的 checklist。五条之上，文章以 [[组织接入交付链路论]] 与 [[复杂度承接之问]] 完成组织级收束。
