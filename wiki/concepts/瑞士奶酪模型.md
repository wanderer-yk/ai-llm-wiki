# 瑞士奶酪模型

[[韩春]] 借用的安全分析透镜：每层防御（代码审查、测试、监控、运维）皆如带孔洞的奶酪切片——单层孔洞不致命，但当各层孔洞对齐时，危险将穿透所有防线。

在 Agent 语境下的用途：解释为何在缺乏全局视角的 Agent 系统中，传统多层防御失效——[[概率级联故障]] 的"错误前提传播"恰好逐层寻找并对齐各防御层的孔洞。这与 [[agent开发经验主义]] 呼应：每层防御的参数与规则本身也是经验性的，孔洞位置不可先验预知。
