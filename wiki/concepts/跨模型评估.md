# 跨模型评估

百度Geek说《Harness Engineering》提出的去偏评估策略：评估者与执行者使用**不同模型**，进一步降低同源偏见。

## 典型配置

- Claude Sonnet 做 Code Review（执行）；
- GPT 做置信度 Grader（评估）；
- 评估结果交回 Sonnet 修复（回流闭环）。

跨模型与独立会话（[[自我说服效应]]）是双重降偏：会话隔离消除"自证"，模型隔离消除"同源盲区"。

## 同型实践比对

美团 [[高阶模型审查低阶模型]]（高配模型作 Judge Model 审查低阶模型编码）与本概念结构同型，但语境不同：美团是**团队成本策略**（Judge 用高配、执行用低配以省成本），本文是**评估去偏手段**（评估与执行刻意异源）。两者可互为印证，不构成矛盾。
