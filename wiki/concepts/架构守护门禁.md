# 架构守护门禁

"架构守护门禁"是《[202604231830]从可观测到可理解用UModel构建Agent原生的代码知识图谱》展望部分给出的 CI/PR 集成设计：**PR 时自动执行图谱增量更新、架构违规检查与变更影响分析三条命令，将架构约束从文档约定升级为机器强制**。它是 [[验证门禁化]]（vivo 丁俊杰："验证从建议检查升级为硬性阻断规则"）主张在代码域的直接实例。

## CI 门禁三命令（原文 verbatim）

```bash
code-wiki ingest --incremental        # 增量更新图谱
code-wiki check arch                  # 架构违规检查
code-wiki query impact <changed_files>  # 变更影响分析
```

## 门禁内容

- **ingest --incremental**：PR 变更实时入图，保证检查基于最新结构；
- **check arch**：扫描分层违规，案例三实证检出 utility→api、infra→service 两条违规（分层规则内置，配置方式未说明）；
- **query impact**：对变更文件输出影响面，供评审者判断风险（案例一输出 9 依赖/3 入口点/2 跨界的评估报告）。

## 与跨团队验证门控共识的关系

爱奇艺 [[blocker-gate]]（需求对齐门控）、美团 [[pre-pr机制]]（AI 多轮自查前置）、vivo [[验证门禁化]]（四条硬性阻断规则）构成验证门控共识谱系；本概念将门控对象从"流程合规"与"代码质量"扩展到"架构分层合规"，并以知识图谱作为判定基础设施——门禁的裁判从规则引擎/linter 变为结构化图查询。
