# 被动记忆式 Skill 演进

"被动记忆式 Skill 演进"是 [[kiritomoe]] 提出的 Skill 机制未来理想形态，指在持续的自然语言对话和迭代中，Skill 像人类的被动记忆一样实现自主沉淀和优化，无需人工显式创建和维护。

## 核心理念

### 当前状态

- Skill 需要人工显式创建（如借助 Claude 官方 `skill-creator`）
- 高频操作需要人工识别并固化为 Skill
- Skill 的更新和维护依赖人工介入

### 未来形态

- Skill 在对话过程中自动沉淀——AI 从高频操作中"被动记忆"出可复用的模式
- Skill 自主优化——根据执行结果自动调整 Skill 参数和流程
- 无侵入式——开发者无需感知 Skill 的创建和更新过程

## 与被动记忆的类比

人类在重复执行某项任务后，会"自然而然"地形成肌肉记忆和经验法则，无需刻意学习。被动记忆式 Skill 演进追求类似的机制：

| 维度 | 人类被动记忆 | Skill 自主演进 |
|------|------------|----------------|
| 触发 | 重复经历 | 高频操作模式 |
| 沉淀 | 神经连接强化 | Skill 自动生成 |
| 调用 | 直觉反应 | Agent 自主调用 |
| 优化 | 经验修正 | 执行结果反馈 |

## 跨领域关联

- 是 [[sdd留痕进化论]] 的终极形态——"高频动作固化为 Skill"从人工决策进化为自主沉淀
- 与 [[数据自迭代]] 理念一致——都追求系统的自我优化闭环
- 与 [[活文档机制]] 互补——活文档解决"文档与代码同步"问题，被动记忆 Skill 解决"经验与系统同步"问题
- 目前仅为概念设想，尚无技术实现方案，是 Wiki 中明确的未来研究方向之一
