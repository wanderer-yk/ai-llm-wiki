# 无需走查的代码集成

[[柚漫剧团队]] 设计章 3.3 的交付目标：研发**前置干预**使设计产出即最终方案——交付物是经设计校验、符合底层代码规则的"**逻辑成品**"，实现像素级自动化还原，无需传统 UI 走查环节。

## 前置代码约束 Prompt 三要素

RD 为 PM/设计师提供：

1. 组件库规范
2. 布局规则
3. 性能基准

## 实例

"prompt 参考"实例（verbatim 开头）："帮我生成一个如图所示的官网界面，背景的漫画从下至上无限滚动，同时按以下要求做优化：……"——即漫剧官网任务描述与 [[通用技术Prompt模板]] 两段工程约束的组合引用。

## 对照

与传统走查的补救式校验相对，本概念是"约束前置"的正向路径；其逆向互补面是 [[AI Checker 茶茬]] 的 [[figma图像对比前置]]——对既有页面做设计源驱动的走查校验，两者同属设计源驱动校验谱系。
