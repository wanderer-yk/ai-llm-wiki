# 感官肢体与大脑神经隐喻

**感官肢体与大脑神经隐喻**是 [[牛潇]] 用于阐述 [[mcp]] 与 [[agent-skills]] 协同共生关系的生动类比。

## 隐喻映射

| 人体系统 | 技术对应 | 核心功能 |
|----------|----------|----------|
| 感官（眼睛/耳朵） | MCP | 感知外部世界，获取数据 |
| 肢体（手） | MCP | 执行物理操作，与外部交互 |
| 大脑 | Agent Skills | 决策、规划、行为规范 |
| 神经系统 | Agent Skills | 信息传递、协调、上下文感知 |

## 核心寓意

正如人不能只有感官和肢体而没有大脑（无法决策），也不能只有大脑而没有感官和肢体（无法行动），**MCP 和 Agent Skills 是共生关系，缺一不可**。最强的系统是两者精心设计的协同体。

这一隐喻与 [[能力vs行为二分法]] 的"企业 IT 基础设施 vs 企业 SOP 手册"隐喻形成互补——前者更生动，后者更具工程实践指导意义。
