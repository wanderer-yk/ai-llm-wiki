# 原生记忆不确定性链路

原生记忆不确定性链路是对 [[openclaw]] 原生长期记忆系统"玄学效果"的工程归因模型：记忆从对话内容到上下文注入的四环节（展开为六项不确定性）叠加，任一环节的不确定都会传导至最终记忆效果。来源文章定性：非设计缺陷，而是通用框架在提取精度与系统复杂度间的权衡。

## 链路图（原文）

```
对话内容
  ↓ ❶ LLM 自主判断是否写入（可能遗漏）
  ↓ ❷ 短对话无 Flush 安全网（可能不触发）
日记忆文件
  ↓ ❸ 晋升不确定或不准确
  │   ├─ 默认路径：Agent 自主判断，可能不执行或整理不全
  │   └─ Dreaming 路径（默认禁用）：
  │        Jaccard 机械去重（无语义理解）
  │        六维统计评分（无 LLM 语义判断）
MEMORY.md
  ↓ ❹ 召回受限（无 embedding 时降级为词法匹配）
对话上下文
```

## 六项不确定性

1. **LLM 主观写入**：是否写入/写什么/什么格式全凭单次推理，无结构化规则与强制格式（案例：名字/城市/饮食偏好只记住名字）。
2. **短对话无 Flush 安全网**：Memory Flush 仅在接近压缩阈值时触发。
3. **Cron 演进延迟**：Dreaming 跨日信号积累导致时效信息失效。
4. **Jaccard 机械去重**：无法捕捉语义近似，同事实可能存多版本。
5. **统计评分无语义**：六维评分无 LLM 语义判断，"花生过敏"类低频重要信息可能被埋没。
6. **召回配置制约**：受 embedding 配置、查询精准度、Agent 检索意识制约。

注意归因的三层结构：弱约束写入（玄学主要来源）→ 确定性 Dreaming 管线的语义盲区与时效代价（管线确定性 ≠ 记忆正确性）→ 召回配置制约。

## 补强方案

[[RDSClaw]] 插件对六项不确定性逐条互补：结构化 Prompt 约束、`agent_end` 钩子每轮触发、同轮完成、向量+LLM CRUD、LLM 每次决策、混合召回（详见来源页映射表）。

## 关联

- 晋升门控 ↔ [[验证门禁化]]；Flush 安全网 ↔ [[autocompact水位线机制]]、[[三层上下文压缩]]。
