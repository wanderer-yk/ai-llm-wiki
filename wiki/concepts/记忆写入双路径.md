# 记忆写入双路径

记忆写入双路径是 [[openclaw]] 原生记忆系统的日记忆写入机制：两条路径均写入同一 `memory/YYYY-MM-DD.md` 文件，该文件是 Dreaming 系统的输入源。

| 路径 | 触发方式 | 定位 |
|---|---|---|
| Agent 主动写入 | 用户显式要求（"remember this"）或 Agent 自主判断 | 日常主路径，完全依赖 LLM 自主决策 |
| Memory Flush | Compaction 前双阈值触发（`softThresholdTokens`=4000 / `forceFlushTranscriptBytes`=2MB） | 压缩前安全网，"最后一次救济机会"（详见 [[memory-flush机制]]） |

## 弱约束特征

是否写入、写入什么、用什么格式写入，完全由 LLM 在对话中自主决定——无结构化提取规则、无强制写入模板。AGENTS.md 模板对记忆写入的指导（"capture what matters"）属"方向性建议"而非结构化规则。后果：Agent 可能记得很详细，也可能完全不记。

## 关联

- 写入环节是 [[原生记忆不确定性链路]] 的第一、二环。
- flush 期间权限收紧（其余记忆文件只读、`write` 包装为 appendOnly）与主会话"freely"读写 MEMORY.md 是分阶段权限控制而非矛盾。
