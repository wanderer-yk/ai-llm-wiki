# 四大高频场景抽象

四大高频场景抽象是本文的第一性原理归纳：除 coding（单列课题，不在此列）外，近 80% 的日常工作任务可归入**复杂指令执行、知识问答、问题排查、常规碎片化**四大场景类型。每类场景以"目标（本质）/挑战/方案"三层定义，并固化于 [[智空间分层解耦架构]] 的解决方案层。

## 四场景本质

| 场景 | 本质 | 代表方案页 |
|------|------|-----------|
| 复杂指令 | 工具海选 + 链路规划 + 安全执行 | [[复杂指令场景方案]] |
| 知识问答 | 图文召回 + 多语义理解 + 知识保鲜 | [[知识问答场景方案]] |
| 问题排查 | 表象→根因的 RCA 过程，工具调用与人工经验融合 | [[问题排查场景方案]] |
| 常规碎片化 | 极简接入 + 能力复用 | [[常规极简场景方案]] |

## 五大共性问题与应对

1. query 不全、不清晰、句式多变 → 意图识别：理解用户意图，并做好必要的校验、纠偏
2. query 多模态（含图文）→ 多模态支持：识别并解析图文输入
3. 工具描述不清晰、功能重合 → 工具治理：提升工具描述质量、优化出入参，引入冲突检测
4. 上手成本高、调试难 → 助手市场：一键创建 agent 实例、页面调试（所见即所得）
5. 安全与权限问题 → 安全治理：工具执行权限校验、工具分类（写管控）、工具治理（非测试数据管控）
