# 意图路由

意图路由是问题排查场景方案（[[问题排查场景方案]]）的入口分派机制：由通用意图识别模块区分两类排查问题，并路由到不同的处理流程，避免"该查知识的问题去跑工具、该查数据的问题去翻文档"的错配。

## 两类问题（原文定义）

- **业务咨询类**：面向静态知识问答（如"如何创建绑定账号"）→ 走知识问答流程（[[知识问答场景方案]]）。
- **查询和排查类**：面向特定账号/数据的咨询排查 → 走 ReAct 推理流程（[[ReAct推理模块]]）。

## 关联

- 与 [[意图识别前置门控]]（意图识别作前置门控）、[[意图规划]]（Query改写→意图识别→意图挖掘）、[[Agent协同模式]]（精准路由）构成跨团队的"先识别后分派"共识。
- 复杂指令场景方案（[[复杂指令场景方案]]）的意图处理模块中亦有"意图路由"职责，本文未展开其细节。
