# 经验学习与快速响应

经验学习与快速响应是 [[AssistantAgent]] 经验模块（Experience）的机制总称：Agent 将成功执行沉淀为**三类经验**，经**两条复用路径**反哺后续任务——普通经验注入 Prompt 供 LLM 参考，配置了 `fastIntentConfig` 的经验命中后**跳过 LLM 完整推理**、直接执行预记录的工具调用或代码。经验支持生命周期管理（创建/更新/删除）。

## 三类经验

1. 代码生成经验；
2. ReAct 决策经验（关联 [[react-agent]]）；
3. 常识经验。

## 双复用路径

- **路径一：注入 Prompt**——未配置快速意图的普通经验仅作为"历史经验参考"片段注入（由[[评估图|评估图 Layer 2]]"检索经验（有/无）"探测），供 LLM 决策时参考。
- **路径二：快速意图响应（`fastIntentConfig`）**——需**显式配置**才能启用（opt-in 机制，而非自动发生）：
  - 匹配条件类别：消息前缀、正则、元数据、状态等；
  - 命中动作：跳过 LLM 完整推理，直接执行预记录的工具调用或代码；
  - 文内示例：经验 B 配置条件"前缀匹配 `查看*销量`"、动作"调用销量查询API"，用户输入"查看今日销量"命中后直接执行；未配置的普通经验 A 仅注入 Prompt 供 LLM 参考。

## 重要精化

文章技术特性列表中"熟悉场景跳过 LLM 推理"的表述，在后文被明确限定为**需显式配置 `fastIntentConfig` 才能启用**——快速意图是 opt-in 的加速通道，属于 [[意图路由]] 的"高频意图短路"变体；经验来源由 [[学习模块四通道提取]] 供给。

## 与既有概念的关联

- 与 [[多智能体自进化]]（阿里商旅）、[[skill功能聚合]]（vivo，Agent 自动积累工具"说明书"）、[[sop-doc可召回排查文档]]（顺乾问诊）同属"Agent 从执行中沉淀可复用资产"的演进路径；Assistant Agent 的差异化在于提供了**绕过推理**的确定性快速通道。
