# 同步异步双路径

同步异步双路径指单进程 Agent 框架中**数据流的两条主线**：同步路径承载用户交互（标准 ReAct 循环），异步路径承载内部消息（子 Agent 结果、定时任务触发），二者经消息总线汇入、由互斥锁保证不冲突。该概念由苏雄 800 行框架的「模块协作全景」章节明确提出，并与 [[react-agent]]（同步路径被文称「标准的 ReAct 循环」）、[[agent-loop]]（`AgentLoop.run()` 迭代上限 10/15）直接呼应。

## 双路径定义

| 路径 | 链路 | 定性 |
|---|---|---|
| 同步路径 | 用户输入 → REPL → `agent.run()` → 工具调用 → 结果回传模型 → 最终回复 → stdout | 「标准的 ReAct 循环」 |
| 异步路径 | SpawnTool / CronService → `bus.publish("system")` → handler 入队 → `tryDrainPending()` → `agent.run()` | 内部消息经总线/队列消费 |

异步路径收尾（作者原话级表述）：「异步结果通过 MessageBus 汇入主循环，由互斥锁保证不与同步路径冲突。」互斥锁机制详见 [[互斥锁与暂存队列]]；总线机制详见 [[入站消息总线]]。

## 与暂存-轮询消费范式的关系

`bus.subscribe` + `pendingSubagentResults` 队列 + `tryDrainPending` 守卫的组合，与 zhiyuanfu [[24h打工人]] 的 [[文件轮询架构]] 同属**暂存-轮询消费范式**：事件源不直接驱动消费，而是先入暂存结构，由消费者在安全时机（锁空闲）批量取空处理。区别在于前者以进程内消息总线 + 回调为通道，后者以文件系统 + 轮询为通道。
