# 需求上下文自动关联

需求上下文自动关联是 [[智能代码评审系统]]的未来演进方向之一：commit 信息嵌入需求编号→评审时自动提取并获取 PRD→对照需求文档判断实现完整性。

## 机制设计

1. 开发者在 commit 信息中嵌入需求编号
2. 评审时系统自动从 commit 提取需求编号
3. 根据需求编号自动获取对应的 PRD 文档
4. 对照需求文档判断代码实现的完整性

## 待解决的问题

commit 信息嵌入需求编号的规范如何落地执行尚未说明。这需要：
- 团队规范约定
- CI/CD 流程的 commit 信息校验
- 需求管理系统与代码评审系统的集成

## 价值

实现代码评审从"代码质量检查"到"需求实现完整性检查"的升级，确保代码不仅写得好，而且写对了。
