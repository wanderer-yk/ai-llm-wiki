# 工具结果头尾修剪

工具结果头尾修剪（Pruning）是 [[openclaw]] `src/agents/pi-embedded-runner/tool-result-truncation.ts` 中对过大工具输出的规则化裁剪：保留头尾、省略中间（中间替换为 `.`）。经验法则依据：报错的关键信息通常在首尾、JSON 的核心字段通常在头部，中间是最可牺牲的部分。裁剪比例设 **≤50% 止损线**，防止修剪本身破坏信息主体。

与压缩（Compaction）的差异：压缩生成 Summary 替换旧消息、需调用 LLM、保留关键信息；修剪直接删减、零 LLM 成本、信息直接丢失，适用于"工具结果占用太大或会话太多"场景。完整四维对比见来源页及 [[摘要分层降级策略]]。与 Claude Code 的 [[函数结果清理机制]]、[[microcompact工具白名单]] 构成跨框架对照。
