# 检索与生成联动失效

检索与生成联动失效是技术 2（JoyAgent 知识库 RAG）的核心缺陷之一，由 [[知识归纳失真]]传导引起。

## 失效链条

1. LLM 对 Code Diff 的知识归纳产生失真
2. 基于失真结果做 RAG 检索，召回匹配度低
3. 检索结果未经重排序，噪声干扰严重
4. 送入不完整的上下文给生成模型
5. 最终生成不可靠的评审意见

## 核心问题

整个链路的效果取决于最薄弱的环节——知识归纳失真作为源头缺陷，逐级放大影响最终输出质量。这是 [[rag技术瓶颈]]在代码评审场景的具体体现。

## 解决方案

[[双rag架构]]通过以下方式切断失效链条：
- 知识工程层直接提供精确代码语义，绕过 LLM 归纳
- [[bge-本地重排序方案|BGE 重排序]]解决 [[向量召回质量不均问题]]
- [[项目身份感知能力]]确保检索方向正确
