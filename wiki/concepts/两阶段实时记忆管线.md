# 两阶段实时记忆管线

两阶段实时记忆管线是 [[RDSClaw]] 插件处理个人记忆的核心架构：由 `agent_end` 钩子在**每轮对话结束时稳定触发**（不依赖 token 阈值或 Agent 自主判断），提取与整合两个阶段在**当轮完成**，无需 Cron 调度——与原生系统"数天演进"相对，实现"分钟级"记忆更新。

## 流程（原文）

```
对话内容
  ↓ ① 提取器（Extractor）
LLM 结构化提取，配合强制规则
  ↓ 分流：个人记忆管线 / 世界记忆管线
  ↓ ② 整合器
  对每条新事实，向量检索已有记忆 → LLM 判定 CRUD 动作：
  INSERT（新事实）/ UPDATE（信息更丰富）/ SKIP（已存在）/ DELETE（矛盾过时）
  ↓
LanceDB（向量 ANN + BM25 FTS + 标量索引）
```

## 与原生系统的核心差异

- 稳定触发 vs Agent 自主判断/token 阈值；
- 每步均有 LLM 语义判断 vs Jaccard 字面去重 + 统计评分；
- 当轮完成 vs Cron 跨日演进。
