# 复杂指令场景方案

复杂指令场景方案是四大场景方案之一，处理"根据用户指令、专家经验，在海量工具中找到并规划工具链，达成任务"的场景（本质：工具海选 + 链路规划 + 安全执行；案例：演练助手）。挑战在于指令拆解、海量工具、工具链推导与复杂场景理解。

## 六步核心流程

```
1. 预处理
2. 意图识别
3. 意图处理
4. 工具召回（过滤引擎）
5. 推理执行
6. 总结&返回
```

- **预处理**：多模态识别处理 + 内嵌式命令快速响应——"能不用LLM就不用LLM"。
- **意图处理**：意图路由、定制化意图处理、定制化流量处理。
- **挑战定位**：用户语言/诉求多样化、工具描述/功能多样化、诉求粒度与功能粒度断层。

## 核心节点

1. **意图识别**：[[IntentResult模型]] 把"人话"翻译成七字段标准模型。
2. **工具召回**：[[FSWW工具召回算法]] 在调用大模型前工程化预选海量工具。
3. **工具链推导**：[[逆向推理正向执行]]——从目标工具反推依赖、正向串成工具链，经 MCP 协议调用。
4. **安全执行**：[[四重安全校验]] 内置于工具链执行（原文表格记"工具读写管控"）。

## 关联

- 选用核心能力层的"工具推理"模块（[[智空间分层解耦架构]] 搭积木组合）。
- 工具召回思路与 [[agent架构四决策]]（工具查找）、[[七步工具策略管道]]、[[向量检索rag]]/[[rag技术瓶颈]] 形成跨来源对照。
