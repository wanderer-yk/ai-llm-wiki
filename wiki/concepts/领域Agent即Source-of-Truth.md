# 领域Agent即Source of Truth

小红书 [[小红书PMO团队]] 在 3.0 阶段切换至 [[openclaw]] 后形成的核心认知：OpenClaw 与领域 Agent 不是替代关系，而是分工协同——领域 Agent 的核心价值不是再造轮子，而是成为领域内可信唯一信息源。

## 核心含义

在 OpenClaw 通用 Agent 平台时代，领域 Agent（如 PMO BP Agent）的差异化价值在于：
1. 持有领域内最完整、最权威的结构化数据（如 [[项目注册平台]] 的项目主数据）
2. 持有领域内最精准的知识（如项目管理方法论、组织流程规范）
3. 成为该领域内所有 Agent 查询的权威数据锚点

## 与 Skill 蒸馏的关系

PMO 团队将原有项目管理能力蒸馏为 Skill 上架内部 Skill Hub，供全公司员工调用。这体现了"能力共享、数据独占"的分工策略——Skill 是通用能力层，数据锚点是领域壁垒。

## 跨领域关联

- 与 [[三大武器库]] 中知识库层（"知道"）的理念对应
- 与 [[信息中枢先于任务执行]] 的定位策略互补——先成为信息中枢，再扩展任务执行
- 与 [[项目注册平台]] 作为唯一数据锚点的设计直接对应
