# 多语种参照系 Few-shot

多语种参照系 Few-shot 是 [[货拉拉技术]] 团队在翻译 Agent 中引入的一种创新语义消歧技术。其核心思路是利用同源语料下其他语种的人工翻译结果作为带权 Few-shot，在多维语义空间中锁死多义词语义，消除歧义。

## 问题背景

UI 文案短小且缺乏上下文，导致 AI 误判一词多义。典型案例：

- **order**：在 UI 文案中既可能指"命令"也可能指"订单"
- AI 翻译通常选择"最大概率"词汇而非最合适词汇

单纯依赖术语库或上下文注入无法完全解决此类多义问题。

## 技术原理

当翻译某段 UI 文案到目标语言时，如果同一文案在其他语种中已有高质量的人工翻译结果，则将这些翻译作为**带权 Few-shot** 注入 Prompt：

1. 同源语料的其他语种人工翻译蕴含了翻译者对该文案真实语义的理解
2. 多个语种的翻译结果在语义空间中形成交叉验证
3. 通过带权方式综合多个参照翻译，在多维空间中"锁死"该文案的准确语义
4. 目标语种的翻译在此基础上生成，有效消除歧义

## 价值

该技术是 [[翻译信达雅]] 中"信"（准确）维度的重要保障，也是 [[多agent翻译框架]] 翻译 Agent 的三大核心技术之一（与术语库强约束、上下文注入并列）。
