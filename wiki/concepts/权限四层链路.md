# 权限四层链路

权限四层链路是无岳《Claude Code 源码拆解》第五章对权限系统的结构化拆解，核心命题（原文）：**「权限系统的核心不是确认框，而是可解释的执行链。」**

## 四层

| 层 | 职责 |
|---|---|
| 规则层 | 静态权限规则（allow/deny/ask 配置） |
| 运行时判定层 | 逐次工具调用的动态判定 |
| 交互层 | 需人工确认时的 UI 交互 |
| 执行隔离层 | 沙箱等执行侧隔离兜底（[[沙箱即权限落地点]]） |

## 配套机制

- [[逻辑授权与执行隔离分离]]：允许是一回事，能否执行是另一回事；
- [[权限决策对象化]]：PermissionDecision 使权限从 boolean 变为「为什么过、卡在哪、下一步怎么处理、能不能先自动判一轮」；
- [[权限拒绝协议内包装]]：拒绝以协议内消息返回模型，使其可自我修正；
- [[自动模式危险能力裁剪]]：自动模式下裁剪危险能力子集。
