# 每种复杂度只在一个地方爆炸

「每种复杂度只在一个地方爆炸」是《Claude Code 源码拆解》给出的架构成熟标志：不是没有复杂度，而是复杂度被放到对的位置。Claude Code 的四处安放：

- 上下文续跑的复杂度只在 Query Loop（[[queryloop状态机]]）
- 副作用权限的复杂度只在执行链（[[权限执行链论]]）
- 并发后台的复杂度只在任务链（[[统一任务抽象先行]]）
- 平台增长的复杂度只在扩展层（[[动态能力面稳定内部对象]]）

与 [[横切复杂度下沉]] 是同一原则的两种表述（后者是工具层的局部视角，本条是全局架构视角）；与 [[复杂度安放位置论]] 构成正反两面（原则 vs 散架诊断）。整体落点是 [[三主干链路]] 总架构。
