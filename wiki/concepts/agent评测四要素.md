# Agent 评测四要素

有赞共享技术团队在 AI 客服建设中提出的 Agent 评测框架，包含评测对象、评测数据集、评估指标、反馈闭环四个核心要素。

## 核心洞察

**Agent 评测与传统软件测试有根本性差异**：
- **不确定性**：模型输出不可精确预测
- **开放性**：用户问题无固定模式
- **场景多样性**：同一问题在不同上下文中有不同最优回答

这些特性使得无法完全沿用传统软件测试方法（如断言、边界值分析等），需要专用评测体系。

## 四要素框架

### 1. 评测对象

- 场景：售前咨询、售后问题、物流查询等
- 流程：意图识别准确性、回答生成质量
- 知识：商品知识、政策知识、历史 QA

### 2. 评测数据集

- 历史真实对话数据
- 人工构造的边界场景
- 线上 Goodcase / Badcase 持续积累

### 3. 评估指标

- 人工评估：准确性、完整性、语气适宜性
- 自动评估：评估器（Evaluator）相似度判断

### 4. 反馈闭环

问题识别 → 根因分析 → 优化迭代（Prompt/知识/流程）→ 再次评测
