# RL 知识蒸馏降本论

RL 知识蒸馏降本论是来源文章对“为什么要做 RL 训练”的核心回答：**RL 的真正目的是知识蒸馏**——把 Claude Opus 等旗舰大模型的能力压缩到 Qwen 3~4B 量级的小模型中，而不是“从用户那里学东西”（后者是营销号误传，见 [[用户数据不直接训练论]]）。

## RL 训练的三个意义

1. **降本**：API 贵、小模型免费、大模型慢——蒸馏后可用小模型以更低成本、更快速度达到接近的能力。
2. **安全合规**：数据不出机器（训练在本机环境内完成）。
3. **领域极致特化**：开源小模型经领域 RL 后，其领域 Agent 能力有机会接近甚至超过更大参数的闭源通用模型。

## 在自进化架构中的位置

该论断解释了 [[内外双路径自进化]] 中“内路径（RL）”的经济学动机，与 [[外挂式进化vs权重内化]]（能力必须内化到权重）互为表里；执行层面依托 [[research-ready训练闭环]] 与 [[grpo算法]]，数据供给见 [[批量数据生成]] 与 [[opd机制]]。
