# 批量数据生成

批量数据生成是 [[hermes-agent]] RL 训练闭环的“主力数据工厂”，由 `batch_runner.py` 实现：批量合成 Agent 运行轨迹、筛选高质量数据并转为 [[sharegpt格式]]，供 RL 训练消费（见 [[research-ready训练闭环]]）。

## 六步流程

1. **提示词准备**：从 JSONL 提示词文件或 GSM8K/HumanEval 等 Benchmark 数据集采集。
2. **线程池并行**：并行运行多个独立 Agent 实例。
3. **Teacher 模型**：默认 `anthropic/claude-opus-4.6`（来源确认为默认配置而非举例）。
4. **轨迹录制**：录制完整 [[agent轨迹]]。
5. **工具集随机采样**：随机采样不同工具组合，让模型学会灵活运用而非死记一种配置。
6. **零推理过滤**：`_extract_reasoning_stats` 统计 `<REASONING_SCRATCHPAD>` 与 reasoning 字段出现次数，**双零样本丢弃**——无显式推理说明机械执行、无思考过程、无训练价值。

## 与 mini_swe_runner.py 的对比

| 文件 | batch_runner.py | mini_swe_runner.py |
|---|---|---|
| 用途 | 通用数据的批量生成 | SWE Benchmark 任务 |
| 任务类型 | 任意提示词 | 代码修复/实现 |
| 完成信号 | 对话自然结束 | `echo "MINI_SWE_AGENT_FINAL_OUTPUT"` |

另有基于 Princeton 2026 OpenClaw-RL 论文的 [[opd机制]]（Hindsight-Guided On-Policy Distillation）作为更精细的 Teacher-Student 数据合成路径。

生成的原始轨迹经 [[轨迹头尾保护压缩]] 压缩后进入训练。
