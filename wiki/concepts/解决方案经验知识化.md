# 解决方案经验知识化

[[书牧]]（[[天猫技术]]）提出的概念：将实战经验作为可注入的专家知识沉淀。

典型案例：

- 消息重试机制解决最终一致性问题
- [[tair]] version 解决分布式并发问题

这些经验作为 [[基础技术层七项子规范]] 的第七项，是企业级 Code Agent 需要的专家知识。
