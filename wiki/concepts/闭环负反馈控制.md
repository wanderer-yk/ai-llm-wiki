# 闭环负反馈控制

控制工程专业出身的 [[韩春]] 提出的 Agent 控制论解读：**ReAct 与经典闭环控制是同一件事**——负反馈即减小期望值与实际值误差。

## 原文映射图（verbatim）

```
 经典闭环控制系统
 ══════════════════

        r(t)          e(t)         u(t)          y(t)
   目标值 ──→ ⊕ ──→ 控制器 ──→ 执行器 ──→ 被控对象 ──→ 输出
             ↑
             │               Sensor
             └────────────────────────────────────────┘
                             反馈信号


 Agent 系统映射
 ══════════════════

        Goal           Context         Action       Result
   用户目标 ──→ ⊕ ──→   LLM   ──→   Tool   ──→  环境  ──→ 效果
              ↑     (控制器)     (执行器)    (被控对象)
              │
              │            Observation (Sensor)
              └────────────────────────────────────────┘
```

## Agent 控制论总定义（原文）

> 利用不可靠的 LLM（黑盒），通过外挂足够多样的工具（必要多样性），在负反馈（反思）和前馈（规划）的配合下，构建一个能维持在目标稳态（Homeostasis）的控制系统。

## 关键缺陷与补救路径

- 缺陷：Observation 依然是 LLM 返回，未跳脱 LLM 语义空间——见 [[observation语义空间受限]]；
- 补救一：以多样性对抗多样性——[[必要多样性定律]]；
- 补救二：引入物理世界真实影响作为反馈——[[真实世界负反馈]]。

关联：为 [[react-agent]] 提供理论根基，与 [[reflection模式]]（反思脉络）、[[反馈回灌闭环]]（有赞质检回灌）互为印证。
