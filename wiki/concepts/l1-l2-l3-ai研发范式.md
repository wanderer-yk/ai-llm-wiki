# L1-L2-L3 AI 研发范式升级路线

L1-L2-L3 AI 研发范式升级路线是快手智能化 2.0 阶段的核心路线图，描述了 AI 在研发流程中参与深度的渐进式升级路径。

## 三级定义

| 级别 | 名称 | 模式 | AI 参与程度 | 典型场景 |
|------|------|------|------------|---------|
| L1 | Copilot | AI 辅助 | 人主导 + AI 编码辅助 | 开发者在 IDE 中使用 AI 补全代码 |
| L2 | Agent | AI 协同 | 人机深度协同 + 任务分解给 AI | AI 完成多个关键节点，人审查 |
| L3 | Agentic | AI 自主 | 人类似产品经理澄清需求 + AI 自主交付 + 人类验收 | 全流程 AI 完成，人仅上线前后审核 |

## 产品形态映射

[[kwaipilot]] 的三代演进与 L1→L2→L3 一一对应：

- Code Copilot → L1 Copilot
- Code Agent → L2 Agent
- Multi-Agent & Agentic Coding → L3 Agentic

## 分级实施目标

快手 [[主站技术部]] 的分级实施目标为：

- **所有需求**达到 L1 级
- **大部分需求**持续升级到 L2 级
- **小部分需求**探索达 L3 级（通过 [[全栈跨栈效率跃迁]] 实现）

## 度量牵引

L2&L3 级需求占比已成为快手效能度量的核心牵引指标，替代了传统的「AI 代码生成率」。标杆团队实证数据：L2&L3 占比达 20.34%，需求交付周期下降 58%，两项指标呈明显正相关。

## 当前进展

2026 年快手正处于 L2→L3 跃迁探索期。这一路线图与业界 Agent 成熟度模型（如 [[agent三层商用架构]]）在分层逻辑上存在共通之处，但快手的独特贡献在于将其从技术架构维度提升到组织管理维度，并建立了正式接入度量体系的牵引机制。
