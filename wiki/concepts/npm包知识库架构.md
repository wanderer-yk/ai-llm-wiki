# npm包知识库架构

**npm包知识库架构**是天猫新品营销技术团队实现"工具无关知识分发"的具体架构：git 仓库管理知识源文件 + npm 包作为资源承载与版本管理工具 + 文件链接实现多级文档管理与索引 + AI 通过 curl 直接读取 npm 包下 CDN 资源获取知识 + 编辑器 Rules 一行配置即完成接入，[[sources/[202605081607]天猫新品团队AI编码实战指南下|来源]]。

## 设计目标

直接回答了初期遗留的"团队内存在多种编码工具"问题：知识分发不绑定任何具体编码工具——任何能发 HTTP 请求或读取本地文件的 AI 工具都能消费同一份知识源，避免为每个工具重复适配。

## 关键机制

- **渐进式披露控 token**："使用文件链接进行文档的多级管理与索引，渐进式披露，不会过度占用 token"——与有赞 [[渐进式披露替代向量检索]] 高度同构（目录结构即检索路径、零向量基建依赖），是该概念的第二团队独立实例。
- **npm 版本管理**：知识的更新随包版本发布，配合"及时更新"要求解决多仓库场景下文档与规范改动无法同步的问题。
- **多消费入口**：curl 直读（[[无感辅助]]）+ CodeWiki 问答，汇入 [[统一收口]] 的单一知识源。
