# 高风险优先任务排序

高风险优先任务排序是 Ralph Loop 技巧 7 提出的任务选择策略：让代理按风险递减的五级优先序选择下一个任务，在风险最高的工作上快速失败，将简单的胜利留到后面。

## 五级优先序（原文提示词模板）

```markdown
选择下一个任务时，按以下顺序优先处理：
1. 架构决策和核心抽象
2. 模块之间的集成点
3. 未知的未知和探索性工作
4. 标准功能和实现
5. 抛光、清理和快速胜利
在高风险工作上快速失败。将简单的胜利留到后面。
```

## AFK 门控原则

AFK（无人值守）Ralph 保留到基础稳固之后：架构验证通过、高风险集成正常运作，才转入过夜无人执行（与 [[hitl到afk渐进路径]] 互证）。

## 逻辑依据

- 架构与集成点错误如果后置发现，返工成本指数级放大；前置探索性工作"需要快速失败"以尽早暴露未知
- 与 [[小步迭代]] 互补：排序决定"做哪个"，小步节律决定"怎么做"
- 与 [[plan-and-execute模式]] 的先规划后执行思想呼应：先解决结构性不确定，再批量执行确定性任务
