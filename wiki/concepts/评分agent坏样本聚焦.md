# 评分 Agent 与坏样本聚焦策略

评分 Agent 与坏样本聚焦策略是问诊 Agent 自动化评估的核心设计：月均交互量突破千条后人工打标不可持续，但作者刻意将评分 Agent 定位为**“低投入、高回报的异常检测”，而非“全自动精准裁判”**——目标是快速识别坏样本，而不是为每条输出打准十分。人工复核因此收敛至 ≤ 6 分样本。

## 三段式核心逻辑（原文逐字）

```text
1. 输入：历史问答记录 + 当前知识库状态；
2. 处理：结合少量高质量正例与典型负例（few-shot learning），辅以领域规则与扣分项模板；
3. 输出：生成 Q-score 及对应的扣分明细，如"跳步执行"、"引用过时文档"、"未按手册顺序操作"等。
```

## 三大优势

1. 快速发现幻觉与流程错误；
2. 人工复核仅需聚焦 ≤ 6 分坏样本，成本可控；
3. 支持高频监控与能力退化感知。

## 与手册约束的对应

扣分明细项（跳步执行/引用过时文档/未按手册顺序操作）与 [[手册执行者模式]] 的四硬约束一一对应——评分标准即执行约束的度量。

## 演进机制

典型错误样例持续注入评分 Agent 的 few-shot 示例库，形成“**防错—纠错—免疫**”正向演进。

## 定位辨析

与美团 [[高阶模型审查低阶模型]] 的 judge 模式形成定位差异：美团追求对每条产出的**精准裁决**，本方案追求**坏样本的异常检测**——前者是质量门禁，后者是筛出人工复核对象。两者可视为同一评测光谱的两端。
