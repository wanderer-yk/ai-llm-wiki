# 六条核心原则

六条核心原则是 [[smallnest-autoresearch]] 的系统设计基石（4.1 节），正文仅给出各原则的功能定位，**具体文本承载于文章配图（PNG），本来源未提取到原文**。

## 功能结构

- **原则 01**：规则的来源和边界——由 program.md 约束（见 [[program-md规则核心]]）
- **原则 02–05**：构成多 Agent 对抗的质量保证链——回答"谁来做、怎么评、怎么改进"（对应 [[多agent交叉审核]]、[[5维度量化评分]]、[[反馈驱动迭代]] 等机制）
- **原则 06**：全过程可追溯——全量记录（对应 [[results-tsv结构化归档]] 的 results.tsv + workflows/issue-N/log.md）

## 五项缺失后果（正文推演）

1. 无 program.md → Agent 越权
2. 无对抗（交叉审核）→ 自审盲区
3. 无量化门槛 → 退回主观判断
4. 无反馈驱动 → 退化为盲循环
5. 无全量记录 → 无法回溯
