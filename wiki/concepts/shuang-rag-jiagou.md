# 双 RAG 架构

双 RAG 架构是 [[京东物流]][[齐海智]]提出的组合 RAG 策略，将知识工程的代码知识检索能力与 [[joyagent|JoyAgent]] 知识库检索能力相结合，用于构建 [[智能代码评审系统]]。

## 设计动机

现有 AI 评审方案存在两类核心缺陷：

1. **技术 1（流水线+通用大模型）**：[[固定行数截断策略]]导致全局上下文缺失、[[提示词天花板]]、知识无法沉淀
2. **技术 2（JoyAgent 知识库 RAG）**：[[知识归纳失真]]、[[检索与生成联动失效]]、缺乏 [[项目身份感知能力]]

双 RAG 架构旨在通过双路径组合解决单一方案的固有缺陷。

## 完整流程（五步骤）

1. **[[项目身份感知能力|项目类型识别]]**：[[文件扩展名特征识别]]（`.flow`、`.dt` 等），EDI 优先于普通 Java 项目
2. **[[两级分块策略|两级智能分块]]**：文件级分割（git diff 识别文件边界）+ [[代码结构感知分割]]（方法签名正则在自然边界处分割）
3. **知识工程检索**：[[业务领域识别]]→关键词提取与净化→语义搜索
4. **[[bge-本地重排序方案|BGE 重排序]]**：本地部署 `bge-reranker-base.onnx`，解决 [[向量召回质量不均问题]]
5. **双源知识融合生成**：[[双rag知识融合论|双 RAG 知识融合]]，实现"1+1>2"智能涌现

## 核心价值

[[双rag知识融合论]]——将两种不同质不同源的知识（深度代码语义+精准评审规则）通过结构化协同机制融合，实现"1+1>2"的智能涌现。

## 与其他 RAG 方案的关联

双 RAG 架构与 [[code-insight]]（有赞 RAG+AST+符号表）、[[六步智能提示词生成法]]（转转 AST+Sonar）形成跨团队代码评审方法论谱系。其独特贡献在于**双路径知识融合**和 [[项目身份感知能力]]，回应了 [[rag技术瓶颈]]中跨文件/调用链分析的固有局限。
