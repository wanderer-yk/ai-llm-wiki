# Skill 四类型分类法

Skill 四类型分类法是 Writing-Skills（[[superpowers插件]]）提出的 Skill **内容类型**分类：按 Skill 强制/指导/启发/参考的行为性质分为四类，每类绑定专属测试方法与成功标准，构成 Skill 评测的可复用测试矩阵。

## 四类型 × 测试 × 成功标准

| Skill 类型 | 定义 | 测试方法 | 成功标准 |
|---|---|---|---|
| 纪律执行型 | 强制遵守规则（如 TDD、验证要求） | 压力场景：时间+沉没成本+疲劳组合施压 | Agent 在最大压力下仍遵守规则 |
| 技术指导型 | 具体方法的操作指南（如条件等待、根因追踪） | 应用场景：能否正确应用？边界情况？指令有无缺口？ | Agent 成功将技术应用到新场景 |
| 思维模式型 | 解决问题的心智模型（如降低复杂度、信息隐藏） | 识别场景：能否识别何时适用？何时不适用？ | Agent 正确判断何时/如何应用模式 |
| 参考资料型 | API 文档、命令参考、库指南 | 检索场景：能否找到正确信息？常见用例是否覆盖？ | Agent 找到并正确应用参考信息 |

## 测试强度差异

纪律执行型测试最严格（需压力场景 + [[合理化借口反驳]] 堵漏）；参考资料型主要测可发现性与完整性（与 [[description只写触发条件]] 直接相关——description 即其可发现性载体）。

## 跨厂商对照

与 Google 侧 [[skill五种设计模式]]（内部逻辑设计模式）构成跨厂商双分类法对照：四类型回答"Skill 写什么内容"，五模式回答"内部逻辑怎么设计"。两者的映射关系来源未给出，见 [[queries/五种设计模式与四类型分类法如何映射|五种设计模式与四类型分类法如何映射]]。
