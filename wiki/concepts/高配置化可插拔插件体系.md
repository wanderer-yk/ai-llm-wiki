# 高配置化可插拔插件体系

高配置化、可插拔工程体系是应对「业务需求高度不确定」的架构对策：抽象 AI 搜索核心领域模型与通用组件，复用主搜业务编排能力，使 Prompt/Tool/SOP 均可配置热更新并支持细粒度实验——业务方向调整频繁、一年内多次大版本迭代时，无需改动代码即可完成能力替换与实验。

工程载体是 [[xLangchain]]（[[langchain]] 的 Java 实现）：配置化封装大模型调用，内置 AB 实验、版本管理与插件机制，确保单一能力点变更不影响整体系统稳定性。

## 与近义页的区分

- **[[prompt插拔架构]]**（方法论单物）：那是对 prompt 单一对象的"prompt=代码"设计四步法；本页是**体系级**工程对策（领域模型抽象+组件复用，Prompt/Tool/SOP 三物皆配置热更新，载体 xLangchain）——前者被包含于后者，范围不同。

## 与既有概念的关系

- 与 [[prompt插拔架构]]（智空间来源）同构——均以「配置化 + 可插拔」隔离高频变更；是否合并为一页待裁决。
- 与 [[能力抽象对象迁移]] 互补：前者解决「如何快速换能力」，后者回答「抽象的对象是什么」。
- 与 [[务实演进业务先行]] 构成一对策略：业务先行解决「何时建」，可插拔解决「如何快速改」。
