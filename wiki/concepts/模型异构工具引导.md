# 模型异构工具引导

模型异构工具引导是 [[hermes-agent]] 在 Prompt Engineering 维度的设计：针对不同模型在工具调用上的“性格差异”，通过配置项 `agent.tool_use_enforcement` 动态注入工具使用 Prompt 补丁，做到“因材施教”。

作者自注：“其实也算 Harness 设计的范畴，因为主要是加提示词就放在 Prompt 部分讲”——即该机制在分类上横跨 Prompt 与 Harness 边界（参见 [[harness-engineering]] 的边界讨论）。

## 模型“性格差异”（来源观察）

- **Claude**：训练时强调工具使用，不需提醒；
- **GPT/Codex**：容易“只说不做”；
- **Gemini/Gemma**：需提醒使用绝对路径、先读后改、并行调用。

## 配置树（原样保留）

```
配置项 agent.tool_use_enforcement 可以是：
├── "auto"（默认）→ 根据模型名自动判断
├── true → 强制注入
├── false → 不注入
└── ["gpt", "gemini"] → 只对列表中的模型注入
```

## 专属指导细则

- **GPT 专属**：必须用工具的场景（写文件、执行代码、终端命令、网页搜索）；禁止幻觉（不能编造文件路径、API 地址）；执行后验证（修改文件后要确认、测试代码要验证输出）。
- **Gemini/Gemma 专属**：始终使用绝对路径（不用相对路径）；编辑前先读取文件确认内容；多个独立操作要并行调用工具。

配套的跨生态配置兼容见 [[生态兼容配置迁移]]。
