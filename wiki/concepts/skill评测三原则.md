# Skill 评测三原则

第 04 章的核心命题：**像对待 Prompt 一样对待 Skill**。Skill 是给概率性系统写的指令，无法靠直觉判断好坏——"我觉得写得挺好"与"各场景表现稳定"隔着数轮迭代，只能靠真实场景反复测试验证。据此提出三条评测原则：

1. **分层评测**：Description 与 Body 是两个评测对象，评测方法、标准、迭代策略完全不同——Description 评触发精准度（[[skill触发评测方法]]），Body 评输出质量（[[skill-body评测对照实验]]）。
2. **对照实验**：基线 = 裸跑（新建 Skill 时）或上一版本（改进 Skill 时）；没有对照组，改进无从衡量。
3. **人类参与**：自动化评分管格式/结构/字段完整性；审美、业务适配、专业深度只有人能评。
