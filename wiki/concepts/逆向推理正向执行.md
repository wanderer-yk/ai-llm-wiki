# 逆向推理正向执行

"逆向推理、正向执行"是复杂指令场景方案（[[复杂指令场景方案]]）中的创新工具链推导算法：从目标工具出发**反向追溯依赖**，再**正向串成工具链**执行；LLM 负责生成工具链条，实际调用经 MCP 协议进行。

## 四步流程（原文示例：发券指令）

1. **目标工具筛选**：从发券目标出发，找到能完成发券的工具A
2. **依赖分析**：工具A需要用户ID作为输入，但当前指令没提供
3. **上游追溯**：找到能查询用户ID的工具B
4. **形成工具链**：工具B（查询用户ID）→ 工具A（发放优惠券）

## 安全执行

工具链执行内置 [[四重安全校验]]（环境校验 / 读写类型校验 / 功能匹配校验 / 权限与影响面校验）。

## 关联

- "先规划链条再执行"的思路与 [[plan-and-execute模式]] 同构，但规划对象是工具依赖图而非任务步骤。
- 经 MCP 协议调用，与 [[mcp]] 生态衔接。
