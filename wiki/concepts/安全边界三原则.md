# 安全与边界的 3 条原则

"安全与边界的 3 条原则"是 [[青斧]] 在文章 4.3 节给出的 Skill 安全维度通用原则，将防偷懒之外的"安全边界"补入写作技巧体系：

| 原则 | 做法 | 示例来源 |
|------|------|----------|
| 安全默认值 | 默认选择最安全的选项 | vercel-deploy："Always deploy as preview" |
| 权限最小化 | 只在必要时提升权限 | vercel-deploy："Do not escalate the installation check" |
| 人类兜底 | 不确定时交给人 | TDD："ask your human partner" |

三条原则均有 verbatim 英文原句证据，分别对应"默认态安全""权限态收敛""异常态交接人"三个层面。跨源互证：人类兜底 ↔ [[human-in-the-loop]] 系概念群；权限最小化 ↔ [[agent权限边界清单]] 与 [[agent-control-plane]]（权限/边界/审计的控制平面视角）。这三条可视为 Skill 文本层对 Agent 权限边界的最小实现。
