# LLM 弱约束记忆决策

LLM 弱约束记忆决策是本来源对 [[openclaw]] 记忆系统的核心批评视角：记忆全流程（写入/演进/召回）由 LLM 以"弱约束"方式驱动决策——只有方向性建议（AGENTS.md 模板的 "capture what matters"），没有结构化提取规则与强制模板——导致实际记忆效果不稳定，即标题中的"玄学效果"成因。

## 证据点

- **写入**：是否写入、写入什么、什么格式，完全由 LLM 单次推理自主决定（案例：名字/城市/饮食偏好只记住名字）。
- **默认晋升**：心跳维护是否执行、何时执行、整理质量均无保证（"灵活但不确定"）。
- **召回**：Agent 检索意识与查询精准度不可控。

## 精化：确定性管线的语义盲区

Dreaming 系统以机械规则（Jaccard 去重、六维统计评分）替代 LLM 决策，提供确定性路径，但引入新的失效模式：字面去重无法捕捉语义近似、统计评分无语义判断（"花生过敏"类低频重要信息被埋没）、Cron 跨日延迟。精化表述：**管线确定性 ≠ 记忆正确性**——"玄学"的完整归因是三层结构：弱约束写入 → 确定性管线的语义盲区 → 召回配置制约（详见 [[原生记忆不确定性链路]]）。

## 解法谱系

- 结构化 Prompt 约束 + 强制规则 + LLM 参与每次决策（[[RDSClaw]]）；
- 或如 [[gigo原则]] 所示：输入侧的质量决定整个管线输出上限。
