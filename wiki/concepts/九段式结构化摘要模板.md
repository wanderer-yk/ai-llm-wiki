# 九段式结构化摘要模板

**九段式结构化摘要模板**是 [[claude-code]] Full LLM Compact 层（`services/compact/compact.ts` 的 `compactConversation`）强制 LLM 按固定 9 段输出压缩摘要的模板，使"摘要"从自由文本升级为结构化、可被下游消费的产物。

## 9 段结构（原文还原）

```markdown
1. Primary Request and Intent
2. Key Technical Concepts
3. Files and Code Sections
4. Errors and fixes
5. Problem Solving
6. All user messages
7. Pending Tasks
8. Current Work
9. Optional Next Step
```

## 三重工程保障

1. **隐式思维链摘要**：先在 `<analysis>` 标签内推演、再在 `<summary>` 中输出，返回时 `<analysis>` 被程序剥离（防推理泄露，思路与 [[agent轨迹]] 处理相通）。
2. **反工具调用保护**：`NO_TOOLS_PREAMBLE` 强约束禁止压缩过程调用任何工具（原文："工具调用将被拒绝，且会浪费你唯一的一次机会"），防副作用。
3. **9 段强制结构**：防偷懒、防漏项。

三者合称防偷懒/防幻觉/防副作用三重保障。该层由 [[autocompact水位线机制]] 的回退链触发，是三层压缩（[[三层上下文压缩]]）中成本最高、精度最高的一层。
