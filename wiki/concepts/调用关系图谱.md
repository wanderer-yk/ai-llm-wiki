# 调用关系图谱

基于 [[ast加符号表联合分析|AST+符号表]] 构建的程序调用网络，是 [[code-insight|Code Insight]] 系统的核心输出之一。支持方法级别的精准调用链追踪和[[影响范围分析]]。

## 构建方式

1. **AST 解析**：提取函数调用关系骨架
2. **符号表补全**：关联标识符的定义位置、类型、作用域
3. **图谱生成**：构建完整的调用网络

## 典型链路示例

method3 → method5 → method1 → Dubbo API

通过调用关系图谱，可以精准追踪任意修改点的影响范围。

## 应用场景

### 影响范围分析
代码修改后自动推导受影响的上游调用链路和 API 接口。回答"改了这个函数，会影响哪些接口？"

### 测试用例生成
基于[[影响范围分析]]推导受影响 API 接口，结合大模型理解改动点后自动生成[[测试用例生成|测试用例]]建议。

### TraceAI 排障
将调用关系图谱与链路追踪日志结合，Agent 自主进行线上问题定位（详见[[traceai排障]]）。
