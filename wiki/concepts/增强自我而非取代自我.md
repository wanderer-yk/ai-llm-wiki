# 增强自我而非取代自我

[[zhiyuanfu]] 文章的终极哲学立场。AI 的目标是扩展人的能力边界而非替代人，人的角色从微观调度者退为宏观目标设定者。

## 核心论点

- 瓶颈不是能力不足，而是注意力有限
- 解决方案是让系统不依赖人的实时在场
- 真正的跃迁不是让 AI 多做几个步骤，而是让人退出微观调度
- 每一步认知转折都不是提前设计好的，是被实践逼出来的

## SDD 五层地基链路

```
spec.md (需求→目标)
  → plan.md (目标→方案)
    → tasks.md (方案→步骤)
      → constitution.md (经验→约束)
        → eval/trace/policy (系统→可观测可治理可迭代能力体)
```

这五层文件构成无人值守系统的完整地基，Goal-Driven 是下一站——系统围绕目标自主前进。
