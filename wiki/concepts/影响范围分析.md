# 影响范围分析

代码修改后自动推导受影响的上游调用链路和 API 接口的能力，是[[调用关系图谱]]的核心应用之一。

## 技术实现

基于 [[ast加符号表联合分析|AST+符号表]] 构建[[调用关系图谱]]，当某个函数/方法发生变更时，沿调用图谱反向追溯所有上游调用者和暴露的 API 接口。

## 典型场景

开发者修改了 method3 的实现，系统自动推导出影响链路：
method3 → method5 → method1 → Dubbo API

从而回答"改了这个函数，会影响哪些接口？"这一关键问题。

## 应用价值

1. **[[测试用例生成]]**：基于影响范围推导受影响 API，结合大模型生成测试用例
2. **[[traceai排障]]**：结合链路追踪日志定位问题根因
3. **代码审查**：辅助评估变更风险

## 跨团队关联

美团 [[pre-pr机制]] 中 AI 审查代码改动的实践，本质上也需要影响范围分析能力，但美团未透露具体技术实现；有赞 Code Insight 提供了完整的 AST+符号表技术方案。
