# 实体权重计算模型

实体权重计算模型是 [[货拉拉]] GraphRAG 方案2.0 中的核心排序机制，通过多因子加权为 [[graphrag三类实体设计|三类实体]]计算分数，用于检索结果排序和召回优化。

## 计算公式

### 表实体分数

```
表分数 = manual_boost × (w1×下游依赖 + w2×热度 + w3×星标)
```

- **manual_boost**：人工加权因子，可针对高价值表进行手动提升
- **下游依赖**：该表被下游表/任务依赖的数量
- **热度**：该表的查询/使用频率
- **星标**：用户/管理员对表的收藏标记

### 字段实体分数

```
字段分数 = manual_boost × (w4×基础分 + w5×表因子)
```

- **基础分**：字段本身的固有分值
- **表因子**：所属表实体的分数，使字段继承表的权重

### 业务术语/缩写词实体分数

```
术语分数 = 1
```

术语实体使用固定分值，不参与动态权重计算。

## 设计动机

该模型直接针对 [[badcase五分类]]中的"无关信息干扰"问题：通过多因子加权排序，高价值、高频使用的表/字段在检索结果中获得更高排名，低相关度实体的干扰被有效抑制。

## 与其他权重机制的对比

- 与 [[知识优先级机制]]（有赞）对比：有赞通过 Prompt 定义不同知识源的优先级规则解决信息冲突；货拉拉通过多因子加权计算实体分数优化检索排序，两者分别从"检索后排序"和"注入时优先级"两个层面解决知识质量问题。
