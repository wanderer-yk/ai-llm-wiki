# 代码结构感知分割

代码结构感知分割是 [[两级分块策略]]的第二级策略，利用方法签名正则在自然边界处分割，最大限度保持代码语义完整性。

## 技术实现

利用方法签名正则模式：
- 修饰符：`public` / `private` / `protected`
- 返回类型
- 方法名
- 参数列表
- `{`（方法体开始）

在方法/类的自然边界处进行分割，使用 `MULTILINE` 模式匹配多行代码。

## 价值

- 避免在方法内部随意截断，保持方法逻辑完整性
- 每个分块包含完整的语义单元（方法/类）
- 为后续 RAG 检索提供语义连贯的上下文

## 与 AST 方案的关联

代码结构感知分割与 [[ast加符号表联合分析]]（有赞 Code Insight）有理念上的相似性——都利用代码结构信息提升检索质量。但京东方案使用轻量级正则匹配，有赞方案使用完整的 AST 解析，两者在精度和复杂度上形成梯度。
