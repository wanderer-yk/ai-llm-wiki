# 知识归纳失真

知识归纳失真是技术 2（JoyAgent 知识库 RAG）的核心缺陷。LLM 对 Code Diff 进行知识归纳/总结时不稳定，经常遗漏或曲解关键上下文。

## 根因分析

LLM 的总结过程本质上是一种有损压缩，在代码评审场景中：
- 代码语义高度精确，任何遗漏或曲解都可能导致评审失效
- 不同运行次的结果随机性大，无法稳定复现
- 复杂的代码逻辑链条难以被简单总结概括

## 影响

知识归纳失真直接传导至后续环节，引发 [[检索与生成联动失效]]：基于失真结果做 RAG 检索→召回匹配度低→未经重排序→送入不完整上下文→生成不可靠评审意见。

## 解决方案

[[双rag架构]]通过知识工程层的代码知识检索直接提供精确的代码语义，绕过 LLM 知识归纳步骤，避免失真问题。
