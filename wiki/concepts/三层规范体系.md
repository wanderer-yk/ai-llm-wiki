# 三层规范体系

三层规范体系是 [[阳凯]] 在得物技术基于 [[claude-code]] 的 Spec Coding 实战中提出的项目级规范组织框架：将约束 AI 代码产出的项目知识按职责拆分为三层——约束层（告诉 AI「禁止什么、必须怎样」）、示范层（告诉 AI「标准产出长什么样」）、视觉层（告诉 AI「页面应该长什么样」），分别落在 `.claude/rules/`、`.claude/code-design/`、`.claude/ui-design/` 三个目录，并以 CLAUDE.md 作为规范补充载体。其核心论证是：只有约束层会产生「合法但不地道」的代码，示范层与视觉层提供「对齐锚点」后，生成代码的质量与团队一致性才明显提升（即 [[约束非能力论]]）。

## 目录结构

```text
第一层：约束层（.claude/rules/）      ← 告诉 AI「禁止什么、必须怎样」
第二层：示范层（.claude/code-design/）← 告诉 AI「标准产出长什么样」
第三层：视觉层（.claude/ui-design/）  ← 告诉 AI「页面应该长什么样」
```

## 约束层：7 个规范文件

```
.claude/rules/
├── ts.md          # TypeScript 规范（禁止 any、使用可选链等）
├── code-names.md  # 命名规范（kebab-case/camelCase/PascalCase）
├── comment.md     # 注释规范（JSDoc、@ai-context/@ai-rules 文件头）
├── lint.md        # 代码风格（单引号、文件末尾换行）
├── style.md       # 样式规范（Tailwind CSS、less 文件）
├── pages.md       # 页面目录结构规范（constants/services/hooks/components 分层）
└── service.md     # API 接口生成规范（fetch{Name}Api 命名、UniversalResp 泛型）
```

## 示范层：6 个标准模板

```
.claude/code-design/
├── pro-table/           # 通用列表页模板（含搜索、分页、批量操作、行操作）
├── pro-form/            # 通用表单页模板（含创建/编辑双模式、字段验证）
├── editable-pro-table/  # 可编辑表格模板（含行内编辑、添加/保存/删除）
├── drawer/              # 抽屉组件模板（含标准打开/关闭逻辑）
├── compontent/          # 通用组件模板（含 README、Props 定义、使用示例）
└── utils/               # 工具函数模板
```

作者明言示范层模板「后续可以切换为 skills」——模板→Skill 的演进路径衔接 [[skill知识沉淀机制]]（得物前文）与腾讯 [[生产级skill]]。pro-table 实证「一次生成符合团队风格的代码，无需多轮调整」。

## 视觉层：HTML 设计稿

`.claude/ui-design/` 存放 knowledge-spaces.html（知识空间列表页）、search-strategy.html（检索配置页）、space-detail.html（空间详情页）等高保真设计稿。HTML 稿生成 UI 的吻合度「明显高于纯文字描述」，与 Persona 设计流程（对话式生成高保真 HTML → 作为上下文生成组件行为级 PRD）共同构成「设计阶段前置为上下文源」。

## 实际效果（自报口径）

正面 4 例：205 个文件保持 `fetch{Name}Api` / `I{Name}Req/Res` 命名一致、目录分层被遵守、模板被继承、可选链普及。人工干预 3 例：2/24 单文件不分层（一条追问修复）、2/27 `.less` 误用（项目实际配置 SCSS，即时修正）、antd v5 废弃 API（`destroyOnClose`/`dropdownStyle`，AI 沿用训练数据中高频的 v4 习惯，靠构建报警触发修正）。

## 谱系与关联

- 应对 [[AI失效三模式]] 中的「规范真空」：在 CLAUDE.md 或 code-design 补充规范，一次修复全局生效；
- 与 [[系统提示词护栏论]]（得物前文）、[[ai友好研发规范]]（美团）、[[知识库降熵论]]（有赞）同属「用结构化规范包裹 AI 执行」谱系；
- 约束层/示范层/视觉层的分层逻辑可与天猫 [[代码约束提高迭代生码成功率]] 对照。
