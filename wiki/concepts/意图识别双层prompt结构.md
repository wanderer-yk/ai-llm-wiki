# 意图识别双层 prompt 结构

意图识别双层 prompt 结构是 [[prompt插拔架构]] 以意图识别核心 Agent 为例的完整展开：框架 prompt 与业务定制构成**功能抽象层 + prompt 结构层**的双层契约——通用逻辑由框架固化，业务差异由创建者以"填空"方式注入，实现"配"而非"写"。

## 意图识别 Agent 三目标

- 理解用户语义，确保语义完整
- 解析指令，规范输出
- 意图分类（可选）

## 双层结构表（原文保真）

| | 框架 prompt | 业务定制 |
|---|---|---|
| 功能抽象 | 语义结构；输出格式；步骤拆解逻辑；追问逻辑；归一化逻辑 | 意图分类；归一化词表；案例声明 |
| prompt结构 | 角色定义（职责；原则）；输出模型定义（IntentResult）；深层语义结构识别；意图分类（通用意图；业务定制）；信息抽取与字段规则（如何从query中抽取元素，组装IntentResult）；语义完整与追问逻辑；语义归一化；特殊场景处理 | 业务说明（业务信息补充）；意图定义（分类）（意图定义、说明；意图分类方法；数据完整性校验（可选））；归一化词表（动作、实体）；案例说明 |

- 输出模型为 [[IntentResult模型]]（七字段结构化意图）。
- "框架prompt--插桩"截图（100075314/100075312）与"业务定制模版"截图（100075311）展示了插桩语法与定制界面，prompt 全文未披露。
- 业务定制模版结合前端产品设计开放模块，由助手创建者填写（原文"又助手创建者填写"疑为"由"之笔误）。

## 关联

- 输出模型定义与 [[结构化输出]]、[[知识优先级机制]]（业务优先级经 prompt 注入）呼应。
