# 自我说服效应

百度Geek说《Harness Engineering》提出的小概念：**同一会话中的历史推理会让 Agent 偏向自认正确**——先前自己生成的论证成为后续判断的"证据"，Agent 倾向于维护而非推翻自己。

## 推论

- Evaluator 校验**必须使用独立会话**：新会话不带执行者的推理历史，才能以中立视角评判产出；
- 进一步可叠加 [[跨模型评估]]：执行与评估使用不同模型，消除同源偏见。

## 在体系中的位置

自我说服效应是 [[双轨校验]] 中"Evaluator 轨道"独立性的理论依据，也是 [[批判性evaluator校验]] 三角色架构（主 Agent 编排 / subAgent 执行 / Evaluator 评估）中评估角色必须单独成角色的原因。
