# Harness 核心价值三元组织论

本文全文的最终定义句（逐字）："**Harness 最核心的价值：把模型能力、工具能力和人的判断，组织成一条稳定可控的生产流程。**"

## 三个组织对象与一个目标

- 三元并列：模型能力、工具能力、**人的判断**。
- 目标：一条**稳定可控**的生产流程。
- 关键点："人的判断"被显式纳入生产流程的组织对象，而非流程外的兜底——与实战中各级人工门控点（Plan 检查点五项对齐、首章验收四问、全网页逐步点验、音频清单人眼校对）前后呼应。

## 与既有概念的关系

- 与 [[agent框架三要素]]（LLM Call + Tools Call + Context Engineering）形成对照：三要素不含显式的"人的判断"，三元组织论将其升格为流程一等公民。
- 与 [[agentic-engineering]]（人定义目标/约束/质量标准，AI 在结构化流程中自主执行）同构。
- 与"编排优先于模型能力论"互为表里：编排是手段，三元组织是定义；为 [[脚手架优于模型]]、[[agent生产落地环境重构论]] 提供了独立创作者版本的跨团队印证。
