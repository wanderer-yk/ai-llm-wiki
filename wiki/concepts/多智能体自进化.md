# 多智能体自进化（Self-Evolving Agent System）

多智能体自进化（Self-Evolving Agent System）是 [[阿里商旅]] 在 [[aligo]] 差旅助手文章"未来规划"章中提出的持续进化方案：通过三要素替代传统"人工复盘 + 手动调优"的迭代方式，动机是人工迭代效率低、响应慢，难以支撑系统持续进化。

**状态标注（重要）**：截至文章发表（2026-02-14），该方案为**规划声明**而非已实现能力，三要素均无实现细节与落地数据，引用时必须区分于已实现案例。

## 三要素

| 要素 | 说明 |
|------|------|
| 冷启动优化 | 自进化方案组成之一（细节未披露） |
| 主动发现异常 | 替代被动人工排查（细节未披露） |
| Prompt 优化智能体 | 以智能体自动优化 Prompt 替代手动调优（细节未披露） |

## 思想族定位

与以下跨团队实践同属"系统自我优化"思想族：

- [[数据自迭代]]（马上消费）：AI 质检 + 数据反馈驱动的持续自我优化闭环（已实现）。
- [[反馈回灌闭环]]（问诊小助手）：评分 agent 坏样本聚焦 + 反馈回灌（已实现）。
- [[agent评测四要素]]（有赞）：评测反馈闭环作为框架要素。
- [[知识复利效应]]（有赞共享技术）：知识沉淀价值随规模加速释放。

区别在于：阿里商旅是本组中唯一明确提出"以智能体优化智能体"（Prompt 优化智能体）的方案。
