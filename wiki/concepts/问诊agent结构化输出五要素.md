# 问诊 Agent 结构化输出五要素

问诊 Agent 结构化输出五要素是 [[两类能力形态抽象]] 带来的直接收益：两类形态的 Agent 输出被统一约束为固定的五段结构，使输出**可解析、可评估、可运营、可迭代**——这是 [[q-score质量评分机制]] 能够对每条回答打分、[[反馈回灌闭环]] 能够定位扣分根因的前提。

## 五要素

1. **结论**
2. **分析解释**（规则/口径）
3. **排查计划**（可选）
4. **动作建议**
5. **文档引用**

## 与评估体系的关系

五要素使“回答质量”从整体印象拆解为可逐项核查的维度：结论是否正确、分析是否引用了正确口径、排查步骤是否合规（对应 [[手册执行者模式]] 的跳步/改序/加步扣分项）、建议是否可执行、是否附带了可追溯的参考文档链接（提示词硬性要求“提供参考链接，包括来源的标题和URL”）。
