# LLM 不确定性物理不可消除

即使 Temperature=0、top-k=1，LLM 输出仍然不确定。[[韩春]] 将其归因为工程与物理层面、无法通过采样策略消除的现象，并提出"我们无法消除一个无法被消除的东西，只能理解并接受"。

## 三因归因（Temperature=0/top-k=1 仍不确定）

1. **工程**：MoE 只激活部分神经元（如 DeepSeek R1），复杂度转移到 Router 与负载均衡函数；
2. **硬件浮点精度**：FP16/BF16 误差累积到 Token 概率，argmax 漂移后后续生成路径根本改变；
3. **硬件异构**：A100/H100 等不同显卡的细微差异。

## 关键公式（原样保留）

```text
不确定性 = f(数值精度，硬件异构，运行时架构，采样策略 等)
```

## 厂商主动让渡

不确定性不仅是物理约束，也是基座厂商在推理阶段为低成本高吞吐主动让渡精确性的选择。

## 语义层补充

自然语言不如数学公式严谨 + Attention 机制致长 Context 语义丢失，使信息失真同样根本不可避免（见 [[observation语义空间受限]]）。这一双层不可消除性是 [[概率级联故障]] 与 [[agent开发经验主义]]（参数只能靠实测）的共同根源。
