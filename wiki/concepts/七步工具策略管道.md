# 七步工具策略管道

七步工具策略管道是 [[openclaw]] 工具系统中 `applyToolPolicyPipeline()`（tool-policy-pipeline.ts:65）实现的逐级工具过滤机制：工具列表依次经过七层策略过滤，输出最终可用工具集。它是 [[agent-control-plane]]（权限/边界/审计分层控制）思想在工具维度的直接体现。

## 七层过滤顺序（优先级从低到高）

```text
Profile Policy → Provider Profile → Global Policy → Agent Policy
    → Group Policy → Sandbox Policy → Subagent Policy
```

关键语义：优先级**从低到高**，越靠后的策略越具体、越后生效——Subagent Policy 最具体，最后覆盖前面的策略。

## ToolPolicyConfig 配置结构

```typescript
type ToolPolicyConfig = {
  allow?: string[];      // 白名单
  alsoAllow?: string[];  // 追加白名单（合并到 allow）
  deny?: string[];       // 黑名单
  profile?: "minimal" | "coding" | "messaging" | "full";
};
```

四档 profile 为预置策略模板（minimal/coding/messaging/full），各自包含的具体工具清单源文未给出，待官方源码核证。
