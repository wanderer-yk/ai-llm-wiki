# 记忆资产跨系统迁移

记忆资产跨系统迁移指 Agent 的记忆不锁定在单一框架内、可随标准化接口在不同系统间流转的能力。来源文章将这一能力归于 [[hermes-agent]] 对外部记忆中间件的原生对接：Mem0、Honcho、Hindsight、Supermemory 等服务以标准接口接入，使用户积累的记忆成为可携带资产而非框架绑定物。

## 机制基础

- 外部记忆以插件形式接入（见 [[插件化生态扩展]]），依赖标准接口而非核心代码耦合
- 与 [[内外双驱记忆架构]] 的外层"动态扩展"直接对应：内层文件保稳定，外层标准接口保开放

## 意义

- **反锁定**：用户更换 Agent 框架时记忆资产可随行，显著降低迁移成本
- **与配置层兼容互补**：[[生态兼容配置迁移]] 解决配置文件层面的兼容（`AGENT.md`/`SOUL.md`/`USER.md`、`CLAUDE.md`、`.cursorrules` 等），记忆资产跨系统迁移则解决记忆层面的兼容，两者共同压低 Agent 生态的切换成本
- 沉淀的记忆因此具备 [[知识复利效应]] 式的长期价值：随时间与规模增长加速释放
