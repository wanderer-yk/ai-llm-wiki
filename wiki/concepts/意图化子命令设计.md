# 意图化子命令设计

"意图化子命令设计"是 [[code-wiki]] CLI 的接口组织原则：**子命令按 Agent 的意图（impact/deps/callers）而非底层技术（graph-match vs SLS SQL）组织**，使 Agent 无需感知底层查询引擎差异即可完成结构化推理。

## 设计要点

- `code-wiki query impact <path>` 表达的是"变更影响分析"这一意图，背后可能是 graph-match 图遍历、也可能是 SQL 聚合直查。
- 底层差异（拓扑遍历 vs 聚合统计）由 [[两步查询模式]] 与直查路由消化。
- 与 vivo [[agent架构四决策]] 中"工具查找"决策、[[渐进式工具加载]] 的工具组织策略同主题：工具接口面向任务语义而非实现机制。

## 效果

- 缩短 Agent 从"意图"到"命令"的映射距离，减少试错轮次。
- 案例一实证：子 Agent 通过 search→context→impact→check hotspots 的渐进式推理链完成影响评估，每条命令 1-3 秒（自报 Demo）。
