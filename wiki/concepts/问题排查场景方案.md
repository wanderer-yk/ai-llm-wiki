# 问题排查场景方案

问题排查场景方案是四大场景方案之一，处理"从表象（问题描述）到根因的 RCA 过程：表象 → 可能原因 → 根因"的场景（案例：金融答疑助手）。挑战在于不断试错（排除法）、多轮执行、人工经验指导与交互话术（系统异常到语言表达）（架构图 img 100075310）。

## 方案构成

- **意图路由**：[[意图路由]]——业务咨询类走知识问答流程，查询排查类走 ReAct 推理流程。
- **人工经验指导**：嵌入 prompt（专家排查经验作为知识注入）。
- **ReAct + 执行引擎**：[[ReAct推理模块]]（只思考不执行）+ [[ReAct双引擎场景适配]]（按场景选型执行引擎）。
- **创新点**：prompt 框架 + 定制模式（[[prompt插拔架构]] 在该场景的落地，配套 [[排查助手定制三问]] 方法论与资深编辑模式）。

## 关联

- RCA 三段式与 [[traceai排障]]（Agent 自主结合代码问答+链路追踪定位线上问题）同题异构。
- "沉淀过程而非结论"的定制原则与美团 [[专家经验定向ai辅助排查]]（人定向+AI穷举+人裁决）呼应。
- 选用核心能力层的"反思推理"模块（[[智空间分层解耦架构]]）。
