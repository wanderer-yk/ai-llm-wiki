# 双提取方式

双提取方式是 [[RDSClaw]] 自进化记忆管线的提取路径设计：LLM 提取（默认）与正则提取并存，在语义强度与成本/速度之间提供两档选择。

| 方式 | 输入 | 输出 | 特点 |
|---|---|---|---|
| LLM 提取（默认） | User + Assistant 消息组合 | 结构化 `{category, text, importance}` 数组，每轮最多 5 条 | 语义强，理解上下文 |
| 正则提取 | 消息文本关键词匹配 | 命中 `学习：`/`错误：`/`lesson:` 的条目 | 轻量级、零 LLM 依赖、快速 |

## 未披露细节

正则提取与 LLM 提取的启用/选择机制（配置项？并行？）未披露；`importance` 字段在召回时的实际作用未说明。

## 对照

个人记忆管线（[[两阶段实时记忆管线]]）为 LLM 结构化提取 + 强制规则单路径；自进化记忆管线的双提取体现了按记忆类型分级投入提取成本的思路。结构化输出格式 `{category, text, importance}` 与 [[结构化输出]]（基于 Function Calling 的可靠解析）理念一致。
