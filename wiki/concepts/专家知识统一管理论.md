# 专家知识统一管理论

[[书牧]]（[[天猫技术]]）的架构主张：专家知识建设应独立于各个 AI Agent 体系，具备全局视野且可被跨团队复用，而非各自建设。

## 与现状的矛盾

当前存在 [[知识库全局复用缺失]] 和 [[规模效应断裂论]]——各团队各自为政导致知识重复、缺少全局规划。

## 与既有方案的路线分歧

与 [[knowledge-wiki]]（有赞，以 Git submodule 跟随代码仓库）、[[code-insight]]（有赞，绑定代码搜索）存在架构路线分歧——天猫主张知识独立于 Agent 体系集中管理。
