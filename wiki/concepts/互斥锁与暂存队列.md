# 互斥锁与暂存队列

互斥锁与暂存队列是单线程 Node.js 环境下保护共享 `history` 数组的最简并发控制模式（文章原话「布尔互斥锁 + 暂存队列」）：用布尔标志 `processing` 保证同一时刻只有一个 `agent.run()`，子 Agent 结果先 push 到 `pendingSubagentResults` 暂存队列，`tryDrainPending` 在锁空闲时批量 drain。它是 [[同步异步双路径]] 得以安全共存的关键机制，也是 [[薄抽象设计哲学]] 的实例——不用并发库，一个布尔标志 + 数组显式实现。

## 完整实现（苏雄 800 行框架）

```javascript
let processing = false;
const pendingSubagentResults: InboundMessage[] = [];
async function drainPendingResults(): Promise<void> {
  while (pendingSubagentResults.length > 0) {
    const msg = pendingSubagentResults.shift()!;
    const systemContent = [
      "[SYSTEM NOTIFICATION - Subagent Result]",
      msg.content,
      "Please summarize the above subagent result for the user.",
    ].join("\n\n");
    const reply = await agent.run(systemContent, history);
    history.push({ role: "user", content: systemContent });
    history.push({ role: "assistant", content: reply });
    console.log(`\nBot > ${reply}\n`);
  }
}
async function tryDrainPending(): Promise<void> {
  if (processing) return;
  processing = true;
  try {
    await drainPendingResults();
  } finally {
    processing = false;
  }
  rl.prompt();
}
```

用户输入 handler（**drain-before-release**：释放锁之前先 drain，「保证子 Agent 结果不会无限滞后」）：

```ts
rl.on("line", async (input) => {
  processing = true;
  try {
    const reply = await agent.run(trimmed, history);
    history.push({ role: "user", content: trimmed });
    history.push({ role: "assistant", content: reply });
    await drainPendingResults();
  } finally {
    processing = false;
  }
  rl.prompt();
});
```

订阅 handler 两步模式（「handler 只做两件事：入队、尝试消费」；`void ...catch(console.error)` 防未处理拒绝）：

```js
bus.subscribe("system", (msg) => {
  pendingSubagentResults.push(msg);
  void tryDrainPending().catch(console.error);
});
```

## 机制要点

1. **守卫条件**：`tryDrainPending` 仅在 `!processing` 时进入，避免并发写 `history`。
2. **drain 时序**：用户交互完成后、`finally` 释放锁**之前**执行 `drainPendingResults()`。
3. **无竞态依据**：Node.js 单线程模型保证 `processing` 标志不会出现竞态。
4. **适用边界**（作者明示）：布尔锁在单用户场景足够；扩展到多用户（Bot 多会话）需每会话独立 history + 更完整的队列/锁机制。
