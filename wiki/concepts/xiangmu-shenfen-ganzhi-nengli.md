# 项目身份感知能力

项目身份感知能力是系统自动识别待评审代码所属项目类型（如 [[edi平台|EDI]] 项目 vs 普通 Java 应用）的能力。

## 问题驱动

技术 2（JoyAgent 知识库 RAG）缺乏项目身份感知，无法自动识别 XML 文件属于 EDI 项目，导致检索使用通用 Java 规则而非 EDI 专用规范。这是比 [[知识归纳失真]]更前置的缺陷——在检索方向错误的情况下，后续所有环节都无法正常工作。

## 实现方案

[[文件扩展名特征识别]]：基于文件扩展名（如 `.flow`、`.dt`）精准判断项目类型，EDI 优先于普通 Java 项目。

## 在双 RAG 架构中的位置

项目身份感知是 [[双rag架构]]的首要步骤（步骤 1），项目类型决定后续评审规则选择与 RAG 检索策略。

## 与业务领域识别的关系

[[业务领域识别]]（WMS/ECLP/TC）是项目身份感知在业务维度的延伸，用于进一步精准化检索方向。
