# 代码库模式大于指令

代码库模式大于指令是来源文章技巧 8 引出的核心论断：当自然语言指令与代码库现有模式冲突时，现有代码对 Agent 行为的影响力大于显式指令——AI 倾向模仿现有模式而非遵守提示词约束。

## 实证案例（原文示例）

```cpp
// 你的指令："永远不要使用 any 类型"
// 但现有代码中：
const userData: any = fetchUser();
const config: any = loadConfig();
const response: any = apiCall();
// Ralph 会学习这种模式，继续使用 any
```

## 三因素解释

1. 指令只有几行
2. 代码库是数千行的"证据"
3. AI 的模仿倾向

## 解决方案（技巧 8 三条）

1. 运行 Ralph 之前清理低质量模式（让代码库"证据"与期望一致）
2. 使用反馈循环强制执行标准（[[反馈循环护栏]]）
3. 在 AGENTS.md 中明确质量标准：让期望可见（[[agents-md]]）
