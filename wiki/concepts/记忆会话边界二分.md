# 记忆会话边界二分

记忆会话边界二分是 AI Agent 记忆系统的基础划分框架：以**"是否跨 Session 会话"为判据**（而非时间长短），将记忆分为短期记忆（会话内）与长期记忆（跨会话）。这是柳遵飞（翼严）在《AI Agent 记忆系统》一文中确立的核心概念，三大主流框架虽命名各异，但均遵循这一两分结构。

## 短期记忆四特征

1. 存储当前会话的全部交互消息；
2. 直接作为 LLM 的输入上下文；
3. 实时更新；
4. 受 maxToken 限制，需上下文工程优化（见 [[上下文缩减卸载隔离三分法]]）。

## 双向流动关系

长期记忆与短期记忆**不是单向存档关系，而是双向流动**：

- **向上抽取**：长期记忆从短期记忆中抽取提炼"事实/偏好/经验"，并实时迭代；
- **向下注入**：长期记忆按当前查询反向注入短期记忆，辅助个性化推理。

## 三框架的命名对应

| 框架 | 会话级 | 跨会话级 | 架构定位差异 |
|---|---|---|---|
| Google ADK | Session | Memory | Memory 为长期知识库，可含多次对话信息 |
| [[langchain]] | Short-term memory | Long-term memory | 长期记忆**不属于基础核心组件**，而是高阶"个人知识库"外挂 |
| [[agentscope]] | `memory` | `long_term_memory` | API 层面双组件，功能层面明确区分 |
