# 统一多模态记忆空间如何构建？

## 问题

AI Agent 长期记忆中的文本、视觉、语音等多模态信息目前处于**孤立处理**状态。如何构建统一的多模态记忆空间——让不同模态的记忆可互检、可关联、可统一检索——是《AI Agent 记忆系统》（柳遵飞（翼严））明确指出的**未解难题**（长期记忆三大挑战之一）。

## 已知线索

- 源文参考文献 [5] **O-MEM**（arXiv 2511.13593，https://arxiv.org/abs/2511.13593 ）为全文唯一学术论文引用，正文未展开其在论证中的角色，推测与多模态记忆或参数化记忆趋势章节相关，内容未读——待阅读后评估其对本问题的贡献。
- 有赞 [[多模态知识预学]]：用模型多模态能力（而非 OCR）提取商品信息，处理的是多模态**知识注入**问题，与多模态**记忆空间**不同域，但其"多模态信息统一表征"经验可能可迁移。

## 待研究问题

1. 统一表征应发生在哪一层：嵌入空间（统一 Embedder）、存储层（统一 VectorStore/GraphStore），还是检索融合层？
2. O-MEM（arXiv 2511.13593）是否给出了可行方案？其在正文论证中的角色是什么？
3. 多模态记忆与 [[参数化记忆与外部记忆增强对比]] 两路线如何交互（多模态信息参数化是否可行）？
4. 现有长期记忆产品（[[mem0]]、[[reme]]）对多模态记忆的支持程度如何？
