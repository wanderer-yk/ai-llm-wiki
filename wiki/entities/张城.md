# 张城（元乙）

张城，公开署名采用"张城（元乙）"双名形式，"元乙"为其笔名（署名别名），别名关系由作者本人在文章中自证。据《从可观测到可理解：用 UModel 构建 Agent 原生的代码知识图谱》自述，其在可观测领域工作十多年，并自称属于"阿里云云原生可观测团队"（归属为作者自称）。他是 [[umodel|UModel]] 代码知识图谱方案的提出与阐述者，也是 UModel 相关技术文章的作者，包括前作《如何用 UModel 构建一个会成长的个人 Wiki》（见 [[如何用UModel构建一个会成长的个人Wiki]]）。

## 专业背景

- 据文章自述：可观测领域从业十多年，亲历阿里云可观测从日志/指标/链路零散数据采集演进到面向对象、关系和时序的统一建模（即 [[umodel|UModel]]）的过程。

## 作品与发表信息

- 《从可观测到可理解：用 UModel 构建 Agent 原生的代码知识图谱》作者，发表于微信公众号 [[阿里云云原生]]（IP 属地浙江），2026-04-23。
- 前作《如何用 UModel 构建一个会成长的个人 Wiki》（出处渠道/日期在本文中未给出，待补充，见 [[如何用UModel构建一个会成长的个人Wiki]]）：
  - 确立了 Set/Link/Field 建模与"原始资料 → LLM 抽取 → 对齐 → UModel → Wiki 页面"流程（全程置信度 0.4-0.9）。
  - 代码域版本在其上引入 AST 确定性提取；这一"个人 Wiki → 代码 Wiki"的同范式对照，是 [[个人wiki到代码wiki同范式不同确定性]] 概念的直接来源。

## 文中要点

### 别名自证：分层置信度的自举例证

作者在文中以"张城和元乙是不是同一个人？"作为 LLM 抽取不确定性的自举例证：LLM 无法从文本确定两个署名是否指向同一实体，这类语义归属只能靠 LLM 推断（文中标注为 INFERRED，置信度 0.6-0.9）；文中同时给出 LLM 推断/抽取的置信度区间为 0.4-0.9（个人 Wiki 流程中的抽取全程即此区间）。与之对照，`import pkg/a2a`、`func (s *Server) HandleRequest()` 这类结构关系可被 AST 确定性解析，置信度 1.0。这一对照是 [[ast确定性提取+llm语义增强分层置信度]] 概念的来源与论证起点。

### 范式迁移叙事

将可观测域"从零散数据到 UModel 知识图谱"的演进轨迹，类比为代码理解"从找片段到懂结构"的演进，是全文的叙事骨架。
