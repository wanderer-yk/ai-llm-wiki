# 跨端技术团队

跨端技术团队是淘天集团旗下的核心基础设施团队，自我定位为"淘天集团核心基础设施团队，立足淘宝，专注于构建世界级的多端技术平台"，使命为"驱动终端智能化创新、构建 AI 赋能的研发新基建"。微信公众号"大淘宝技术"文章的作者署名主体（发布主体为 [[大淘宝技术]] 公众号）。

## 技术实践（本来源披露）

该团队维护面向内部开发者的 [[AI答疑助手]]，并是一手执行了以下实验与工程工作：

1. **CoT 意图识别改造**：以 qwen-turbo-latest 实现"识别意图→生成思维过程→生成多组查询→并行召回"四步架构，替代传统串行 query rewriting。
2. **GraphRAG 实验**：选取知识库中某模块 44 篇文档做双栈实验（Streamlit 可视化），确认图结构有效性并实测四大工程困境。
3. **LightRAG 落地**：完成图增强检索在在线答疑场景的工程化，验证秒级响应与三步局部增量更新。
4. **评测体系建设**："好/坏"二元标签升级为三维标注，探索评测 Agent 并发现其"乐观偏差"。
