# 项目注册平台

小红书 [[小红书PMO团队]] 3.0 阶段全栈 Vibe Coding 构建的平台，作为 Agent 上下文的唯一数据锚点。

## 功能定位

承载数百个项目的核心主数据，包括：
- 项目名
- 成员
- 文档空间
- 周会文档
- IM 群
- 需求工具

## 设计理念

[[信息中枢先于任务执行]]的核心基础设施——PMO BP Agent 的所有能力都依赖项目注册平台提供的可信数据锚点。主数据先于场景扩展。

## 与 Agent 的关系

项目注册平台 + 工作流平台 + IM 三平台打通后，用户数一个月内从十几人暴增到几千人，验证了"数据锚点→平台打通→用户爆发"的增长路径。
