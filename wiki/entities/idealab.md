# IdeaLab

IdeaLab 是阿里巴巴内部的 Agent 搭建平台（据本来源记述），支持“智能助手”“流程编排”等多种构建方式。在《让问题不过夜：交易领域“问诊”Agent实践》中，它是 [[问诊小助手]] 问诊 Agent 体系的构建载体，团队选用该平台的原因是**避免重复造轮子**。由于是内部平台，wiki 不掌握其公开产品形态与外部可用性，本页所有信息均来源于该文章。

## 在来源实践中的角色

- 承载问诊 Agent 从 [[agent构建演进三阶段]]（初阶 Java 编码驱动 → 进阶提示词内嵌 SOP → Workflow 模式）到 [[sop-doc可召回排查文档]] 新范式的迭代落地。
- 平台层面的“智能助手/流程编排”双模式，与文章给出的两条平滑迁移路径相呼应：Workflow 架构加兜底路由导向新范式；智能助手将技能描述从提示词拆出迁至独立排查文档。

## 开放问题

- IdeaLab 与阿里对外产品（如 [[百炼]]）的关系未在来源中说明。
