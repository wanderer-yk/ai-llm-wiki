# AI案例实践中心

**AI案例实践中心**是天猫新品营销技术团队在小二端开发后台内置的 B 端常见页面标准化 prompt 模版案例库，[[sources/[202605081607]天猫新品团队AI编码实战指南下|来源]]。它是该团队全栈化转型中期"辅助补齐前端经验短板"阶段的核心平台对策，目的是让缺乏前端经验的转型后端同学可以直接复用经过验证的标准化 prompt，而不必从零描述需求。

## 解决的问题

小二端 AI 生码中期识别出两类高频问题：①"需求描述不准确"——后端同学对前端术语无概念，无法精准描述需求，导致频繁返工；②"垂类场景/复杂问题没有经验"——容易被 AI 的临时方案带跑，踩坑陷入死循环。AI案例实践中心针对第二类问题，将垂类场景的成熟做法沉淀为可直接套用的 prompt 模版。

## 与相关形态的区分

- 与 [[few-shot示例库]]（转转回收团队）同属"案例化 prompt 资产"，但主体与机制不同：前者是团队级平台化的模版中心，后者是嵌入提示词生成流水线的修复示例库。
- 与 [[知识基座-天猫]]（天猫品牌行业前端团队的知识基座）主题相近但主体不同，注意区分。
- 与 [[天猫新品业务编码助手]] 的分工：案例中心是后台内置的静态模版库，编码助手是 MCP 对话式速查工具；后期两者均被"无感"知识库方案部分替代（[[分阶段生码辅助演进]]）。
