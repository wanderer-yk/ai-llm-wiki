# Responses API

OpenAI 推出的统一 runtime，整合内置 Tools、Agents SDK、Tracing，将逐步替代 Assistants API。代表了 [[runtime收敛]] 趋势：Agent 开发从"自己拼一堆能力"走向"围绕统一 runtime 和工具语义来构建"。

在 [[zhiyuanfu]] 的行业分析中，Responses API 是 [[协议runtime控制面之争]] 的核心事件之一，标志着 Agent 开发竞争焦点从框架之争转向协议+runtime+control plane 之争。
