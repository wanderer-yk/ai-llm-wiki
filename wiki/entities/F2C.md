# F2C

F2C 是 [[柚漫剧团队]] 使用的设计稿转代码工具，用于消除"标注—切图—还原"的传统流程；它既是 3.3 节 [[设计即代码]] 能力的基建组成，也是 2025 Q4 接入的四类 AI 研发工具之一（与 Zulu、AI CR、AI 单测并列）。

## 还原度分层（4.2.2）

| 场景 | 表现 |
|------|------|
| 结构清晰、模块独立 | 还原度高，可直接采用 |
| 精细化视觉还原 | 优于纯文本 Prompt |
| 复杂布局、多状态组件 | 需大幅人工修正 |

## 使用原则与输入条件

- **按模块使用原则**：按模块逐个处理远好于整页一次性生成（"一把梭"）。
- **设计稿规范输入条件**：F2C 质量取决于 Rules 完善度 + 设计稿规范度（图层结构 / AutoLayout / 分组命名），由研发 + UE 协同制定 F2C 设计规范。

F2C 与 [[design-json唯一设计源]]、[[无需走查的代码集成]] 共同构成柚漫剧"设计即代码"链路的设计侧基座。
