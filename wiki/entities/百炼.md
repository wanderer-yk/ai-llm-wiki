# 百炼

## 简介

百炼是阿里云提供的大模型服务平台，为 AgentScope 等 AI 应用提供 LLM API 接入能力。在 AI 狼人杀项目中，通过 `DASHSCOPE_API_KEY` 环境变量配置百炼平台的 API Key。

## 在 AI 狼人杀中的角色

- 作为底层 LLM 能力提供商
- 示例代码中使用 `qwen3-plus`（通义千问）模型
- [[agentscope|AgentScope]] 提供了专门的 `DashScopeMultiAgentFormatter` 适配百炼平台的消息格式
