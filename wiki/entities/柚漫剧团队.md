# 柚漫剧团队

柚漫剧团队是漫剧类产品 [[柚漫剧APP]] 的产研团队，也是百度技术公众号 [[百度Geek说]] 2026 年 4 月原创文章《柚漫剧 AI全流程提效拆解》的集体署名作者（IP 属地上海，文中无具名个人成员）。团队归属百度体系由发布载体间接表明。

## 全流程提效实践

团队以柚漫剧 APP 为锚点开展"人力驱动 → AI 驱动"的全流程实验，按五职能分章呈现：

1. **PMO**：规划"需求-设计-开发-测试"智能提效闭环。
2. **产品**：[[需求质量协作者定位]]、[[需求范式共创]]、[[思路比结果更重要]]。
3. **设计**：[[设计师作为需求架构师]]、[[prompt友好需求模板]]、[[毛坯房精装房分工]]、[[design-json唯一设计源]]、[[设计即代码]]。
4. **研发**：2025 Q4 起接入 Zulu、F2C、AI CR、AI 单测四类工具，随后由 [[单点提效到基建驱动]] 走向 [[ai-coding基建]]（Rules / MCP / Skills 三线）。
5. **测试**：[[AIQA]] 全链路智能化测试体系 + [[测试左移AI助力]]（AICR / AI Checker 茶茬）。

## 方法论签名

- 经验一至四：基建被真实痛点倒逼、[[高闭环任务先行]]、[[跨角色前置对齐架构]]、承认边界分场景落地。
- 章级定论："AI Coding 落地不是'用工具'的问题，而是'建基建'的问题"——即 [[隐性知识显性资产化]] 与 [[代码作为产研协作中间态]] 两大命题。
