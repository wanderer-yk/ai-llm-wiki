# AI CR（AICR）

AI CR 是 [[柚漫剧团队]] 贯穿研发章（4.2.3）与测试章（5.2）的智能代码审查工具族，提测阶段总名"AICR（持续完善）"，由静态扫描能力 [[AISA]] 与百度内部智能评审工具"小码哥"两个组件构成，在 Commit 与 CR 阶段对 Android / iOS / Go 代码做问题召回与质量评估。

## 运行机制

| 阶段 | 能力 | 备注 |
|------|------|------|
| Commit 阶段 | 基于 Agent + rules 引入 AISA 扫描能力，CR 提前发现静态代码风险 | Comate IDE / VSCode / JetBrains 三端上线 |
| CR 阶段 | 小码哥智能评审，融合小码哥+AISA（重复内容自动收起），AI 评估代码质量 | 初期误报率较高，针对性优化后提升有效率 |

## 迭代经验（CR 规则分层配置，并入本页记录）

- 不同业务线扫描规则应用效果差异大 → 增加知识本并与代码库 CR 规则打通。
- 支持**工程级 / 个人级**两级规则配置。

## 跨源同构

- 评审左移：AICR ↔ [[pre-pr机制]]（美团）↔ [[十一阶段后台开发流程]] 的 AI 评审环节。
- 静态扫描→AI 消费双路径：AISA ↔ [[sonar]] + [[六步智能提示词生成法]]，双方均含误报优化环节。
- 属于 [[测试左移AI助力]] 的提测阶段支柱，与 [[AIQA]] 的 [[需求准出自动拦截]] 共同构成测试侧门控。
