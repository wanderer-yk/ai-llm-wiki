# 飞书

**飞书**是 [[得物技术]] 团队 AI 编程工作流中的核心外部协作平台，提供审批、日历、消息卡片、文档、多维表格等能力，并通过 MCP 服务器接入 [[claude-code]]。（独立可查证的背景信息：飞书是字节跳动推出的企业协作与管理平台，国际版名为 Lark。）

## 在本来源中的角色

得物团队将飞书作为 AI 编程与团队协作系统之间的桥梁，证据横跨三个层面：

1. **Plan 模式集成**（第二章）：拜访任务示例中的飞书审批 API、飞书日历 API、飞书消息卡片模板
2. **MCP 三场景**（第二章）：
   - `feishu_create_doc` — 在指定知识库目录自动创建格式化技术方案文档
   - `feishu_get_doc_content` — 读取 PRD 需求，基于完整需求生成技术方案和实现计划
   - `feishu_append_bitable_data` — 代码行数、涉及文件等统计自动追加到多维表格，追踪 AI 编程效率指标
3. **硬约束封装**（第三章提示词模板）：「飞书消息发送必须使用 FeishuClient，不要重复实现」被列为「必须遵守」级约束；飞书机器人回调需实现签名校验（参考 FeishuEventHandler）

## 关联

- 与 [[mcp]]：飞书 MCP 服务器是 [[mcp]] 协议在团队工具链落地的实例（官方还是自建未说明）
- 与 [[dify]]：同为得物机器人问答功能的外部 API 依赖（DifyClient 封装 + 重试降级 + integration_log 记录）
- 与 [[中间产物驱动论]]：技术方案文档经 `feishu_create_doc` 落入飞书知识库，成为团队共享白板的物理载体
