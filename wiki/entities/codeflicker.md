# CodeFlicker

CodeFlicker 是 [[kwaipilot]] 的海外版产品，面向全球开发者发布，网址为 https://www.codeflicker.ai/ 。Kwaipilot 完成三代演进后以 CodeFlicker 品牌面向海外市场，后续将持续融入快手智能化 2.0 阶段的探索成果。

## 与 Kwaipilot 的关系

CodeFlicker 与内部使用的 Kwaipilot 共享底层技术基础（统一 Agent 架构、代码大模型），但面向海外开发者的使用场景做了适配。具体功能差异、是否支持企业级部署等细节尚未公开披露。
