# 助手市场

助手市场是 [[智空间]] 平台的核心产品化机制，提供"一键创建 agent 实例、页面调试（所见即所得）"能力，让业务方不经开发即可获得 AI 助手——它是"业务方'配'助手而非'开发'助手"这一 [[ai助手工厂]] 核心理念的产品载体。

## 产品形态

- **四套模版**：四大场景解决方案（[[四大高频场景抽象]]）固化为四套模版；核心 agent 节点（意图识别、工具推理、ReAct推理、总结交互等）均内置框架 prompt + 开放业务定制架构（[[prompt插拔架构]]）。
- **三步法创建**：选择模板 → 配置 → 生效（详见 [[三步法配置助手]]）；4.1 节以"一键三连"演示极简定制三步：一键选择模版 / "三联"配置助手 / 一秒生效（截图 100075320/100075317/100075318）。
- **资深编辑模式**：高级定制入口，提供意图识别定制与排查策略定制（截图 100075321/100075322），面向 [[排查助手定制三问]] 方法论指导下的深度定制场景。

在 [[常规极简场景方案]] 中，助手市场被列为常规碎片化场景的核心方案，与小组支持（人员）共同构成极简接入路径。
