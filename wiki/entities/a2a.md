# A2A (Agent-to-Agent Protocol)

Google 发布的 Agent 间协作协议（2025-04-09），解决多 Agent 协作、发现、协商和同步状态问题。后捐赠给 Linux Foundation 成为行业标准（2025-06-23）。

在 [[zhiyuanfu]] 的行业分析中，A2A 与 [[mcp]]（工具接入）、[[responses-api]]（runtime）并列为 Agent 行业三大收敛趋势。与 [[多智能体消息机制]]（AgentScope）属于同一问题域，但 A2A 定位于跨系统互操作层面的标准化协议。
