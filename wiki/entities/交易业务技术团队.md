# 交易业务技术团队

交易业务技术团队是淘天集团旗下负责淘系交易业务的技术团队，是《从 Vibe Coding 到范式编程》一文的文章署名主体与 [[trade-spec]] 平台的建设者。据文章末尾团队介绍段，该团队专注下单、支付、物流、服务、逆向退款等核心交易链路，面向亿万用户，持续推进交易平台架构演进，并负责大促流量洪峰保障。团队具名作者为[[淘苏]]。

## 方法论立场

该团队在本源中提出并实践「范式编程」（[[规格驱动ai开发]]/SDD 的本文别名），核心论点包括：交易领域四特殊性（合规要求高/历史包袱重/容错空间小/领域知识密集）决定了「规范化生成是必要的防线」；[[领域知识竞争壁垒论]]——AI 编程能力越强，差异化竞争力越取决于知识库丰富度、规范完善度与反馈闭环效率。团队对范式编程持「不是银弹」的限定态度，认为其当前最适合企业级中小需求场景。

## 工程资产

- [[trade-spec]]：Spec 平台（知识库召回、知识点配置、疑问点机制、SOTA 模型 Agent 集成等核心基建）。
- 双通道 Agent 架构：SOTA 通道（Python 自建，基于 [[claude-agent-sdk]] 与 [[claude-sonnet-4-5]]）+ [[aone-agent]] 通道（安全底线）。
- 基础设施依赖：[[aonesandbox]]（沙箱）、[[ideatalk]]（内部网关）、KBase（语义检索）、[[aone]] 流水线、Diamond 配置、[[tair]] 缓存、[[deepwiki]]（调研后落选）。
