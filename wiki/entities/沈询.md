# 沈询

沈询是一位 AI Agent 方向的技术作者与实践者，微信公众号「[[千问AI平台]]」《AI Agent 系列》文章的作者，同时是 Func-Agent 框架 [[lynxe|Lynxe]]（菱科斯，原 JManus）的开发者，该框架位于 GitHub `spring-ai-alibaba` 组织。

## 身份与背景

- **来源内已确认**：AI Agent 系列文章作者（系列规划 5 篇，本篇为第三篇）；Lynxe 框架作者，框架定位为探索 Agent 前沿最佳实践
- **推断信号（未获正文直接声明）**：文章带"阿里妹导读"编辑导语、发布于千问AI平台（IP 属地浙江）、框架归属 spring-ai-alibaba 组织，三重信号指向阿里巴巴，但机构归属待独立来源确认
- 系列第二篇"Agent 将决策权完全下放给模型和 Prompt"的核心观点在其文章中被两次显式引用，系列内互文明显

## 核心观点

- **MCP 与 Skills 竞争大于互补**（[[mcp与skills竞争关系论]]）：明确反驳流行的"互补说"，主张两者是同一问题（整合多既有系统完成复杂多步任务）的两种解法，选此失彼
- **Function Calling 桥梁论**（[[function-calling桥梁论]]）：FC 是非结构化自然语言需求与结构化系统调用之间的桥梁，是 MCP 与 Skills 存在的前置条件
- **任务流程定义困难问题**（[[任务流程定义困难问题]]）：模型自主调度不精确与全代码化丧失动态性的两难，是 Skills 与 Func-Agent 的共同起源
- **一切都是函数**（[[一切都是函数]]）："函数才是第一公民"，Func-Agent 设计哲学
- **Skills 两大未解问题**（[[skills两大未解问题]]）：description 不结构化、只能聊天式接驳
