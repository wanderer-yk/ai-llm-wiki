# 智能平台部

智能平台部是 [[货拉拉技术]] 中心下属部门，负责算法与 Agent 实现。该部门下设算法组，本文署名作者包括张洪龙、杨丹、陆弘源。

## 核心贡献

在 AI 翻译实践中，智能平台部负责 [[多agent翻译框架]] 的算法设计与 Agent 实现，包括翻译 Agent、翻译质量评分 Agent 和敏感信息识别 Agent 的开发，以及自研 [[悟空平台]] 作为核心层的搭建。

该部门与 [[国际化技术部]] 增长组协同完成翻译方案的业务落地。
