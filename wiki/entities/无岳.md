# 无岳

无岳是《Claude Code 源码拆解：从启动到多 Agent 扩展层》（[[千问AI平台]]公众号，2026-04-15）一文的作者。据该文开篇自述，其团队在内部从事 Agent 平台、研发工具链与 Vibe Coding 产品工作——此身份描述来自来源本身。本 wiki 中暂无关于该作者的其他可独立验证的公开身份资料；文中「阿里妹导读」标签、`ata.21736010` spm 锚点与浙江属地仅构成阿里系背景的间接证据，正式关系未证实。

## 观点与方法立场

其文章以源码拆解视角系统分析 [[claude-code]] 的运行时架构，核心立场包括：

- **运行时决定论**：决定 Agent 能否长期存活的是围着模型搭起来的运行时，不是模型；并给出完整命题「把不稳定、概率化、容易失误的模型能力，装进一套稳定、可恢复、可解释、可扩展的工程运行时」。
- **架构论断体系**：[[三主干链路]]（控制链/执行链/任务链）、扩展层收敛论（[[动态能力面稳定内部对象]]）、权限即可解释执行链、统一任务抽象先行等，最终蒸馏为[[五条带走结论]]。
- **务实的工程节奏判断**：单轮阶段不必复制完整恢复体系；进入多工具/多轮/长上下文阶段后，才把上下文治理与失败恢复从 prompt 层挪到运行时层。
- **组织级收束**：真正成熟的 Agent 系统是「组织能把模型做事这件事，稳定地接进交付链路里」（[[组织接入交付链路论]]），以终极之问「当模型开始真的做事，系统准备在哪里把这些复杂度接住」（[[复杂度承接之问]]）收束全文。
