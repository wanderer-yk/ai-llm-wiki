# deanpeters/Product-Manager-Skills

deanpeters/Product-Manager-Skills 是 Dean Peters 维护的产品管理 Skill 仓库，收录 **40+ 产品管理 Skill**，其中 [[discovery-process]]（502 行）是 [[青斧]] 归纳的多阶段+检查点模式代表。该仓库还是自定义 frontmatter 扩展字段的最大贡献者——`type`、`best_for`、`scenarios`、`estimated_time` 四个字段均出自其中的 Skill。discovery-process 内部还引用了 `workshop-facilitation` 等子 Skill 实现交互协议分离（经速查表确认，workshop-facilitation 不在 7 个分析对象之列）。细节见 [[discovery-process]] 与 [[skill多阶段检查点编排模式]]（数据源：[[sources/[202604270830]工作流的Skill怎么写从7个顶级Skill中提炼的模式与最佳实践]]）。
