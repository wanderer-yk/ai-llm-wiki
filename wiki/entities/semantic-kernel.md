# Semantic Kernel

Semantic Kernel 是 [[微软]] 开源的 SDK，展示了如何将自然语言 Prompt 封装为可调用的 Skills/Plugins。

## 工程价值

Semantic Kernel 为**声明式技能封装**提供了工程实现参考，证明了将 AI 能力以配置化、声明式方式定义的可行性。这一理念与 [[agent-skills]] 的"模块化能力封装标准"高度契合，为 Agent Skills 的流程编排、上下文感知和轻量级集成特性提供了先驱性验证。

在 [[202602271818]AgentSkills与MCP一场被误解的替代战争] 中，Semantic Kernel 被引用为四大理论支撑之一，佐证了 Agent Skills（声明式架构）作为独立于 MCP（服务化架构）的技术范式的工程可行性。
