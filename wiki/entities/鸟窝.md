# 鸟窝

鸟窝是本文《我把 Karpathy 的 AutoResearch 搬到了软件开发领域，效果炸了》的署名作者，发布于 [[百度Geek说]] 公众号（IP 属地上海），并是 [[smallnest-autoresearch]]、[[imclaw]] 等开源项目的开发者。文中项目托管于 GitHub 账号 **smallnest** 下，强烈提示"鸟窝"即 smallnest 账号持有者，但本文未直接声明两者同一，同一性待外部确认。

## 本文披露的作品

- **[[smallnest-autoresearch]]**（`github.com/smallnest/autoresearch`）—— 将 [[autoresearch]] 方法论迁移到软件开发领域的核心项目，本文主体
- **[[imclaw]]**（`github.com/smallnest/imclaw`）—— 据同账号推荐阅读标题，是通过微信/飞书操控 ClaudeCode/Codex/GeminiCLI/Pi Agent 蜂群的工具；本文演示 Issue #21 即挂在该仓库
- **GoClaw** —— 据同账号推荐阅读标题《我用 Go 重写了一个 OpenClaw 框架：这就是 GoClaw》，为 OpenClaw 的 Go 语言重写版（本文仅推荐阅读一处提及，未建独立页面，可作 [[openclaw]] 页延伸线索）

## 技术立场

作者在 [[acpx]] 命令行操控层之上构建多 Agent 交叉审核系统，主张软性保护（不做 git revert，"ClaudeCode/Codex 自己足够智能决定回退还是改进上一轮的变动"）与反馈驱动迭代；同账号还产出 Harness Engineering、Skills/MCP/Rules 辨析等 Agent 工程主题文章，与 [[百度Geek说]] 已收录的 [202604081800]、[202604151800] 两文同源。
