# Code Insight

有赞[[有赞技术中台|技术中台]]团队开发的代码搜索定位系统，基于半年实战经验构建。系统为代码库建立"智能地图"，实现代码的精准定位与语义理解。

## 双路径架构

### 路径一：向量检索（RAG）
- **框架**：[[llamaindex|LlamaIndex]]
- **嵌入模型**：自选模型（内部测试集验证，相关代码召回率达 95%）
- **LLM**：[[deepseek-v3]]
- **向量检索算法**：HNSW（分层可导航小世界图）
- **安全机制**：敏感信息扫描工具脱敏
- **擅长**：语义理解、少量文件语义找回
- **瓶颈**：跨文件/跨仓库/调用链/继承链/影响范围分析

### 路径二：AST+符号表
- **核心能力**：构建[[调用关系图谱]]，支持精准[[影响范围分析]]
- **AST 作用**：明确"哪里调用了某个函数"
- **符号表作用**：记录标识符名称/类型/作用域/定义位置，补全 AST 缺口
- **擅长**：结构化分析、调用链追踪、影响范围分析

## 三大落地场景

1. **智能[[代码问答]]**：集成在内部 OPS 平台，支持前后端接口匹配、业务流程图生成，作为 [[cursor]] 的日常平替
2. **[[traceai排障|TraceAI 问题定位]]**：Agent 自主结合代码问答+链路追踪日志进行线上问题定位
3. **智能[[测试用例生成]]**：AST 推导受影响 API 接口，结合大模型理解改动点自动生成测试用例

## 未来方向

- 跨仓库分析
- TraceAI Agent 落地
- 业务文档自动生成
