# CodeWiki

**CodeWiki** 是天猫新品营销技术团队在其轻量级团队知识库体系中借用的知识库问答组件，原文表述为"甚至还可以直接借用CodeWiki进行知识库问答"，[[sources/[202605081607]天猫新品团队AI编码实战指南下|来源]]。它为该团队的统一知识源补充了自然语言问答入口，与 curl 直读 CDN 资源、编辑器 Rules 配置接入共同构成知识的多种消费方式。

> **身份注意**：本文的 CodeWiki 与有赞共享技术开发的 [[knowledge-wiki]]（`.wiki/` + Git submodule 分布式架构）是完全不同的主体，仅名称相近，切勿混淆。CodeWiki 的具体归属（阿里内部工具还是开源项目）原文未说明，待复核。

## 在知识库架构中的位置

团队知识库的完整形态为：类 Skill 形式封装开发规范与代码模版 + git 仓库管理 + npm 包承载与版本管理 + 文件链接多级索引（渐进式披露、控 token）+ curl 读 CDN + 编辑器 Rules 接入 + CodeWiki 问答。CodeWiki 承担其中的"支持问答"能力，是统一知识源四特征（及时更新、不依赖编码工具、支持问答、使用无感）之一的具体支撑（关联 [[npm包知识库架构]]、[[统一收口]]）。
