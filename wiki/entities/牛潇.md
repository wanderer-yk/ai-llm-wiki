# 牛潇

牛潇是 [[京东ei|京东 EI]] 团队成员，IP 属地北京。2026 年 2 月在微信公众号 [[京东技术]] 发表文章《Agent Skills 与 MCP：一场被误解的"替代战争"》，系统阐述了 Agent Skills 与 MCP 的互补关系，提出**能力 vs 行为二分法**（MCP="能不能做"，Agent Skills="怎么做才对"），并给出基础决策框架、经典协同模式三式和真实工程三大误区的完整方法论框架。

其核心观点"真正的智能，不在于选择某一种工具，而在于知道何时用哪一种，以及如何让它们共舞"为 [[mcp]] 与 [[agent-skills]] 的协同设计提供了系统化的理论指导。
