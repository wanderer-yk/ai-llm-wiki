# ChatRhino API

ChatRhino API 是 [[joyai|JoyAI]]官网文档提供的 Token 计算 API 端点，地址为 `api.chatrhino.jd.com/api/v1/tokenizer/estimate-token-count`。

由于 JoyAI 未公开 tokenizer，[[京东物流]]团队通过此 API 进行测试数据反推，得出了 [[token估算经验公式]]。
