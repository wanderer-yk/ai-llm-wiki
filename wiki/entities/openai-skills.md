# openai/skills

openai/skills 是 [[openai]] Codex 的官方 Skill 目录仓库（https://github.com/openai/skills）。按 [[青斧]] 速查表的终局归属，本仓库为 [[sources/[202604270830]工作流的Skill怎么写从7个顶级Skill中提炼的模式与最佳实践]] 贡献了两个分析对象：[[vercel-deploy]]（线性流程模式，77 行，"最小但完整的 Skill 模板"）与 [[cloudflare-deploy]]（线性+决策树模式，224 行，"大平台的渐进式披露"）。需要修正的是：同域的导航型 [[cloudflare导航型skill|cloudflare]] 并非出自该仓库，作者速查表标注其来源为 OpenCode。该仓库与 [[anthropics-skills|anthropics/skills]]（官方模板与规范）、[[agentskills-io|agentskills.io]]（开放标准）共同构成 Skill 生态的官方侧基线。
