# PMO BP Agent

小红书 [[小红书PMO团队]] 4.0 阶段核心产品，为每个项目组配备的 AI 专属业务伙伴（Business Partner）。一个 Agent 按角色支持项目里所有成员。

## 架构

基于 [[openclaw]] 构建，复用其 Gateway / Session / Multi-Agent 编排 / IM 插件 / Skill 体系 / 稳定性机制，新增两层专属能力：

1. **项目上下文路由**：识别用户在问哪个项目
2. **角色感知**：按管理者 / 项目负责人 / 项目成员自动调整回答粒度

## Session 模型

从 3.0 的"1人×1 Session"升级为[[1项目×n人×m-session模型]]——项目级共享多渠道动态上下文。

### 角色感知差异

不同角色问"项目进展怎样"需要完全不同粒度：
- **管理者**：目标达成 / 卡点
- **负责人**：全局进展 / 风险
- **成员**：依赖模块进度

## 12 项落地能力

文章列出 12 项落地能力矩阵（具体内容见原文），覆盖信息中枢 + 任务执行两大类。

## 核心定位

[[信息中枢先于任务执行]]——PMO BP Agent 首先是信息中枢，其次才是任务执行者。主数据先于场景扩展。

## 主数据底座

以 [[项目注册平台]] 作为唯一数据锚点，承载数百个项目核心主数据（项目名 / 成员 / 文档空间 / 周会文档 / IM 群 / 需求工具）。
