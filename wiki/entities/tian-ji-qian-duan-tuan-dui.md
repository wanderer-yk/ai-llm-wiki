# 天玑前端团队

**天玑前端团队**是 [[ai-qi-yi-ji-shu-chan-pin-tuan-dui|爱奇艺技术产品团队]] 旗下的前端开发团队，是 [[specflow|Specflow]] 的研发主体和文章署名作者。

## AI Coding 实践

- **实践时长**：一年以上 AI Coding 实践
- **核心场景**：复杂中后台前端开发
- **实践演进**：从早期 [[vibe-coding|Vibe Coding]] 模式 → [[spec-driven-development|规格驱动开发（SDD）]] 模式
- **核心发现**：AI 效率波动的根因是**上下文断层** + **需求共识缺失**
- **核心产出**：[[specflow|Specflow]]——专为 Cursor IDE 定制的规格驱动 AI 开发流程 CLI 工具

## 方法论总结

天玑前端团队提出的核心理念：

1. AI 辅助编码应是"准"而非单纯的"快"
2. 将解决问题的战场从"编码调试期"推到"需求设计期"
3. 契约清晰时编码成为可交由 AI 的廉价体力活
4. 未来核心竞争力 = 定义需求 + 拆解任务 + 驾驭规范
