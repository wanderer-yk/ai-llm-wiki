# 网盘

本文所称「网盘」指 [[百度Geek说]] 语境下的网盘产品 Android 主端，是文中 AI 存量代码迁移实践的业务载体。源文通篇仅称「网盘」，未给出产品全称；结合百度技术公众号的发布背景，其通常即指百度网盘——此为独立可验证的背景推断，并非源文明示，页面命名按源文拼写保留为「网盘」。

## 在本文中的背景

网盘主端积累了大量存量代码，团队推进 [[KMP]] 多端复用时面临迁移稳定性挑战：页面迁移涉及 UI 层、布局文件、业务逻辑、资源文件四类内容，依赖关系错综复杂，遗漏在编译阶段集中暴露；人工梳理效率低、遗漏率高。

## 在本文中的角色

网盘存量代码迁移是 [[三层架构管住AI输出]] 的问题现场：AI 直接迁移暴露输出漂移、后期幻觉增多、并行缺乏机制支撑三个规律性问题（[[AI迁移三规律性问题]]），由此催生提取阶段四路并行 + 转化阶段串行 Memory 传递的 [[两阶段迁移流程]]。
