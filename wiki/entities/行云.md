# 行云

## 简介

行云是京东内部的部署平台。[[mcp-server-ts]] 框架内置了行云部署脚本支持，部署脚本位于 `xingyun/bin/control.sh`，其中使用 `npm run start:http` 命令启动 streamableHttp 模式的 MCP 服务。

行云平台的具体架构、部署流程和运维能力等细节在现有来源中未详细展开。
