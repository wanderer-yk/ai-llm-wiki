# 内部资产中心

内部资产中心是淘天集团通用资产中心平台，聚合通用基建知识（组件文档、API 说明、最佳实践），是 [[知识基座-天猫|天猫知识基座系统]] [[多来源知识汇聚]] 理念中的核心对接对象。

## 定位与作用

在 [[知识分层模型-天猫|知识分层模型]] 中，内部资产中心是"组件/平台知识"层的主要来源。通过 MCP Server 转发对接实现实时查询，AI 可获取最新版本的组件文档和 API 说明。

## 知识源头获取原则

遵循 [[知识源头获取原则]]——"知识的源头在哪里，就从哪里获取"：组件文档/API 说明/最佳实践由组件负责方统一维护在资产中心平台，组件升级时文档同步更新，AI 通过 MCP Server 转发始终获取最新版本，避免各业务域重复维护导致的 [[版本不一致冲突风险]]。

## 覆盖范围

集团 10+ 业务域依赖内部设计系统、API 平台、工作台 A/B/C/D、运营平台等基建。这些基建相关的知识统一由内部资产中心汇聚管理。
