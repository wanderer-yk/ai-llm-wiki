# 悟空平台

悟空平台是 [[货拉拉技术]] 自研的大模型应用平台，在 [[多agent翻译框架]] 中作为**核心层**，桥接各项后端功能。

## 架构定位

在多 Agent 翻译框架的三层架构中，悟空平台承担核心层角色：

- **应用层**：负责业务侧的翻译请求接入和结果返回
- **核心层（悟空平台）**：桥接翻译 Agent、翻译质量评分 Agent 和敏感信息识别 Agent 的调度与协同
- **数据层**：提供术语库、Few-shot 参照语料、上下文信息等数据支撑

悟空平台作为自研大模型应用平台，不仅服务于翻译场景，也是 [[垂直场景llm落地框架]] 的基础设施。
