# 智空间

智空间（文中正式称谓"AI 平台智空间"）是《拒绝重复造轮子！抽象 80% 工作场景，打造可复用的"AI 助手工厂"》一文所介绍的企业内部 AI 助手一键创建平台，即标题所称"AI 助手工厂"的落地实体。它基于"解决方案模板 + Prompt 框架 + 业务定制扩展"的方案构建，目标是让业务方"配"助手而不是"开发"一个助手。其与阿里巴巴、[[千问AI平台]] 的具体组织归属关系文中未明示，仅经"阿里妹导读"栏目佐证为阿里系内部实践。

## 平台构成

- **技术架构**：[[智空间分层解耦架构]]——解决方案层（固化四大场景差异化流程）+ 核心能力层（推理、执行、知识、工具、安全五大能力域），方案"搭积木"式自由组合。
- **产品机制**：[[助手市场]]——四套场景模版 + [[三步法配置助手]]（选择模板→配置→生效）+ 一键三连 + 资深编辑模式双定制入口。
- **技术底座**：[[prompt插拔架构]]（框架 prompt + 业务定制双层契约）与 [[IntentResult模型]]、[[FSWW工具召回算法]] 等核心能力。

## 演进方向

文中声明方法论三步法（[[场景抽象三步法]]：场景抽象→解法沉淀→产品化落地）将继续驱动智空间演进；产品目标为"配置化、模板化、极简化"；未来将从配置化走向自动化（[[配置化到自动化]]），并由后台 agent 接管意图划分、配置录入、调试发布、运维 query 分析等人工环节。
