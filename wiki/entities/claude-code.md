# Claude Code

Anthropic 推出的 Claude CLI 工具，具备读文件、改代码、跑命令能力。区别于 Claude 本身（用于文档生成），Claude Code 是完整的 CLI Agent。在 [[zhiyuanfu]] 的 [[24h打工人]] 系统中作为调度层调用的终端工具之一。
