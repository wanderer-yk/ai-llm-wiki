# openclaw/clawhub（Skill 注册中心）

openclaw/clawhub（https://github.com/openclaw/clawhub）是 [[openclaw]] 生态的 Skill 注册中心，被 [[sources/[202604270830]工作流的Skill怎么写从7个顶级Skill中提炼的模式与最佳实践]] 列为参考资源。它与 [[agentskills-io|agentskills.io]]（开放标准）、[[anthropics-skills|anthropics/skills]]（官方模板/规范）构成 Skill 分发与治理的生态基础设施；其定位也与小红书 PMO 案例中的企业内部 Skill Hub 市场互为参照（参见 [[生产级skill]] 的可复用 SOP 封装讨论）。注册中心的审核机制、质量管控等细节在来源中未展开。
