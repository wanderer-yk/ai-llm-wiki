# 微软

微软（Microsoft）是全球科技公司，提出了 [[semantic-kernel]]（语义内核）概念，通过 Microsoft Learn 平台提供相关技术文档。

在 Agent 工程领域，微软的 Semantic Kernel 为**声明式技能封装**提供了工程实现参考，展示了如何将自然语言 Prompt 封装为可调用的 Skills/Plugins，为 [[agent-skills]] 的模块化能力封装理念提供了先驱性验证。
