# AIQA

AIQA 是 [[柚漫剧团队]] 测试章（5.1）的中心主体：一个 QA 域**全链路智能化测试体系**，其核心主张是 LLM 在其中成为具备"独立行动"能力的 AIQA，人从"执行者"转为"监督者/调教者"（见 [[copilot到ai-agent范式转移]]）。

## 架构

两大角色 + 六大专业 Agent + 工具生态 + 交付工程记忆：

- **两大角色**：主 Agent + 数字员工"度小智"。
- **六大专业 Agent 与交付工程记忆**：具体构成仅存于不可提取架构图，正文未展开，确认为**永久性信息缺口**；AIQA 属百度公司级平台还是团队自建亦未明示。

## 功能清单

- 根据提测内容分析判定、自动发送提测报告（QA 反馈正向）。
- 根据需求准出标准**自动拦截未达标需求**（见 [[需求准出自动拦截]]）。
- 支持如流侧边栏形式，便捷观测需求和版本维度风险。
- 自动断言、自动签章（效果截图标题级能力名）。
- 智能测试打通端到端全流程链路：从需求生成到测试准出全 AI 化。
