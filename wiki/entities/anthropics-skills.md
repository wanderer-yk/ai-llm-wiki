# anthropics/skills

anthropics/skills 是 [[anthropic]] 的官方 Skill 仓库，包含官方模板（/tree/main/template）与规范文档（/tree/main/spec）两个核心部分，被 [[sources/[202604270830]工作流的Skill怎么写从7个顶级Skill中提炼的模式与最佳实践]] 列为"官方规范"级参考资源。它与 wiki 既有的 [[Skill-Creator]]（Skill 生成工具）、[[skills-cli跨平台安装]]（跨平台安装）、[[agent-skill知识包]]（Skill 知识包概念）同属 Anthropic Skill 体系脉络，与 [[agentskills-io|agentskills.io]] 开放标准共同构成 Skill 写作的权威起点。
