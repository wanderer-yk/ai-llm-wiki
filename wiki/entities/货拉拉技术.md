# 货拉拉技术

货拉拉技术是货拉拉公司旗下的技术分享微信公众号，IP 属地北京。该公众号发布货拉拉技术中心各团队的实践经验与技术方案。

## 组织结构

货拉拉技术中心下设多个部门，本文涉及的两个核心部门为：

- [[智能平台部]]：负责算法与 Agent 实现，下设算法组
- [[国际化技术部]]：负责业务需求与落地，下设增长组

## 代表性实践

在 AI 翻译领域，货拉拉技术团队为海外品牌 [[Lalamove]] 的跨国开城场景构建了 [[多agent翻译框架]]，以自研 [[悟空平台]] 为核心层，通过翻译 Agent、翻译质量评分 Agent 和敏感信息识别 Agent 协同工作，成功削减了 90% 的人力成本，并将翻译响应时间从数月缩短至数天。
