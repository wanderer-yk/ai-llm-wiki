# 互联网项目团队

vivo 公司旗下技术团队，与已收录的 [[互联网搜索团队]]（Wang Wenqian，同为 vivo）属同公司不同子团队。

团队成员 [[ding-junjie]] 于 2026 年 4 月发布文章《[[sources/[202604152000]OpenClaw落地到生产实际应用的一种可能的路径|[202604152000]OpenClaw 落地到生产实际应用的一种可能的路径]]》，聚焦 OpenClaw 从 Coding Agent 到生产落地的路径分析。两支团队的文章同属 [[vivo互联网技术]] 公众号的 Agent 系列专题，分别从架构设计（[[agent架构四决策]]）和生产落地路径（[[agent生产落地四层框架]]）两个视角分析 Agent 技术。
