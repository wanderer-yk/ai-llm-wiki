# AI Checker 茶茬

AI Checker 茶茬是 [[柚漫剧团队]] 测试体系中负责**走查阶段**的 UI 问题检测工具（文中标注"建设中"），以"AI + 算法 + 代码"实现 figma 与图像对比的前置 UI 问题召回，并通过 [[openclaw]] 实现知识与算法的自主进化。

## 检测机制

- **核心机制**：[[figma图像对比前置]]——设计稿（figma）与实际图像对比，前置召回 UI 问题。
- **检测范围**：文本 / 元素布局 / 样式 / 区域四类检测；高频问题归纳为文本、样式、布局。
- **校验策略**：按问题类别定制化校验策略，提升召回准确率。

## 自主进化与 skill 化

- 通过 [[openclaw]] 实现**知识与算法的自主进化**——这是 [[openclaw]] 在 wiki 中的第三家引用源（vivo 架构分析、小红书 PMO 3.0 采用之外）。
- 检测能力 **skill 化后渗透设计、开发、测试全流程**（见 [[知识算法自主进化与能力skill化]]）。
