# 苏雄

苏雄是淘天集团-会员技术团队的工程师，AI Agent 框架实践者。其在本 wiki 中的身份来自《[202604241629]800行代码实现OpenClaw的Tool消息总线子Agent管理架构》一文文末团队介绍的实名署名（文章头部署名为团队名「会员技术团队」，发布于微信公众号「[[大淘宝技术]]」，2026-04-24）。

## 主要贡献

苏雄在上述文章中以 TypeScript + Anthropic SDK + 单进程 Node.js 对 [[openclaw]] 的 Tool、消息总线、子 Agent 管理架构做了约 800 行的研究学习式最小复刻实现，核心技术主张为：对 Tool 调用、消息分发、子 Agent 管理三类核心组件优先采用薄抽象、显式控制流、贴近模型 API 的实现（见 [[薄抽象设计哲学]]、[[轻量级单进程agent框架]]）。文章的显著特点是诚实声明取舍——「设计选择与局限」章节给出 7 项显式的「设计选择—收益—代价/局限」清单（见 [[有意取舍边界声明]]），涵盖零框架依赖、无运行时参数校验、子 Agent 无持久记忆、cron 静默降级、MessageBus 无持久化、ExecTool 正则黑名单可绕过、REPL 单用户并发边界。
