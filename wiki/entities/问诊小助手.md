# 问诊小助手

问诊小助手是阿里系交易领域的问诊 Agent 产品家族（依据来源的阿里系术语侧证与 [[千问AI平台]] 账号归属），是“运维友好型问诊Agent构建范式及运营体系”的产品化载体。它不是单一助手，而是按 [[小域专精原则]] 在交易后链路各子域独立建设的专用助手集合——文中以“部分小助手”复数表述、五个落地场景、配套管理后台与 F1 指标表中的多个助手行共同构成家族证据链。构建载体为 [[idealab]]，作者为 [[顺乾]]。

## 五个落地场景

1. 买家订单管理
2. 物流查询
3. 商家问题答疑
4. 评价场域（含问大家、买家秀种草）
5. 逆向流程诊断

F1 指标表中出现的“评价小助手”（90%/85%/87.43%）疑对应评价场域；“逆行者2.0”（90%/80%/84.7%）疑对应逆向流程诊断，但源文未给出场景与助手名的精确映射。

## 运营体系

- 配套**问诊Agent管理后台**（三张截图，功能细节不可读），支撑 [[双层召回知识体系]] 的知识维护（专家编写 + AI 自动生成混合模式，建设中）。
- 运营指标图表：近几期服务次数趋势、研发月度工单受理数、AVG(Q-score)、有效率（均以截图给出，正文无数值）。
- 月均交互量迅速突破千条，纯人工打标不可持续，故引入 [[评分agent坏样本聚焦]] 与 [[反馈回灌闭环]]。
- 部分数据链路同步类疑难杂症可由运营小二一键重置、“研发零干预”（无量化数字）。
