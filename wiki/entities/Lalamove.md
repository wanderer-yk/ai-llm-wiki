# Lalamove

Lalamove 是货拉拉的海外品牌，是跨国经营的业务主体。面临大量海外开城场景下的 App 和官网翻译需求。

## 翻译痛点

Lalamove 在海外开城时面临以下翻译挑战：

- **数据量大**：App 和官网存在大量需要翻译的文案
- **UI 文案混杂**：文本短小且缺乏上下文，容易导致 AI 误判一词多义（如 order 判定为命令还是订单）
- **人工翻译成本高**：传统使用外部平台人工翻译存在耗时长、效果无法保证、需二次核验等问题

## 解决方案

[[货拉拉技术]] 团队为 Lalamove 构建了 [[多agent翻译框架]]，通过翻译 Agent、翻译质量评分 Agent 和敏感信息识别 Agent 协同工作，成功削减了 90% 的人力成本，并将翻译响应时间从数月缩短至数天。
