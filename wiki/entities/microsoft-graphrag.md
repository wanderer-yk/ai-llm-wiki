# Microsoft GraphRAG

Microsoft GraphRAG 是微软开源的 GraphRAG 方案，以**知识挖掘**为核心维度。在 [[货拉拉]] [[大数据技术团队]]对三种 Graph-based RAG 范式的对比中，Microsoft GraphRAG 与 [[lightrag]]（轻量化维度）和 [[pathrag]]（路径推理维度）并列。货拉拉最终未选择 Microsoft GraphRAG，而是在复杂度、灵活性、可嵌入性评估后选择了 LightRAG。
