# 阳凯

阳凯是得物技术公众号的署名作者，2026 年 3 月发表《AI编程能力边界探索：基于 Claude Code 的 Spec Coding 项目实战》一文（文末署名「文 / 阳凯」，与文章 HTML meta 的 author / og:article:author / twitter:creator 三处一致）。据文中第一人称叙述，他是该项目（code-knowledge-qa，代码知识问答系统）的开发者，以 Spec Coding 方式在 10 天内通过 217 条指令、2,754 次工具调用完成 25,546 行净增代码的企业级中后台系统从 0 到 1 搭建。注意：源文未披露其具体职位与内部团队归属，上述身份限定以文章署名与第一人称叙述为据。

## 方法论贡献

阳凯在本文中提出（或作为实践者总结）的系列概念，构成本 wiki 中得物 Claude Code 系列的核心增量：

- [[三层规范体系]] —— 约束层（`.claude/rules/` 7 文件）+ 示范层（`.claude/code-design/` 6 模板）+ 视觉层（`.claude/ui-design/` HTML 设计稿）；
- [[需求颗粒度三档协作模式]] —— 对话→Rules/Skills→OpenSpec SDD 的按颗粒度协作决策框架；
- [[AI顶级执行者比喻]] —— 极度服从/无限耐心/无内部业务常识三特征模型；
- [[AI失效三模式]] 与 [[AI能力边界三结构性特征]] —— 同文两套失效分类法（编码失效 vs 排障失效）；
- [[开发者角色重构]] —— 规范设计能力、系统性思维、质量意识前移三项新核心竞争力；
- [[确定性空间边界论]] —— 「规范是杠杆，AI 是力，Spec 工作流是支点」的全文哲学总结。
