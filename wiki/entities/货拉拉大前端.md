# 货拉拉大前端

## 基本信息

- **所属公司**：货拉拉（Lalamove），物流/出行平台
- **团队定位**：大前端技术团队
- **IP 属地**：上海
- **微信公众号**：「货拉拉大前端」（主体显示名：货拉拉技术）

## 核心实践

货拉拉大前端团队设计并落地了一套 AI 业务级 Code Review 系统，核心理念为**"把团队踩过的坑变成模型的直觉"**。该系统针对传统代码评审中 Diff 过多、历史教训遗忘、AI 不懂业务三大痛点，构建了一个有记忆、懂业务、看过线上事故的 AI 评审助手。

系统完整链路为：[[gitlab-webhook]] 事件触发 → [[diff预处理流水线]] → [[rag经验召回引擎]] → LLM 深度 Review → 可视化报告 → 反馈闭环。工程优化方面采用 [[长diff分片并发与报告整合]] 策略处理大规模 Diff。

## 落地情况

系统已在核心业务大组深度落地，平稳运行于多个核心项目，覆盖底层服务及复杂业务中台等多场景。落地后老事故复发率明显下降。

## 未来规划

- [[发布卡点校验]]：将审计结果作为发布流水线标准条件（规划中）
- 与 [[cursor]] CLI 集成：将审计反馈嵌入编辑器侧边栏（规划中）

## 与其他团队的对比

货拉拉大前端的 AI Code Review 实践与以下团队方案形成互补：

- [[美团技术团队]]：侧重 Pre-PR 机制和高阶模型审查低阶模型
- [[腾讯技术工程]]：侧重 MR 双重视角审查（代码 + 规划文档）
- [[转转技术]]（回收团队）：侧重从 Sonar 静态扫描结果生成修复提示词
- [[有赞技术中台]]：侧重代码搜索定位（Code Insight），同样使用 RAG/AST 技术但聚焦不同场景
