# Nous Research

Nous Research 是一家美国开源人工智能研究机构（此身份表述来自本来源文章），是开源自主智能体项目 [[hermes-agent]] 的开发方，GitHub 组织为 `nousresearch`。据来源文章，Hermes Agent 于 2026 年 2 月底由其开源发布，文章发布时的参考文献给出官网 https://hermes-agent.nousresearch.com/ 与 GitHub 地址 https://github.com/nousresearch/hermes-agent。

在本 Wiki 中，Nous Research 目前仅作为 Hermes Agent 的开发方实体被记录；其研究谱系、其他项目与组织背景在来源文章中未展开，不作推断。

**独立可核查的公开背景（补充说明，非本来源内容）**：Nous Research 是公开可查的 AI 研究组织，其 GitHub 组织页面与官网可用于独立验证 Hermes Agent 项目的存在性与 Star 数等声明。
