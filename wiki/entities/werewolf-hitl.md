# werewolf-hitl

AgentScope 狼人杀人机对战示例项目，位于 `agentscope-examples/werewolf-hitl`，基于 Spring Boot 运行。

## 快速开始

1. 环境要求：Java 17+、Maven
2. 配置 [[bailian|百炼]] API Key：环境变量 `DASHSCOPE_API_KEY`
3. 启动：Spring Boot 主类
4. 访问：`localhost:8080`

## 当前角色集

- 狼人、女巫、预言家、猎人、村民（社区贡献方向包含白痴、守卫、丘比特）
