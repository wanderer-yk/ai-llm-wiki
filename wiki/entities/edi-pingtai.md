# EDI 平台

EDI 平台是 [[京东物流]]用于解决与多样化商家系统对接难题的技术平台。

## 核心功能

- **协议转换** — 对接不同商家的通信协议
- **数据格式转换** — 处理异构数据格式
- **数据校验** — 确保数据完整性
- **流程编排** — 管理复杂的业务流程

## 配置规范要求

EDI 平台的配置文件须严格遵守预定义的语法标准，文件扩展名通常为 `.flow`、`.dt` 等。

## 在代码评审中的关键性

EDI 项目类型是 [[项目身份感知能力]]和 [[文件扩展名特征识别]]的核心应用场景。由于技术 2（JoyAgent 知识库 RAG）缺乏项目身份感知，无法自动识别 XML 文件属于 EDI 项目，导致检索使用通用 Java 规则而非 EDI 专用规范。[[双rag架构]]通过 [[文件扩展名特征识别]]（EDI 优先于普通 Java 项目）解决了这一问题。

实际案例：XML 字面常量错误 `<case value="${orderType}">`（应使用 `<case value="NORMAL">`）被系统成功检出。
