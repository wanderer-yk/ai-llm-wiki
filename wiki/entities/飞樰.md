# 飞樰

飞樰 是微信公众号 [[千问AI平台]] 的作者。据本来源文章，其在该账号撰写“项目深度解析”系列，本篇为系列第 3 篇，前两篇为《深度解析 OpenClaw》与《深度解析 Claude Code》（[[openclaw]]、[[claude-code]]）；作者自称“月更作者被迫周更”，并在文中对 2026 年 AI 迭代提速作出“技术爆炸”的行业观察。

飞樰的分析框架为 Prompt Engineering / Context Engineering / Harness Engineering 三维度，并在 Hermes Agent 一篇中新增“如何实现自进化”视角；共性部分指向前作，重点放在与 OpenClaw/Claude Code 的差异。其系列文章是本 Wiki 中 Agent 自进化、RL 训练闭环与子 Agent 沙箱等主题的重要来源。
