# agentskills.io（Agent Skills 开放标准）

agentskills.io（https://agentskills.io/）是 Agent Skills 的官方开放规范站点，标志着 Skill 已从各厂商私有格式演进为标准化开放规范。在 [[sources/[202604270830]工作流的Skill怎么写从7个顶级Skill中提炼的模式与最佳实践]] 中，它被列为参考资源"官方规范"首位，与 [[anthropics-skills|anthropics/skills]]（官方模板与规范仓库）、[[openai-skills|openai/skills]]（Codex 官方 Skill 目录）、[[clawhub|openclaw/clawhub]]（Skill 注册中心）共同构成 Skill 生态的规范—模板—目录—注册基础设施分层。其开放标准的治理方与版本信息在来源中未披露，待溯源。
