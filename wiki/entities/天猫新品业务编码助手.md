# 天猫新品业务编码助手

**天猫新品业务编码助手**是天猫新品营销技术团队自建的 B 端 MCP 速查工具：通过与 AI 对话获取小二端高频页面代码模版，再输入具体需求，最终输出标准化页面 PRD 供 AI 生成代码。它是该团队"后端向前，前端向后"全栈化转型中，小二端中期阶段"辅助补齐前端经验短板"的三项工具对策之一，[[sources/[202605081607]天猫新品团队AI编码实战指南下|来源]]。

## 定位与工作方式

面向的痛点是转型后端同学（"前端练习生"）的前端术语匮乏——无法精准描述需求导致频繁返工。使用路径为"对话获取模版 → 输入需求 → 输出标准化页面 PRD"，将模糊的自然语言需求转化为结构化的 PRD 输入，体现了"文档先行/PRD 即输入"的生码思路（关联 [[文档先行]]、[[PRD即单测]]）。

## 演进位置

该工具属 [[分阶段生码辅助演进]] 的中期方案；到后期阶段，团队记录到真实采纳摩擦——用户"不想跳出编辑器进行额外的操作（甚至不想配mcp）"，方案转向编辑器 Rules + 无感知识库注入（[[无感辅助]]、[[npm包知识库架构]]）。这一 pivot 是反馈驱动方案迭代的实证，而非 MCP 技术路线本身被否定——C 端方向后续仍纳入"页面检查MCP"。
