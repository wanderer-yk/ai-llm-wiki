# Tair

**Tair** 是阿里巴巴自研的分布式缓存/KV 存储系统，现为阿里云数据库产品线旗下的云数据库产品，兼容 Redis 协议与生态（可独立验证的公开背景）。

## 经验知识化案例

在 [[书牧]] 文章中，"tair version" 用于解决分布式并发问题，被作为 [[解决方案经验知识化]] 的典型案例——将实战经验作为可注入的专家知识沉淀。

## 淘宝闪购 AI Agent 短期记忆存储

在《[[sources/[202603271800]Tair短期记忆架构实践淘宝闪购AIAgent的秒级响应记忆系统|[202603271800]Tair短期记忆架构实践淘宝闪购AIAgent的秒级响应记忆系统]]》一文中，Tair（企业版内存型，云原生架构）承担了 [[淘宝闪购]] AI Agent 短期记忆层的核心存储，支撑"一句话点外卖"场景的秒级响应与千问春节红包活动 10 倍峰值流量。

### 核心能力（该文所述）

- **多线程内核**：企业版内存型采用多线程模型，读写性能宣称达同规格开源 Redis 实例的 3 倍（厂商自报，无第三方基准），使单节点在 Agent 场景一次对话触发数十次 Tair 操作时仍不成为瓶颈。
- **集群读写分离**：主节点挂载只读副本，读请求自动分发到只读节点；只读副本支持 1～9 个/分片，集群分片支持 2～256 个水平扩展，适配记忆数据读多写少（读写比 5:1～10:1）的特征。
- **无感扩缩容**：详见 [[tair无感扩缩容]]——以 Slot 为单位原子整体迁移、中心化控制组件协调，解决传统 Redis `-ASK`/`-TRYAGAIN` 错误对 Agent 对话链路的致命影响。
- **弹性突发带宽**：详见 [[弹性突发带宽]]——秒级自动扩展带宽（单节点最高 288MB/s），分片粒度独立生效，按实际突发量计费。
- **集群带宽水平扩展**：通过增加 LB 扩展总带宽，单个 LB 上限 20Gbps，分片数超过 8 个时可新增 LB 且不断连。
- **TTL 生命周期管理**：会话 Key 自动过期清理，配合弹性扩缩容实现"高峰扩、低谷缩、过期自动数据清理"的全自动资源管理。
- **分布式锁支撑**：基于 `SET NX EX` 的 String 结构为会话级并发控制提供原语（见 [[会话级分布式锁]]）。

### Memory Service 中的数据模型

在 [[淘宝闪购]] Agent 记忆层（Memory Service）中，Tair 以 List 存储模型记忆、Hash 存储业务上下文记忆、String 存储会话状态标记与分布式锁（见 [[模型记忆与业务上下文记忆分离]]）。与 [[RDSClaw]]、[[RDSHermes]] 同属 [[阿里云]] 数据库体系面向 AI Agent 的存储实践。
