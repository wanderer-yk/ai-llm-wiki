# AI Agent 记忆系统：从短期到长期的技术架构与实践

[[柳遵飞（翼严）]] 发表于 [[千问AI平台]] 公众号的记忆系统技术综述，发布于 2026-01-30 08:30（IP 属地浙江）。全文以"短期记忆（会话内）→ 长期记忆（跨会话）"为主线，覆盖记忆基础概念、Agent 框架记忆集成架构、短期记忆上下文工程、长期记忆技术架构与行业趋势五个部分，并以 Google ADK、LangChain、AgentScope 三大框架的实现代码作为实证支撑。

## 核心主张

1. 短期/长期记忆的划分判据是"是否跨 Session"，而非时间长短。
2. 长期记忆与短期记忆双向流动：长期记忆从短期记忆中抽取提炼、实时迭代，并反向注入短期记忆辅助个性化推理。
3. Google ADK、LangChain、AgentScope 均遵循会话级/跨会话级两分，但命名与集成方式各异；LangChain 的长期记忆不属于基础核心组件，而是高阶"个人知识库"外挂。
4. 上下文缩减/卸载/隔离三策略各有适用面，选择取决于时间远近、数据类型、信息可恢复性三因素。
5. ADK 与 LangChain 的上下文策略均与记忆数据存储解耦；AgentScope 经 Memory 接口无缝集成。
6. AutoContextMemory 三点优势：6 种渐进式压缩策略、Memory 接口集成、四层存储完整可追溯。
7. 长期记忆由六大核心组件支撑；Record 流水线终点为 SQLite 审计日志，Retrieve 流水线终点为 Reranker-LLM 重排后返回。
8. Mem0 类长期记忆系统与 RAG 技术架构相似（向量化存储/相似性检索/注入上下文生成），但功能与场景有明显区别（差异对比表为图片，未提取）。
9. Mem0 "几乎成为事实标准"，各方以其为评测基准，综合技术指标与 star/issues 活跃度居长期记忆产品领头地位。
10. ReMe 为 AgentScope 官方长期记忆实现：`userId` 记忆隔离 + 独立服务化部署 + `LongTermMemoryMode.BOTH` 记忆模式。
11. 长期记忆三大挑战：准确性（记忆管理 + 检索准确度）、安全隐私（防数据中毒/加密访问控制/透明管理/用户掌控权）、多模态（统一多模态记忆空间为原文自认未解难题）。
12. 记忆即服务（MaaS）：记忆系统将类比"数据库"之于传统软件，成为 AI 应用基础设施。
13. 参数化记忆（Memory Adapter）响应快但面临灾难性遗忘与高更新成本；外部记忆增强是当前主流。
14. 各框架内置上下文策略已解决 80-90% 通用场景；医疗/法律/金融等垂直领域仍需针对性处理与更精细的压缩 prompt 设计；长期记忆将走向云服务化与人脑式全生命周期管理。
15. 业务领域经验有两条沉淀路径：领域知识库、强化学习微调进模型（见 [[长期记忆信息组织维度]]）。

## 关键结构化数据

### 记忆集成四步模式

```text
Step1：推理前加载 — 根据当前 user-query 从长期记忆中加载相关信息
Step2：上下文注入 — 从长期记忆中检索的信息加入当前短期记忆中辅助模型推理
Step3：记忆更新 — 短期记忆在推理完成后加入到长期记忆中
Step4：信息处理 — 长期记忆模块中结合 LLM+向量化模型进行信息提取和检索
```

### 长期记忆六大核心组件

| # | 组件 | 职责 |
|---|------|------|
| 1 | LLM 大模型 | 提取短期记忆中的有效信息（语义理解、抽取、决策、生成） |
| 2 | Embedder 向量化 | 文本转语义向量，支持相似性计算 |
| 3 | VectorStore 向量数据库 | 持久化存储记忆向量和元数据，支持高效语义检索 |
| 4 | GraphStore 图数据库 | 存储实体-关系知识图谱，支持复杂关系推理 |
| 5 | Reranker 重排序器 | 对初步检索结果按语义相关性重新排序 |
| 6 | SQLite | 记录所有记忆操作的审计日志，支持版本回溯 |

### Record / Retrieve 流水线

```text
Record：LLM 事实提取 → 信息向量化 → 向量存储 →（复杂关系存储）→ SQLite 操作日志
```

```text
User query 向量化 → 向量数据库语义检索 → 图数据库关系补充 →（Reranker-LLM）→ 结果返回
```

### Google ADK 事件压缩配置（Python）

```python
from google.adk.apps.app import App, EventsCompactionConfig

app = App(
    name='my-agent',
    root_agent=root_agent,
    events_compaction_config=EventsCompactionConfig(
        compaction_interval=3,  # 每3次新调用触发压缩
        overlap_size=1          # 包含前一个窗口的最后一次调用
    ),
)
```

### LangChain 摘要中间件（Python）

```python
from langchain.agents import create_agent
from langchain.agents.middleware import SummarizationMiddleware

agent = create_agent(
    model="gpt-4o",
    tools=[.],   # 原文如此，疑为 tools=[...] 的排版截断
    middleware=[
        SummarizationMiddleware(
            model="gpt-4o-mini",
            max_tokens_before_summary=4000,  # 4000 tokens时触发摘要
            messages_to_keep=20,  # 摘要后保留最后20条消息
        ),
    ],
)
```

### AgentScope AutoContextMemory 使用示例（Java）

```java
AutoContextMemory memory = new AutoContextMemory(
    AutoContextConfig.builder()
        .msgThreshold(100)
        .maxToken(128 * 1024)
        .tokenRatio(0.75)
        .build(),
    model
);
ReActAgent agent = ReActAgent.builder()
    .name("Assistant")
    .model(model)
    .memory(memory)
    .build();
```

### AgentScope 集成 Mem0（原文标注 Java）

```java
// 初始化Mem0长期记忆
Mem0LongTermMemory mem0Memory = new Mem0LongTermMemory(
    Mem0Config.builder()
        .apiKey("your-mem0-api-key")
        .build()
);
// 创建Agent并集成长期记忆
ReActAgent agent = ReActAgent.builder()
    .name("Assistant")
    .model(model)
    .memory(memory)  // 短期记忆
    .longTermMemory(mem0Memory)  // 长期记忆
    .build();
```

### AgentScope 集成 ReMe（原文标注 Java）

```java
// 初始化ReMe长期记忆
ReMeLongTermMemory remeMemory = ReMeLongTermMemory.builder()
    .userId("user123")  // 用户ID，用于记忆隔离
    .apiBaseUrl("http://localhost:8002")  // ReMe服务地址
    .build();
// 创建Agent并集成长期记忆
ReActAgent agent = ReActAgent.builder()
    .name("Assistant")
    .model(model)
    .memory(memory)  // 短期记忆
    .longTermMemory(remeMemory)  // 长期记忆
    .longTermMemoryMode(LongTermMemoryMode.BOTH)  // 记忆模式
    .build();
```
