# 颠覆传统！意图规划+上下文工程+数据自迭代，让企业智能办公助手效能跃升200%

## 基本信息

- **作者**：[[fucheng|富城]]
- **发布机构**：[[ma-shang-xiao-fei-ji-shu-tuan-dui|马上消费技术团队]]
- **发布时间**：2026年1月13日
- **平台**：微信公众号

## 核心主张

文章提出[[enterprise-intelligent-assistant|企业智能办公助手]]的三层方法论架构，主张从"能用"到"好用"需通过三大方法论融合实现效能跃升：

1. **[[intent-planning|意图规划]]**：确保精准理解用户意图
2. **[[context-engineering|上下文工程]]**：保障信息准确交付
3. **[[data-self-iteration|数据自迭代]]**：驱动持续优化

## 技术架构

### 意图规划落地
- **[[query-rewriting|Query改写]]**：多轮补全、指代消解、长文摘要三类动作
- **[[small-model-beats-llm-in-classification|意图识别]]**：微调 [[roberta|RoBERTa]]（110M参数）达到95%+准确率，远超LLM少样本的<90%
- **意图挖掘**：基于匿名会话关联挖掘，摒弃ToC通识推荐

### 上下文工程落地
- **知识入库**：解决动态更新、多模态注入、客服沉淀、信源冲突四大难点
- **数据注入**：[[entity-merge-wide-table|主体合并宽表]]（~100%准确率）与 [[faq-conversion|FAQ转化]]（98%+准确率）
- **Agent协同**：[[agent-collaboration-delivery|智能规划模式+精准路由模式]]双模式

### 数据自迭代
- **质检机制**：基于通用LLM的 [[quality-inspection-ai|质检AI]]，混淆矩阵一致性89%
- **闭环迭代**：日志记录→弱样本抓取→标注回流→模型重训→动态部署

## 关键量化成果

| 指标 | 数值 |
|------|------|
| 意图识别准确率 | 95%+（RoBERTa微调） |
| 全局查询准确率 | 93%+ |
| 主体合并宽表准确率 | ~100% |
| FAQ转化准确率 | 98%+ |
| 质检AI一致性 | 89%（基准80%） |
| NLP2SQL准确率 | <80%（被否定） |

## 核心矛盾与张力

- 明确否定 [[nlp2sql-limitation|NLP2SQL]] 路线（<80%不可接受）
- 渠道优先级将模型世界知识置于最低：人工FAQ > 内部文档 > 外部搜索 > 模型世界知识
- 标题宣称"200%效能跃升"但未给出具体度量方法
- 质检AI接受通用LLM（89%），但意图分类否定通用LLM（<90%），存在场景依赖的准确率容忍梯度
