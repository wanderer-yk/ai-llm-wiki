## 核心思想：观察-思考-行动

ReAct = Reasoning（推理）+ Acting（行动），说白了就是"让 AI 一边想一边做，而不是想完了再做"。

ReAct Agent 不是一次性规划好整个流程，而是在有一个整体目标的前提下走一步看一步：观察当前情况 → 思考下一步 → 执行动作 → 观察结果 → 根据结果决定下一步，循环直到任务完成。

**类比**：传统方式像出门前把整个路线都查好、严格按照路线走；ReAct 像走到路口看路牌再决定左转还是右转，边走边找咖啡店。

## ReAct 五要素

文章将 ReAct 的实现拆解为五个关键要素（详见 [[react五要素]]）：

1. **历史上下文（History）**——记录之前所有的思考、行动和观察，供 LLM 决策参考
2. **当前环境信息（Current Environment Information）**——当前时刻接收的外部信息
3. **LLM Thinking**——"大脑"，负责推理和决策（思考隐藏，外显为 toolcall）
4. **工具/动作（toolcall）**——"手脚"，执行搜索、查询 API、读写文件等具体操作
5. **观察结果（toolcall 结果）**——动作执行后的返回，作为下一轮推理的依据

## 三轮执行示例

任务："帮我查一下北京今天天气怎么样，适合穿什么衣服。"

| 轮次 | 历史上下文 | 当前环境信息 | 当前轮次提示词 | 行动(toolcall) | 观察结果(toolcall结果) |
|---|---|---|---|---|---|
| Round 1 | 无 | 空 | 固定模板（全文见下方代码块） | 天气查询工具调用：查询"北京今天天气" | 天气查询工具返回：温度 25°C，晴天，湿度 60%，风速 3m/s |

## 固定提示词模板

```
已知：
当前历史上下文：&{历史上下文}
当前环境信息：&{当前环境信息}
用户目标："帮我查一下北京今天天气怎么样，适合穿什么衣服。"

做出下一步的决策

你必须最少使用一个工具来实现该决策
```

**关键观察**：提示词跨轮次固定不变，仅"历史上下文"字段随轮次增长——这是 ReAct 轮次推进的实现机制。

## 单轮执行与主循环伪代码

```
函数 执行一个轮次(用户目标, 历史上下文):
    // 1. 获取当前环境信息
    当前环境信息 = 获取当前环境信息()

    // 2. 构建提示词（替换占位符）
    提示词模板 = "已知：\n当前历史上下文：${历史上下文}\n当前环境信息：${当前环境信息}\n用户目标：\"${用户目标}\"\n\n做出下一步的决策\n\n你必须最少使用一个工具来实现该决策"
    完整提示词 = 替换占位符(提示词模板, {
        历史上下文: 历史上下文,
        当前环境信息: 当前环境信息,
        用户目标: 用户目标
    })

    // 3. 调用 LLM 进行推理（思考过程隐藏，直接输出 toolcall）
    工具调用结果 = 调用语言模型(完整提示词, 历史上下文)

    // 4. 解析工具调用
    工具名称 = 解析工具名称(工具调用结果)
    工具参数 = 解析工具参数(工具调用结果)

    // 5. 执行工具调用
    观察结果 = 执行工具(工具名称, 工具参数)

    // 6. 更新历史上下文
    新历史上下文 = 追加到历史上下文(历史上下文, {
        行动: 工具调用结果,
        观察结果: 观察结果
    })

    // 7. 返回结果
    返回 {
        观察结果: 观察结果,
        新历史上下文: 新历史上下文
    }
结束函数

// 主循环
函数 执行ReAct流程(用户目标):
    历史上下文 = 空
    当前轮次 = 1
    最大轮次 = 10

    当 当前轮次 <= 最大轮次 且 未完成任务:
        结果 = 执行一个轮次(用户目标, 历史上下文)
        历史上下文 = 结果.新历史上下文

        如果 判断任务已完成(结果.观察结果):
            中断循环

        当前轮次 = 当前轮次 + 1
    结束循环

    返回 历史上下文
结束函数
```

主循环包含完成判断与 `最大轮次 = 10` 的硬编码上限，防止无限循环——是 [[agent-loop]] 概念的一个具体落地实例。

## 关键论断

1. **ReAct = 边想边做，而非想完再做**：通过"找咖啡店"类比与固定流程对照阐明
2. **实现由五要素构成**：见 [[react五要素]]
3. **提示词固定、仅历史增长**：轮次推进的工程本质
4. **思考是可选输出**：思考如同人的内化思考，最终表现形式就是 toolcall（见 [[思考内化论]]）
5. **优势与代价并存**：优势是能根据观察动态调整（如 Round 1 搜索失败可换关键词换策略）；代价是行为可能不可预测、有时会"犯傻"
