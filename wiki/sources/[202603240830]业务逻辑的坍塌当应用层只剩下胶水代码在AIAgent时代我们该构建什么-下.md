# 业务逻辑的坍塌（下）：当应用层只剩下胶水代码，在 AI Agent 时代我们该构建什么

作者 [[韩春]]，时间戳 2026-03-24。本文是《业务逻辑的坍塌》系列的**下篇**，直接续接 [[sources/[202603240830]业务逻辑的坍塌当应用层只剩下胶水代码在AIAgent时代我们该构建什么-上|《业务逻辑的坍塌（上）》]]。参考资料 [2] 即库内既有来源 [202602260830]（Function Calling / MCP / Skills 对比），且两篇共享同一微信 `__biz=MzIzOTU0NTQ0MA==` 标识，可确认同一系列账号（发布公众号中文名待确认，故 venue 暂空）。

## 核心论点总览

1. **"60 年回到起点"论**：Transformer 中参数量最大的全连接网络 FFN，与上世纪 60 年代的多层感知机（MLP）没有太大区别——变的是 GPU 超强算力的爆发，以及物理世界在数据世界投射后留下的海量高质量学习样本。
2. **简单结构堆叠可涌现智能**：理解 MLP 以简单单元组合产生超强泛化能力的机制后，就能直观理解"当数据足够多、算力足够强时，简单的结构堆叠也能涌现出惊人的智能"。
3. **两种解题思路**（借用 [[阳萌]] 的观点）：分而治之（符号化拆解）vs 暴力美学（LLM 以海量参数+算力直接逼近原问题）→ [[分而治之与暴力美学]]。
4. **大 Prompt 即可解决痛点**：担保平台刷单风控案例——不做任何 Context 管理，把订单+买家数据（含征信）组成大 Prompt 提交 LLM 也能发现问题且效果不错。
5. **AI 突破性应用本质是业务流程的重新定义**：这类创新很难从下而上在叶子团队产生（康威定律）→ [[业务流程重定义论]]。

## 内容一：深度学习简史（1957–2017）

### 历史时间线（按源文保留）

| 年份 | 里程碑 | 核心贡献 |
|------|------|------|
| 1957 | 感知机（Frank Rosenblatt） | 模拟生物神经元的简化模型；AI 研究方向从符号主义（规则与逻辑推理）转向联结主义（神经元连接与数值矩阵计算） |
| 1969 | XOR 问题（Minsky《Perceptrons》） | 论证感知机系统局限：多层感知机不可被训练——缺乏有效学习算法（当时只能训练输出层）、理论分析极其困难（"群不变性"等问题） |
| 1986 | 反向传播（Hinton 等） | 基于计算图的可自动微分分布式梯度计算范式：计算图构建与正向传播、链式法则的工程化实现（梯度以 O(N) 复杂度计算）、模块化与局部性（节点只定义局部梯度，全局梯度链式相乘） |
| 1998 | CNN / LeNet-5（Yann LeCun） | 将领域知识（图像空间局部性、平移不变性）编码进网络结构：从全连接到稀疏连接、进入弱特征工程时代、硬件友好的可并行计算模式 |
| 2012 | AlexNet | ImageNet 夺冠，Top-5 错误率 15.3% vs 传统方法（手工特征+SVM）26.2%；定性为**工程实践**而非理论突破：8 层（5 卷积+3 全连接）激进扩展、2× NVIDIA GTX 580 GPU 并行（解决单卡显存不足）、ReLU 替代 sigmoid/tanh 缓解梯度消失 |
| 2017 | Transformer | 实现工程上的标准化（注意力层、前馈层、残差连接、层归一化），降低新模型开发复杂度、促进开源生态繁荣；原论文为 Encoder-Decoder 架构，如今 LLM 几乎一边倒地导向 Decoder-only |

### 神经网络三要素

- **深度**（中间隐藏层层数）：从线性代数空间折叠视角看，矩阵每层计算是对输入维度的一次折叠；关键在 `wx+b` 后的**激活函数**——这是引入非线性的关键，否则多层瞬间退化为单层（一个矩阵），依然只是线性变换，无法扭曲空间。
- **宽度**（每层神经元个数）：对上一层输入的一次特征提取；神经元越多，相当于把数据投影到越高维的空间，寻找切分平面的自由度越大。
- **形式**（神经元间连接形式）：理论上无限扩展宽度和深度即可解决非常复杂的问题（如 Transformer FFN 的全连接）；但在 GPU 算力到达一定程度前全连接不可落地，中间几十年出现了贴垂直场景的结构——CNN（局部连接/卷积）与 RNN（时序传递，但有长距离遗忘问题）。

**佐证**：借助 TensorFlow Playground 与可视化工具 GeoGebra，随机调整超参数后，仅 2 层隐藏层的神经网络也能产生复杂的空间折叠能力，解决复杂分类问题。

### MLP 解 XOR 的权重配置（按源文保留）

```
隐藏层（2 个神经元）：
  或门   w=[1, 1]   b=0.5   （sum ≥ 0.5 输出 1）
  与非门 w=[-1, -1] b=-1.5  （sum > -1.5 输出 1）
输出层：与门（sum ≥ 1.5 输出 1）

示例输入 (0,0)：
  隐藏层 或门   0×1+0×1=0，0 < 0.5  → 输出 0
  隐藏层 与非门 0×(-1)+0×(-1)=0，0 > -1.5 → 输出 1
  输出层 与门   0×1+1×1=1，1 < 1.5  → 最终输出 0
```

**关键论断**：以 Transformer 中参数量最大的 FFN 看，和上世纪 60 年代的多层感知机没有太大区别——"**60 年后，又兜兜转转回到了起点**"，中间变的是 **GPU 算力**与**数据**。此论断直接强化 [[Transformer历史阶段性]] 与 [[显存墙与算力墙]]。

## 内容二：Qwen2.5-7B 推理三阶段拆解

源文以 [[qwen]] 家族的 Qwen2.5-7B 为例，完整拆解 LLM 一次推理的计算过程 → 详见 [[llm推理三阶段]]。

### 架构参数（按源文保留）

| 参数 | 值 |
|------|------|
| 词表大小 | 约 152000 |
| Embedding 维度 | 4096 |
| 层数 | 28 |
| FFN | 2 层，4096 → 18944（约 4 倍于 4096，不同模型不同）→ 4096 |
| 示例输入 | "你作为一个科普达人，请用小学生可以理解的方式，介绍下 LLM 的主要原理？" → 约 20 个 Token（中文通常 1~2 字一 Token）→ X=[20×4096] |
| 注意力矩阵 | [20×20]，Q·K 除以 √d 缩放后 softmax，再乘 V |

### 三阶段要点

- **阶段一：Tokenization 与 Embedding 映射**——分词器与 Embedding 成对出现、预训练后得到；每个 Token 以 4096 维向量表示，得输入矩阵 X=[20×4096]；Embedding 维度越高拟合细节越好，但后续计算量急剧上升；加入位置编码后送入注意力计算。
- **阶段二：预填充（Pre-fill）与注意力计算**——训练所得权重矩阵与 X 相乘得 QKV（均 [20×4096]）；**K 和 V 存入显存**（KV Cache），后续新 Token 到来时避免前序 Token 重复计算，Q 用完即弃；注意力计算中每个 Token 的 Q 与其他 Token 的 K 相乘算相关性，除以 √d 缩放（防梯度消失、保持 softmax 输入可控），softmax 归一化后乘 V 提取信息，输出仍为 [20×4096]，但已掺杂 Token 间关系；Attention 的非线性来自 softmax，FFN 通过激活函数（如 SwiGLU）进一步增加非线性表达；随后残差连接 Add（解决深层网络梯度消失）与归一化 Norm（保障数值分布稳定）。
- **阶段三：生成首个 Token**——28 层循环后仍输出 [20×4096]；只取最后一行 [1×4096]（对应"？"位置，包含全部输入上下文信息），与输出映射矩阵相乘（可为阶段一 Embedding 矩阵的转置）映射回词表空间，经 softmax 得概率分布，按采样方法（如参考 Temperature 设置）仲裁出下一个 Token；如此往复自回归生成。

**层次澄清**：本节的 KV Cache 是**推理层**的 K/V 显存缓存机制；与 [[kv-cache时间窗优化]]（OpenClaw 上下文缓存的命中时间窗，应用层）是**不同层次的同名机制**，不可混淆。

## 内容三：九、一些后话

### 两种解题思路（借用阳萌的观点）

如果把解决问题的方法进行足够抽象，只有两种解题思路：
1. **分而治之**：把大问题拆成一个个已知问题，通过严谨的数据符号、规则去解决。难点在于：大多数事物不是绝对 0 或 1，存在大量微观联系，纯符号表达要么丢失微观细节、要么表达式过于复杂无法落地，**精度很容易停在 50% 或 80%，再往上很难**。
2. **暴力美学**：今天 LLM 的思路——不再对细分后的问题精确求解，直接通过**海量参数以及算力逼近原问题**的解决。

→ 详见 [[分而治之与暴力美学]]。

### 担保平台刷单风控案例（"暴力美学"的实战注脚）

一些监管机构为规避商家跑路风险（如健身房充卡）牵头搭建担保平台：用户向平台充值、商家定期提取并可获补贴；有利益即生灰产——部分商家通过刷单骗取补贴。正常解题需招聘业务风控、数据分析、前端与后端开发；而借助 LLM，**即便不做任何 Context 管理**，仅将该商家一段时间内订单及对应买家数据（包括征信等）组成一个大 Prompt 提交给 LLM，也能发现问题，而且效果还不错。"远远谈不上用了什么高深的技术架构，但是它**实实在在解决了一个痛点问题**"。

⚠️ 证据等级：作者**转述的单一轶事**，无量化指标，强度弱。与全库上下文工程重心（及本文自身参考资料 [5] Anthropic context engineering）形成张力——见 [[分而治之与暴力美学]] 中的适用边界辨析。

### 业务流程重定义论（康威定律的 AI 应用）

"AI 突破性应用，本质上是一场业务流程的重新定义。这也决定了这种创新，**很难从下而上在叶子团队产生**。"现有组织架构是已有产品形态运行多年沉淀下来的分工，而 AI 的创新大概率要突破现有产品形态。电商例证：商品、优惠、交易、库存拆到 4 个团队（还可能涉及中台/平台更多团队），每个团队职责仅是整个业务流程的一部分——优惠再拥抱 AI 也还是优惠，而优惠不是目的，只是原有体系中促成交易的一种方法。"**不改变大的业务流程，所在问题域依然被限定在一个确定输入和输出的空间**"——此句为 [[确定性输入输出空间定制论]] 的原文级呼应。
