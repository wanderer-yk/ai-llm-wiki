## 核心声明

- Agent = Reasoning + Acting；所有主流框架本质是 ReAct 的扩展
- **Agent 框架设计核心 = 在 Agent Loop 的 While 循环中管理上下文**
- [[上下文工程]] 是 Agent 框架中"低垂的果实"（GPT-5.1 (High) 无 Context 仅解决 <1% 任务）
- 代码库本身成为上下文工程的一部分；代码越简洁，Agent 越智能
- Manus 放弃微调和 MCP，选择上下文工程 + CodeAct 路线
- Manus 首席科学家 Peak："Actually, Manus doesn't use MCP, inspired by CodeAct"
